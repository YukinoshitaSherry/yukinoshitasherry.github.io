为了硕士阶段上点体育课恶补的。
健身口令的骨架是动词、身体部位与体位名。本文按五种场景分列：垫上普拉提（Mat Pilates）、普拉提融合（Pilates Fusion）、把杆融合（Barre Fusion）、有氧舞蹈（Cardio Dance）、健身房器械（Gym）。前四块在约百词基础上略作扩展；器械一块按机种、部件、调节与标牌用语写细。释义对应身体所指与常见搭配，不收录课堂流程。

<br>

# Mat Pilates

逻辑链：**呼吸 → 核心 → 骨盆/脊柱 → 四肢控制 → 稳定**。幅度通常偏小，强调控制而非甩动。

## 呼吸

| 英语 | 中文 | 释义 |
| --- | --- | --- |
| **inhale** | 吸气 | 常见经鼻 |
| **exhale** | 呼气 | 发力、卷腹、收核心时常落在呼气 |
| **breathe** | 呼吸（动词） | 与 *hold the breath*（憋气）相对 |
| **breath** | 气息（名词） | *take a breath* |
| **deep breath** | 深呼吸 | 慢吸、充分换气 |
| **lateral breathing** | 侧向呼吸 | 胸廓向两侧扩张，腹部不完全鼓起 |
| **ribcage breathing** | 胸廓呼吸 | 与 *lateral breathing* 近义 |
| **diaphragmatic** | 膈肌的 | *diaphragmatic breathing* 腹式/膈肌呼吸 |
| **through the nose** | 经鼻 | *inhale through the nose* |
| **through the mouth** | 经口 | *exhale through the mouth* |
| **exhale on effort** | 发力时呼气 | 阻力最大的瞬间配合呼气 |

> [!EXAMPLE]+ 搭配
>
> Exhale and engage the core. / 呼气并收紧核心。
>
> Inhale to prepare, exhale to lift. / 吸气预备，呼气抬起。

# Pilates Fusion

Fusion 把普拉提的核心控制，和力量、把杆、瑜伽、有氧元素拼在同一套组合里。词表按来源分列；同一节课里 *tabletop* 之后接 *squat* 或 *downward dog* 属于正常混用。

## 从普拉提带过来的词

**core / engage / tabletop / neutral / pelvis / imprint / bridge / roll down / C-curve / hover / lengthen**

这些词在 Fusion 里仍然管稳定，不因加入负重而改义。

<br>

> Hold the squat and pulse. / 停在蹲位，只做小幅度上下。
>
> 完整 *rep* 是蹲下再站起；*pulse* 把行程截在短区间里。
