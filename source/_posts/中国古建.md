> 市政上的发展，建筑物之新陈代谢本是不可免的事。但即在抗战之前，中国旧有建筑荒顿破坏之范围及速率，亦有甚于正常的趋势。这现象有三个明显的原因：一，在经济力量之凋敝，许多寺观衙署，已归官有者，地方任其自然倾圮，无力保护；二，在艺术标准之一时失掉指南，公私宅第园馆街楼，自西艺浸入后忽被轻视，拆毁剧烈；三，缺乏视建筑为文物遗产之认识，官民均少爱护旧建的热心。
> 中国金石书画素得士大夫之重视。各朝代对它们的爱护欣赏，并不在文章诗词之下，实为吾国文化精神悠久不断之原因。独是建筑，数千年来，完全在技工匠师之手。其艺术表现大多数是不自觉的师承及演变之结果。
> 如果世界上艺术精华，没有客观价值标准来保护，恐怕十之八九均会被后人在权势易主之时，或趣味改向之时，毁损无余。
> ——《中国建筑史》代序

## 绪论

据梁思成《中国建筑史》绪论整理：

建筑三要素：**合用、坚固、美观。**

* 建筑之始出于实际需要，受制于自然物理，并非先有意创制“形式”或“派别”
* 结构系统与形式分野，由**材料与环境**所形成；埃及、巴比伦、伊琴、美洲及中国诸系，皆各自在环境中胚胎、粗具规模，再转增繁缛
* 演变随气候与物产、国俗与制度、政治经济，以及艺文技巧、知识发明之进退，而不自觉
* 建筑之规模、形体、工程、艺术，乃民族特殊文化兴衰之投影；可反鉴一民族物质与精神面貌
* 治古史者常赖建筑遗迹或记载以测文化——建筑活动与民族文化动向相牵连，互为因果


显著特征来自两方面，治史须先把握，以免淆乱一系自身优劣之准绳，亦不惑于他时他族之异同：

1. **实物结构技术**上之取法及发展
2. **环境思想**之趋向

把握此二者，始能对中国建筑物有正确观点，不作偏激毁誉。

### 结构特征

#### 木构为主

* 材料决定做法，做法产生形式特征
* 他系多由木而改以石为主，或以石雕模仿木构外形；中国则一贯以木为主要构材，形式即木构之直接表现
* 目标：尽量发挥木材性能以应实用，并同时取得尽善尽美之形式
* 历代遵古经验，唐宋少数遗构可视为千余年工程经验蓄积后之结构与风格高峰

#### 构架制

* 因木为主，结构原则为**梁柱式 / 构架制**：墙不承重，梁柱传力
* 基本空间单位为**间**：四柱，前后以枋、左右以梁联系
* 梁架层叠如阶，辅以**举折**定坡；梁端承**槫（檩）**，视层数可有五、七乃至十一槫，最上为脊槫

#### 斗栱

* 位于梁柱交接，与屋顶结构关系尤密；将上部荷载逐步集中传到柱上，为大建筑所必需
* 标准化后，以**材**（及后世斗口）为权衡单位，类似罗马柱式之以柱径为模数
* 建筑如语言：**辞汇**为柱额斗栱梁檩瓦椽等；**文法**为各件之一定做法与组合规则
* 砖石阙、塔亦常仿木斗栱之形；斗栱组织与权衡历代不同，故可作**年代判断**之依据


#### 外部轮廓与组织

##### 轮廓

* **翼展屋顶**：自殷商以来即为着眼处；梁架层叠与举折成曲面；角梁、翼角、椽与飞椽、脊吻等合成柔和而宏大之轮廓
* **崇厚阶基**：与瓦顶相衬。周秦汉曾盛高台之风，后渐趋平缓，然台随檐出、须弥座等仍为轮廓要部
* **玲珑屋身**：屋顶与阶基之间，正面多为楹柱与玲珑装修，罕用厚墙开窗；山墙左右门窗常少。厚墙开洞多见于箭楼、仓廒等，与砖石建筑做法有别

##### 院落

* 中国建筑之单位非孤立一殿，而是主屋与配厢、夹室、廊庑、周屋、山门、前殿、围墙、角楼等之组织
* 除佛塔等外，单体少能于远处见全貌；院落中因距离近，往往只见立面之一部
* 完整印象须含庭院；故宫殿楼阁图绘多用登高鸟瞰

##### 彩色

* 结构表面施色为固有传统；春秋已有彩饰，唐宋以来体制等级渐严
* 明清梁枋彩画有严格规矩（分段、留素面等）；以青绿与纯丹对比，非任意堆色
* 外檐彩画多集中于檐影下之斗栱、横额、柱头——略如欧洲石建筑雕饰集中于额与柱头；墙面与柱身反多素净
* 木面髹漆有实用必要；琉璃亦重纯色与等级

<br>


* **胶结料**：垫灰（石灰类）长期未得圆满解决，亦限制砖石大木式结构之发展

### 环境思想

与他系建筑史背景迥异者，至少有四：

#### 不求原物长存

* 地面最古实物极少；汉唐石阙、砖塔年代已近，且非居止殿堂
* 木寿有限是一因；更深者在观念：未若古埃及刻意与自然竞久存，而安于**新陈代谢**，视建筑如被服舆马，可更换；焚毁亦常视为灾异天谴
* 后果：
  * 满足于木材沿用数千年，精进木作，而不深究砖石替代
  * **重修远不如重建之盛**；珍旧址与创建年代，不重原物本身。唯陵墓砖券求永固，与地面木殿原则互异；地面殿堂鲜因墓室用砖而改辙

#### 道德制裁

* 官方尚俭：大兴土木易被目为劳民、骄奢
* 坛社宗庙、城阙朝市因礼制而受尊；宫馆台榭园林则史家常据以责非礼
* 史籍少详述建筑形状与营造法，建筑多附见于舆服、食货等，意在戒奢，非技术史
* 道德与阶级制度，使设计趋于简约与制度化，而非个人炫技式结构创新

#### 布署规划

* 儒家政治与礼仪使记载重**名称方位、平面布署**，鲜及殿堂结构细部
* 中国思想（政治、宗法、风俗、礼仪、佛道、风水）主要寄托于**平面分布**
* 立体形貌之感人处多见于诗词歌赋与绘画意境；史家所重在规制等级

#### 匠学传授

* 建筑素称**匠学**，非士大夫余事；须毕生实习，非茶余可兼
* 匠人多困于文字，赖**口授实习**，不重书籍
* 传世官刊术书，主要仅宋《营造法式》、清《工程做法则例》——因各家匠法分歧、功限料例无准则而颁为官府标准
* 士人不解术语，匠人又难读其书，日久造法成谜；亦无如画学《历代名画记》一类之建筑全史专书
* 视建筑为文化表现而作系统研究，乃近现代视角（梁氏当时犹称新观点），先有考察测绘之风，社会态度始渐改

#### 两种平面

| 类型 | 适用 | 特征 |
| :--- | :--- | :--- |
| **绝对均称** | 宫殿、官署、庙宇、住宅 | 左右均齐；建筑绕庭院；最重**中轴线**；适于大朝、婚丧节庆等礼仪 |
| **绝对自由** | 庭园游息 | 排斥对称庄严；高下曲折，穿插池沼花木；求自然与诗画之境 |

二者反映中国精神生活之不同方面。

#### 不擅用石

* 数千年以木为主，砖石多居辅助；大工程罕以石为主要构材
* **力学误解**：石耐压而不善张、弯；匠人多以木作思维治石（如石牌坊、钩阑用卯榫），未能充分用垒砌承压之长——隋李春安济桥等为少数善用石性之例

### 分期

建筑演变本为赓续过程；分期乃为叙述方便，兼据朝代更迭、文化变动与实物、文献之多寡。梁思成《中国建筑史》第二节大致如下：

| 期 | 年代约 | 要点 | 遗存与依据 |
| :--- | :--- | :--- | :--- |
| **上古 / 原始** | 上古至秦（约前 200 年以前） | 文献、实物皆极少 | 殷周战国城垣宫殿墓葬遗址多待发掘；殷以前地面建筑实物无考 |
| **两汉** | 约前 204—220 | 中国建筑之发育期；营建活跃，记载较丰，形制大体可推 | 地面遗构少，多赖墓室、石阙；旁证为明器、汉画像石等 |
| **魏晋南北朝** | 220—590 | 乱世而宫室佛寺仍盛；佛教为大动力 | 艺术吸收健陀罗等风，圆和雕刻与花草鸟兽人物图案开新境，脱两汉而创新；遗物多石窟、佛塔、陵墓 |
| **隋唐** | 590—906 | 隋建大兴（长安）奠基；唐为艺术全盛与成熟 | 安定则宫寺大盛；安史乱与会昌、后周灭法毁损巨构。今存多石窟、陵墓、砖石塔；尤珍隋石桥、晚唐木构佛殿。风格豪劲宏伟而兼柔和精丽 |
| **五代宋辽金** | 906—1280 | 五代北宋以降趋于绚丽精细，中叶后益趋纤巧 | 宫室多毁；佛殿散见北方各省，塔幢特多。手法特殊、布置稳妥，遵古制而渐变。《营造法式》为关键文献 |
| **元明清** | 1280—1912 | 三朝多以北京为都，都市宫殿规模空前；大体沿古制 | 明清之际藏式传入，耶稣会教士传入西式；清工部《工程做法则例》为官式准则。清末欧风浸入，标准紊乱，民居市廛传统影响渐弱 |
| **民国以降** | 1912 以后 | 初颇沉寂；通商口岸欧美建筑扩展 | 留学欧美者归而竞造，欧式盛极；后渐自觉采用固有建筑样式于新建筑。未来或随世界潮流减其绝对地方性，然因传统与民族性，终当别成一派，形成尚待 |


接上列特征与分期，现场可先抓三层，再与后文各节互证：

* **单体**：台基—屋身—屋顶（三段式轮廓）
* **构架**：柱梁枋檩如何传力；有无铺作层；柱网是否减柱、移柱
* **组群**：院落、轴线、等级与礼制如何组织空间

细读斗栱（铺作）：**出跳数 → 铺作名 → 杪昂组合 → 逐跳计心/偷心 → 单栱或重栱**。

宋《营造法式》与清《工部工程做法则例》即上述“文法书”。宋以**材、栔、分**为模数，清大式以**斗口**为模数。

> [!NOTE]+ 风格分期（梁、林常用框架）
>
> - **豪劲**：隋唐——出檐深远、斗栱硕大、结构逻辑清晰
> - **醇和**：宋辽金——权衡成熟、标准化与变化并存
> - **羁直**：明清——斗栱缩小偏装饰、梁架更规整、制度更严

山西保存唐至明清实物极丰（佛光寺、应县木塔、晋祠、五台山诸寺等），唐以前木构约占全国绝大多数，是核对文献与实物的核心样本区。下文各节所举，优先**全国重点文物保护单位（国保）**，地名统一标**（省份）**。

## 形制

形制指建筑类型、屋顶形式、开间进深与等级制度所规定的外观与平面规则。

### 屋顶

屋顶是识别等级与时代风格最直观的标志。

| 形式 | 特征 | 等级与常见用途 | 典型实例（多为国保） |
| :--- | :--- | :--- | :--- |
| 庑殿顶 | 四面坡，正脊一条，无山花 | 最高；宫殿主殿、重要寺庙 | （北京）故宫太和殿（重檐）；（天津）独乐寺山门（现存最早庑殿顶山门） |
| 歇山顶 | 上半四面坡，下半两面垂直山花 | 次高；殿堂、楼阁常见 | （山西）佛光寺东大殿；（山西）大同善化寺诸殿；（山西）晋祠圣母殿 |
| 悬山顶 | 两坡，屋檐悬出山墙外 | 民居、次要殿宇 | （山西）五台南禅寺大殿；（山西）平顺天台庵 |
| 硬山顶 | 两坡，山墙齐檐不悬出 | 明清北方民居、防火要求高处 | （山西）平遥古城民居、王家大院等晋商大院 |
| 攒尖顶 | 锥形/多角收于宝顶 | 亭、塔、坛庙中心建筑 | （山西）应县木塔（八角）；（北京）天坛祈年殿；（北京）颐和园诸亭 |
| 卷棚顶 | 两坡而无正脊，脊部圆弧 | 园林、行宫、次要建筑 | （江苏）苏州园林厅堂；（北京）行宫园林常见 |

另有重檐（重檐庑殿、重檐歇山等）抬高体量与等级；盔顶、盝顶等相对少见。

### 平面与开间

* **开间（面阔）**：沿面宽方向柱距形成的间数；明间最宽，次、梢、尽间依次。奇数开间为常，强调中轴对称。
* **进深**：沿进深方向的间数或架数；与梁架跨度、步架安排直接相关。宋式常论几架椽（如八架椽屋），与前后檐柱、内柱划分槽（前槽、后槽、内槽）相连。
* **廊与副阶**：周围廊、前后廊、卷棚抱厦等；**副阶周匝**为殿身外加一圈较低廊檐，平面扩大而殿身柱网可保持规整。著名实例：（山西）晋祠圣母殿。
* **柱网变通**：标准满堂柱网之外，可用**减柱造、移柱造**开敞室内或避让像设（详见构架节）。

清式又分**大木大式**（多用斗栱，殿堂官式）与**大木小式**（多无斗栱，住宅厅堂等）。

### 组群与院落

单体很少孤立存在。典型逻辑是：

* **中轴对称**：前朝后寝、左祖右社一类礼制布局
* **院落递进**：层层院落控制纵深与私密等级
* **廊庑连属**：殿—廊—门—厢形成可游可居的空间连续体

园林则打破严整轴线，以曲折、对景、借景组织视线，但单体本身仍常遵守官式或地方做法。常见手法：**抑景**（先抑后扬）、**借景**（借入园外山塔）、**框景**（门窗洞取景）、**漏景**（漏窗透景）、**对景**（轴线或转折处互望）。

### 礼制等级（速记）

形制背后是身份制度，观察时可作“配色与屋顶对照表”：

| 要素 | 大致等级梯度（越高越尊） |
| :--- | :--- |
| 屋顶 | 重檐庑殿 > 重檐歇山 > 单檐庑殿 > 单檐歇山 > 悬山/硬山 > 卷棚 |
| 开间 | 十一、九、七、五、三间递减（宫殿主殿可达十一间） |
| 琉璃色 | 黄 > 绿 > 蓝/黑等；民居不得擅用黄琉璃 |
| 台基 | 多层汉白玉须弥座 + 丹陛 > 普通砖石台基 |
| 彩画 | 和玺 > 旋子（又分金线大点金等）> 苏式 |
| 门钉 | 路数与枚数受限；最高如九路九九之制 |
| 斗栱 | 出跳多、用昂、用材大 → 等级高；清式攒数、踩数亦分级 |

《营造法式》《明会典》《清会典》与工程做法则例层层规定“准用/禁用”。地方寺庙、晋商大院常“越礼”用琉璃、彩画，读实物时要区分**官式规制**与**地方僭越/特许**。

## 构架

中国木构的本质是：**梁柱承重，墙体围护**。墙塌屋不塌，平面与立面因而具有极大灵活性。

### 传力路径

简要路径可记为：

**屋顶荷载 → 椽 → 檩（桁）→ 梁（或梁—斗栱）→ 柱 → 础 → 台基/地基**

* **柱**：檐柱、金柱、中柱等；柱有收分、侧脚（下端略外撇），增强稳定感与抗震冗余。
* **梁**：清式常按所承檩数称九架梁、七架梁等；梁上可叠瓜柱、短柱以承上层梁檩。
* **枋**：联系柱头、稳定构架（额枋、平板枋、穿插枋等）。
* **檩/桁**：有斗栱之大木清式多称桁；无斗栱称檩。
* **椽**：飞椽（飞子）使出檐更远、檐口更轻盈。
* **叉手、托脚**：早期屋架常见——叉手在脊槫两侧斜撑，托脚在平槫下斜撑；宋以后官式逐渐减少，是断代细部之一。
* **普拍枋**：柱头之上、斗栱之下的通长枋；唐构多无，辽宋以后普及，使柱头连成一体，也改变立面横向线条。

### 侧脚与生起

* **侧脚**：檐柱柱脚略向外撇（柱头内收），四面墙面微倾，增强构架稳定，并造成立面“下舒上敛”的视觉。
* **生起**：由心间向角柱逐渐加高柱高，使檐口呈一抹生翘曲线，与屋顶举折共同形成飞动感。
* 二者在唐辽金实物上往往比明清官式更醒目；看立面时不要只盯斗栱，也扫一眼柱脚与角柱高差。

### 抬梁与穿斗

| 体系 | 逻辑 | 分布与观感 |
| :--- | :--- | :--- |
| 抬梁式 | 柱上架梁，梁上叠梁承檩，室内少柱 | 北方官式、大型殿堂；室内开敞 |
| 穿斗式 | 柱直接承檩，柱间以穿枋连系 | 南方民居、轻巧密集；用料较小 |
| 混合 | 厅堂抬梁、厢房穿斗等 | 各地常见折中做法 |

此外还有井干式（木墙承重，如部分藏羌、东北仓房）、干阑式（底层架空，湿热与防兽）等地域类型。

### 殿堂造与厅堂造

宋式大木在构架组织上常分两类（陈明达等据《营造法式》与实物归纳）：

| | 殿堂造 | 厅堂造 |
| :--- | :--- | :--- |
| 结构层次 | 柱网 + **铺作层** + 屋顶草架，层次分明 | 梁栿直接与柱交结，铺作与梁架咬合更紧 |
| 室内观感 | 常有平棋（天花），梁架部分隐蔽为草栿 | 多用彻上明造，梁架外露 |
| 内柱 | 内柱与外檐柱常等高，铺作层连续成水平网架 | 内柱常升高直接承檩，柱高不等 |
| 典型 | 高等级殿宇 | 厅堂及部分殿宇变体 |

**铺作层**是理解唐宋结构的关键：一圈柱头枋与梁栿交织成井字水平框架，斗栱是交叉节点的加强件——故斗栱不只是“挑檐花边”，而是整层构架的一部分。

### 减柱造与移柱造

二者都是对**标准柱网**的变通，目的多为扩大礼拜/集会空间、避让像设与礼制轴线，辽金元华北实例尤多。

#### 减柱造

* **含义**：按规矩应有的内柱被减去若干根，荷载改由大内额、大梁或特殊梁架传递。
* **效果**：室内少柱或无内柱，空间通敞；梁跨加大，用料与节点要求更高。
* **常见手法**：减前内柱、减后内柱、只留中柱一列等；佛殿常减前槽金柱，使佛坛前空间开阔。
* **结构代价**：剪力与弯矩集中，需粗壮内额、大丁栿、扎牵等配合；后期修缮中常见加固痕迹。

<img src="https://raw.githubusercontent.com/YukinoshitaSherry/qycf_picbed/main/img/20260731132153290.png"/>




#### 移柱造

* **含义**：内柱并不取消，但**柱位偏离**外檐柱的纵向或横向轴线（前后移或左右错位）。
* **效果**：柱网与梁架不再严格对位，可让出佛道像、塔心、礼佛通道，或迁就上层楼阁柱网。
* **与减柱的关系**：可单独出现，也可与减柱并用；移柱使梁架出现斜栿、大爬梁、不对称步架等“非常规”节点。

> [!NOTE]+ 观察提示
>
> - 先在平面上画出“应有柱网”，再对照室内实柱，才能判断减/移
> - 辽金元寺院大殿（山西、河北一带）是减柱、移柱的富矿
> - 明清官式趋于规整，减移不如前代大胆，但地方做法仍可见

相关变通还有：**大额承重**（粗内额代柱）、**叉柱造 / 缠柱造**（楼阁上层柱与下层铺作的衔接，见平坐）、**副阶周匝**（殿身外加一圈廊柱，扩大平面而不改殿身柱网）。

### 平坐

楼阁、木塔层与层之间，常向外挑出一圈平台，宋称**平坐**。

* **作用**：形成游廊式平座、转换上下层柱网、加强水平刚度；平坐铺作宜重栱、逐跳计心（法式有专条）
* **铺作**：常减上屋一跳或两跳；下用**普拍枋**
* **叉柱造**：上层柱根叉于下层栌斗之上
* **缠柱造**：上层柱包在下层柱外，角上用多枚栌斗（法式：每角可见三枚一类做法）
* **实例**：（山西）应县木塔各层平座；（天津）独乐寺观音阁暗层与平座逻辑

无平座的多层建筑则靠墙体、砖石或其他方式分层，木构“明层 + 暗层 + 平坐”是理解辽宋楼阁的钥匙。

### 模数与权衡

#### 宋式：材、栔、分

《营造法式》：**“凡构屋之制，皆以材为祖。”**

* **材**：断面高∶厚 = 15∶10（即高十五分、厚十分）；一“分”是该等材高度的 1/15
* **栔（契）**：高六分、厚四分；材上加栔为**足材**（高 21 分），栱眼内隐出者称闇栔
* **单材 / 足材**：补间华栱常用单材；柱头华栱等多用足材

八等材与适用规模（尺寸为宋尺）：

| 等第 | 广（高）× 厚 | 一分约合 | 主要用途 |
| :--- | :--- | :--- | :--- |
| 一等 | 9寸 × 6寸 | 6分 | 殿身九至十一间 |
| 二等 | 8.25寸 × 5.5寸 | 5.5分 | 殿身五至七间 |
| 三等 | 7.5寸 × 5寸 | 5分 | 殿身三至五间，或堂七间 |
| 四等 | 7.2寸 × 4.8寸 | 4.8分 | 殿三间、厅堂五间 |
| 五等 | 6.6寸 × 4.4寸 | 4.4分 | 小三间殿、大三间厅堂 |
| 六等 | 6寸 × 4寸 | 4分 | 亭榭、小厅堂 |
| 七等 | 5.25寸 × 3.5寸 | 3.5分 | 小殿、亭榭 |
| 八等 | 4.5寸 × 3寸 | 3分 | 藻井、小亭榭铺作多者 |

副阶、挟屋材分常减殿身一等，廊屋再减——等级通过**材等**层层下落。屋宇高深、构件长短、举折曲直，皆以所用材之“分”为制度。

#### 清式：斗口

* **大式**：以坐斗开口宽为**斗口**，分十一等（约 1 寸至 6 寸，每 0.5 寸一等）
* **攒当**：两攒斗栱中距常取 11 斗口；每跳出挑约 3 斗口
* **小式**：多无斗栱，以檐柱径为权衡（如柱高约 11 倍柱径等经验比例）

模数制度使整座建筑比例可自斗栱或柱径“生长”出来，类似西方柱式以柱径定比例。

## 斗栱

斗栱（枓栱）是柱与梁/檐交接处，由**斗**（方形木块）与**栱**（弓形短木）层叠出挑的节点构件，也是中国木构最具辨识度的“文法单元”。宋称**铺作**，清称斗栱（计攒）；读唐宋文献与实物时，宜统一用“铺作”思维。

### 功能

1. **结构**：加大出檐，减小梁柱交接处剪力；唐宋时参与水平框架（铺作层）整体拉结
2. **模数**：栱广/斗口作为整座建筑的尺度基准
3. **等级与装饰**：出跳层数、杪昂组合、计心与否、彩绘复杂度标志建筑等级；明清后结构作用减弱、装饰性增强

### 受力

斗栱不是“托在柱上的花边”，而是**传力与悬挑节点**。可从竖向、水平、出檐三线理解：

#### 竖向传力

**屋面荷载 → 椽 → 檩/橑檐方 →（令栱、耍头）→ 层层栱、斗 → 栌斗 → 柱 → 础 → 台基**

* 每一层**栱**把荷载分到两端的**斗**上，斗再传到下一层栱或柱头，避免单点压裂
* 榫卯咬合：屋面压得越紧，节点越咬合；地震等水平扰动时，构件可微滑、摩擦耗能，整朵不易瞬间散架
* **计心**造因跳头有横栱与素方，竖向刚度与整体性通常强于同跳数的**偷心**造；偷心则更突出出跳悬挑、横向联系较弱

#### 出檐与真昂（杠杆）

* 华栱（杪）层层平出，把檐口挑到柱中线以外，使墙少淋雨、阴影加深
* **真昂**：斜置长木，外端承挑檐，里端（昂尾）伸入屋内压在梁枋或平槫之下——外向下、内向上，近**杠杆**：屋内压重帮助平衡外檐悬挑
* **假昂**：只雕成昂嘴外形，实际仍近乎平出构件，杠杆作用大减甚至消失（明清常见）
* 出跳越多、出檐越远，檐口弯矩越大，故早期用硕大材分与真昂；后期出檐收敛、斗栱缩小，受力需求下降，装饰比重上升

#### 水平与铺作层

* 一圈柱头枋、梁栿与各朵斗栱交叉，构成**铺作层**水平井字网：抵抗扭转、把相邻柱头拉齐
* 转角铺作、斜栱等还参与角部空间传力；楼阁、木塔的平坐铺作则兼作层间“圈梁”式加强

> [!NOTE]+ 读剖面时的受力意识
>
> 外跳看谁在挑檐（杪还是真昂），里跳看昂尾压在何处；有无横栱（计/偷）决定这层是“悬挑为主”还是“拉结成网”。明清小斗栱梁压最上跳，传力路径变短、变直接，斗栱本身承担的结构份额已大不如唐宋。

### 基本用语

* **栌斗（坐斗、大斗）**：柱头最下承托整朵铺作；宋式栌斗方约 32 分，高 20 分（耳—平—欹）
* **华栱**(杪)：垂直屋面方向出跳之栱（又称杪栱、卷头、跳头）；清称**翘**
* **横栱**：平行屋面——泥道栱、瓜子栱、令栱、慢栱等
* **昂**：斜置构件；**下昂**外跳真昂有杠杆作用，**上昂**用于里跳或平坐；晚期多假昂（雕成昂嘴）
* **交互斗、齐心斗、散斗**：分置跳头、栱心、栱端
* **耍头（爵头）**：与令栱相交，承撩檐方一带
* **出跳 / 踩**：向外（或向里）挑出的层次；清式称几踩
* **柱头铺作 / 补间铺作 / 转角铺作**：位置分类

### 铺作计算

#### 铺作数与出跳数

《营造法式·总铺作次序》：

> 自柱头上栌斗口内出一栱或一昂，皆谓之一跳；传至五跳止。

换算口诀：

**铺作数 = 出跳数 + 3**

（“3”可理解为：栌斗 + 耍头/要头一层 + 撩檐一层等计数习惯；实务上直接记表更稳。）

| 出跳 | 铺作名 | 法式典型杪昂组合（外跳示意） |
| :--- | :--- | :--- |
| 1 | 四铺作 | 一跳；或华头子上出一昂 |
| 2 | 五铺作 | 下一杪 + 上一昂 |
| 3 | 六铺作 | 一杪两昂，或两杪一昂 |
| 4 | 七铺作 | 两杪两昂 |
| 5 | 八铺作 | 两杪三昂 |

描述一朵铺作时，习惯连写结构特征，例如：

**“七铺作双杪双下昂，下一杪下一昂偷心，上一杪上一昂计心”**

即：总出四跳；两跳用华栱（杪）、两跳用下昂；下两跳偷心、上两跳计心。

#### 出跳长度（心）

* 每跳心长**不过 30 分**；传跳虽多，出跳总心长**不过 150 分**
* 角华栱、角昂按斜长加；厅堂里跳承梁出㭼头（压跳）可加长一跳
* 铺作数多时，里跳可减一铺或两铺，以免里跳过远、室内压抑

#### 补间铺作布置（法式）

* 当心间补间**两朵**，次间及梢间各**一朵**；分布令远近皆匀
* 若逐间皆双补间，则各间面阔宜相近；仅心间双补间时，心间与次间面阔可成比例（法式举例心间一丈五、次间一丈一类）
* 转角铺作勿与补间相犯；梢间过近可连栱交隐，或于次角补间减跳

#### 单栱造与重栱造

| | 单栱 | 重栱 |
| :--- | :--- | :--- |
| 做法 | 跳头令栱上只用素方一重 | 跳头瓜子栱上加慢栱，再上素方 |
| 材栔 | 每跳约两材一栔 | 每跳约三材两栔 |
| 观感 | 横线较疏 | 横线更密、铺作层更厚重 |

扶壁栱（影栱）在柱头壁上：全计心重栱造时，泥道重栱上施素方；若下跳偷心，扶壁做法随铺作数另有配套（法式对五至八铺作偷心时的泥道/令栱/素方组合有专条规定）。

#### 清式踩数对照

清式以**踩**计（从柱头科中线计两边横栱列数的习惯说法，与宋铺作计数不同）：

* 三踩 ≈ 出一跳量级；五踩、七踩、九踩递增
* 口诀粗换：**踩数 ≈ 2 × 出跳数 + 1**（便于与宋式对照，细部以实测为准）
* 清式梁常压在最上一跳之上，斗栱尺度缩小，真昂少见

### 计心造与偷心造

《营造法式》定义：

* **计心**：逐跳之上（下昂之上亦同）**安横栱**
* **偷心**：逐跳之上**不安横栱**，而再出跳或出昂

南中工匠口语：出一跳曰“出一枝”，计心曰“转叶”，偷心曰“不转叶”。

<img src="https://raw.githubusercontent.com/YukinoshitaSherry/qycf_picbed/main/img/20260731132929612.png"/><img src="https://raw.githubusercontent.com/YukinoshitaSherry/qycf_picbed/main/img/20260731133038585.png"/><br>

| | 计心造 | 偷心造 |
| :--- | :--- | :--- |
| 跳头 | 有瓜子栱/令栱等横栱 | 无横栱，华栱或昂上仅坐交互斗/散斗再出 |
| 结构作用 | 横栱 + 素方把各朵铺作连成整体，形成铺作层 | 突出悬挑，横向联系较弱，用材相对经济 |
| 时代倾向 | 宋以后渐增；明清官式以全计心为主 | 唐至元常见；与计心混合使用极多 |

**全计心**：每一跳跳头皆有横栱。  
**全偷心**：各跳皆不设横栱（早期、小型或特定位置更常见）。

#### 跳间偷心造（偷心与计心的组合）

实物与法式图式中，最常见的并非“全偷”或“全计”，而是**下跳偷心、上跳计心**——即所谓跳间（隔跳）偷心：只在部分出跳层级省略横栱。

法式图样与总铺作次序中的典型配套（外跳）：

| 铺作 | 杪昂 | 常见偷心/计心分配 |
| :--- | :--- | :--- |
| 五铺作 | 一杪一昂 | 下一杪偷心，一昂计心 |
| 六铺作 | 一杪两昂 | 一杪偷心，两昂计心 |
| 六铺作 | 两杪一昂 | 下一杪偷心，上一杪与昂计心 |
| 七铺作 | 两杪两昂 | 下一杪、下一昂偷心；上一杪、上一昂计心 |
| 八铺作 | 两杪三昂 | 下两杪（及部分昂）偷心，最上昂计心 |

> [!INFO]+ 为何下偷上计
>
> 下层偷心减少横向构件干扰，利于真昂斜杀与出檐悬挑；上层计心用横栱—素方收住外檐，并把相邻铺作拉齐，兼顾悬挑效率与整体性。读剖面时先数跳，再逐跳看有无横栱，即可判断。

骑斗栱宜单用，其下跳并偷心造——局部节点亦强制偷心。

唐辽金实物可与此对照：

* **（山西）南禅寺大殿**：五铺作双杪，偷心
* **（日本）唐招提寺金堂**（存唐风）：六铺作双杪单下昂，偷心

#### 例：佛光寺东大殿（山西，唐 857，国保）

梁思成所称“中国第一国宝”级木构殿堂。外檐柱头铺作可写成完整描述：

**七铺作 · 双杪双下昂 · 跳间偷心**（下杪、下昂偷心；上杪、上昂计心）

逐项拆开：

| 步骤 | 怎么读 | 东大殿对应 |
| :--- | :--- | :--- |
| 1. 数出跳 | 外跳几层挑出 | 四跳 → 铺作数 = 4 + 3 = **七铺作** |
| 2. 杪还是昂 | 出跳用华栱还是下昂 | 下两跳为**华栱（双杪）**，上两跳为**下昂（双下昂）** |
| 3. 计心/偷心 | 每跳跳头有无横栱 | **下一杪、下一昂偷心**；**上一杪、上一昂计心** |
| 4. 观感核对 | 斗栱高与柱高比、出檐 | 斗栱雄大（常言约占柱高四成量级）、出檐极深远，真昂杠杆清晰 |

口诀可记：**出两个卷头（杪）+ 两个昂嘴 = 四跳；再加栌斗与耍头一层等，称七铺作。** 转角铺作另出**由昂**。补间铺作相对柱头为简（唐构补间常少而弱），与辽宋以后密布补间对比鲜明。

殿内还有内柱铺作（如偷心多跳一类），与外檐共同组成铺作层；梁架、唐塑、壁画、题记合称“四绝”，证明年代。读斗栱：先站在檐下侧视数跳，再仰看跳头有无横栱，即可自行写出上面那句术语。

> [!EXAMPLE]+ 与南禅、镇国对照
>
> | 实例 | 时代 | 开间 | 铺作大意 | 读点 |
> | :--- | :--- | :--- | :--- | :--- |
> | **南禅寺大殿** | 唐 | 三间 | 五铺作双杪，偷心 | 小殿配小铺作，比例贴合；认“跳”与“偷心”入门 |
> | **佛光寺东大殿** | 唐 | 七间 | 七铺作双杪双下昂，跳间偷心 | 大殿配大铺作；认杪昂组合 + 下偷上计 + 真昂 |
> | **镇国寺万佛殿** | 五代北汉 | 三间 | 亦用**七铺作**（高等级），斗栱极硕 | 小殿却套用近乎大殿级铺作，斗栱高与柱高比惊人（常言近半），唐风余绪、比例近“失调的豪劲”；补间仍偏少，处在唐→宋补间加密之前的过渡 |
>
> 路线建议：南禅认术语 → 佛光寺认完备唐构 → 镇国寺看“体量小而铺作大”的五代唐风；再去辽金、明清看斗栱如何缩小变密。

#### 例：镇国寺万佛殿（山西平遥，五代北汉，国保）

与南禅同为**三开间**小殿，却外檐柱头采用**七铺作**级铺作，斗栱雄大、出檐深远，被视作唐风在五代的重要遗响。无内柱、彻上明造；补间铺作相对柱头仍简（当心间虽面阔拉大，补间朵数仍少），不同于北宋以后常见的双补间密布。

对照读法：

* 对**南禅**：同是小殿，南禅五铺作比例“合身”，镇国七铺作“过大”——可见铺作等级不仅随开间，也随时代审美与对唐制的追摹
* 对**佛光寺**：同属七铺作系统，佛光寺铺作与七间殿堂体量匹配；镇国则是把高等级铺作“套”在三间殿上，更易一眼感到斗栱压倒屋身
* 受力观感：硕大铺作 + 深远出檐，仍是悬挑与真昂逻辑；小殿用大铺作，结构冗余与表现性都偏强

#### 例：应县木塔（山西，辽清宁二年 1056，国保）

全称佛宫寺释迦塔，现存最高、最古之木构佛塔。斗栱在此不是殿檐一圈，而是**整座高层的节点系统**。

* **总貌**：八角；外观五层六檐（底层重檐），明层之间夹**暗层**，实为**九层**（五明四暗）；通高约 67 米；顶为八角攒尖加铁刹
* **套筒**：每层内外两圈柱（外槽、内槽），形成双层套筒，利于抗侧
* **平坐**：各明层外有平座勾栏可绕行；暗层梁枋、斜撑密布，近乎“圈梁”，加强层间刚度
* **斗栱**：全塔用斗栱种类极多（常称五十余种），柱头、补间、转角、平坐各有变化，有“斗栱博物馆”之称；底层铺作最硕，向上收分、铺作相对减等
* **与殿堂的读法差异**：殿堂一朵铺作读完即可；木塔要分层看——明层出檐铺作、平坐铺作、暗层内部撑拉——同一套计心/出跳术语，重复叠高九次

寺平面仍保留塔在山门与大殿之间的古制。现场若不能登临，至少绕塔看底层重檐斗栱与平座出跳，再仰看收分与攒尖轮廓。

### 昂、耍头与里跳

* **下昂**：外跳斜下，昂身可伸入屋内抵平槫；有批竹昂、琴面昂等面处理；昂下常用华头子承托第一昂
* **插昂（矮昂）**：四铺作等处斜随跳头的短昂
* **上昂**：用于里跳之上及平坐内，与下昂方向逻辑不同
* **由昂**：转角角昂之上再出一昂，以坐角神
* **挑斡**：彻上明造时，以斜木挑承里跳，或挑一斗，或挑一材两栔
* **里跳减铺**：铺作数多则里跳减一至两铺，或于平棋方下加慢栱

### 演变简谱

#### 形制与角色

* **汉—南北朝**：斗栱逐渐从柱上支承构件发展，图像与明器可见早期形态
* **唐—元**：斗栱与梁架、柱头枋交织成铺作层；出檐深远，真昂与偷心/跳间偷心常见；补间铺作由少（唐常每间 0–1 朵）增多（辽宋金可达双补间）
* **明—清**：梁常压在斗栱最上一跳之上，斗栱尺度缩小，真昂少见，全计心与标准化加强；清式以斗口模数严密控制攒当与出踩

#### 尺度大小

读立面时，最醒目的往往不是“有没有斗栱”，而是**斗栱相对柱高、出檐相对进深有多大**：

| 阶段 | 斗栱相对尺度 | 出檐 | 结构角色 | 对照实物 |
| :--- | :--- | :--- | :--- | :--- |
| 唐 | 极大；铺作高常达柱高约 1/2～2/5 量级 | 极深远 | 传力 + 悬挑主角 | 南禅（小而合身）、佛光寺（大而匹配） |
| 五代 | 仍喜硕大；小殿可套高等级铺作 | 深 | 唐风延续 | **镇国寺万佛殿**（三间而七铺作） |
| 辽金 | 柱头仍硕；补间加密、种类变多 | 深 | 铺作层发达 | 独乐寺、华严寺、应县木塔 |
| 宋 | 材分制度化；权衡趋于醇和 | 仍深而更规范 | 结构与制度并重 | 晋祠圣母殿；法式图样 |
| 元 | 地方与官式并行；有减移大胆者 | 不一 | 过渡 | 永乐宫等 |
| 明—清 | **显著缩小**，密集成檐下“花边” | 相对收敛 | 装饰与等级标识为主，真昂少 | 故宫官式；对比唐辽一目了然 |

总趋势可记：**由大而稀、结构性强 → 由小而密、装饰性强**；补间从几乎没有到每间一朵再到双补间，是另一条平行线索。豪劲 / 醇和 / 羁直的风格分期，很大程度就写在斗栱大小与真假昂上。

> [!INFO]+ 看实物时的速判
>
> - 斗栱硕大、出檐远、真昂明显、多偷心或跳间偷心 → 偏唐辽金（镇国寺亦属此路）
> - 斗栱细密如花边、出檐相对收敛、全计心 → 多明清官式
> - 先数外跳，再标每跳计/偷，再看杪还是昂 → 可写出完整铺作描述
> - 三间殿却七铺作、斗栱“大得夸张” → 优先想到镇国寺一类五代唐风
> - （山西）应县木塔、佛光寺东大殿、镇国寺万佛殿、晋祠圣母殿，可串成唐→五代→辽→宋的铺作课

## 屋檐

屋檐解决排水、遮阳与立面轮廓。中国屋顶曲线（“如鸟斯革，如翚斯飞”）来自举架/举折与翼角起翘的共同作用。

### 举折与举架

* **举折（宋）**：先定脊槫高度（举屋），再逐缝“折”下各中平槫，使屋面呈凹折曲线，利于排水并形成柔和轮廓。《营造法式》举屋之法大致按前后橑檐方心距取一定比例定脊高，再按架数折之。
* **举架（清）**：按步架深的百分比逐层加高——如檐步五举（步架深的 50%）、金步七举、脊步九举等，效果与举折相近而算法不同。

<img src="https://raw.githubusercontent.com/YukinoshitaSherry/qycf_picbed/main/img/20260731133515355.png"/><img src="https://raw.githubusercontent.com/YukinoshitaSherry/qycf_picbed/main/img/20260731133635329.png"/><br>

檐口常有**飞椽**（飞子），使檐端更薄、更远。出檐深度与铺作出跳、飞椽长度直接相关：唐宋深出檐往往对应硕大铺作与真昂。

### 翼角

转角屋顶的起翘由角梁系统完成：

* **老角梁、仔角梁**（清式常用名）：斜向伸出，仔角梁在上更冲出
* **由戗**：屋面斜脊下的支撑构件
* **角神、套兽**：角梁端饰
* **南北差异**：官式北方翼角相对平缓；江南发戗冲得更高更飞，有水戗发戗等地方做法
* 翼角曲线与正身屋面举折、生起叠加，才是“如翚斯飞”的完整来源

### 瓦作

* **筒瓦、板瓦**：官式殿堂多用筒板瓦；琉璃瓦按颜色与剪边体现等级（黄琉璃等级最高）
* **沟头、滴水**：檐口排水构件，兼装饰
* **屋脊**：正脊、垂脊、戗脊（岔脊）构成屋顶骨架线，也是安放吻兽、走兽的位置

<br>

## 鸱吻与脊兽

屋脊装饰既是防水收头与压脊构件，也是等级与祥瑞象征。

### 正脊与鸱吻

* **鸱尾 / 鸱吻 / 螭吻**：正脊两端大物。早期多作鸱尾上扬；后世常见张口吞脊的吻兽，传说与防火厌胜有关（鱼龙、蚩尾能克火等说法历代不一）。
* 明清宫殿正脊吻体量大、工艺复杂，是远观轮廓的点睛。
* **（山西）大同华严寺大雄宝殿**：辽金巨构，正脊鸱吻极为硕大（常称高约四米余），远望即成屋顶轮廓的标志；与（天津）独乐寺山门等早期鸱尾对照，可见辽金吻饰追求体量与气势的一路。读脊饰时，华严寺大雄宝殿是山西境内最醒目的国保标本之一。

### 垂脊走兽（清式常见序列）

清式垂脊走兽自下而上（近檐角处起）有固定秩序，数量为奇数，多寡对应建筑等级。常见记忆序列：

**龙、凤、狮子、天马、海马、狻猊、押鱼、獬豸、斗牛、行什**

最前端常有**骑凤仙人**（或垂兽前的仙人）领队。（北京）故宫太和殿可用满数（含行什），一般建筑递减。

### 其他脊饰

* **正吻、合角吻、宝顶**：攒尖顶收于宝顶
* **垂兽、戗兽**：垂脊、戗脊端部
* **跑兽、套兽**：角梁端等位置的防护与装饰

等级越高，脊饰越完整、用料越考究（琉璃相对灰陶）。

## 台基与栏杆

台基是“三段式”的底座，既防潮排水，也抬高体量以示尊崇。

### 台基本体

* **普通台基**：素土/砖石砌筑，民居与一般殿宇最常见
* **须弥座**：束腰、叠涩线脚，来自佛座形式；宫殿重要殿座多用**汉白玉**须弥座，如（北京）故宫三大殿，洁白硕大，本身即等级信号
* **月台**：殿前宽阔平台，礼仪与活动空间；高等级殿宇月台可层层叠涩，与丹陛相连

### 踏跺（台阶）

宋称**踏道**，清称**踏跺**，是台基与地面之间的台阶系统，形式直接反映礼制等级。

| 类型 | 特征 | 常见场合 |
| :--- | :--- | :--- |
| **垂带踏跺** | 两侧有垂带石（斜置条石），踏步夹在中间；最常见的“正规”台阶 | 宫殿、庙宇、厅堂普遍 |
| **如意踏跺** | **不做垂带**；踏步可沿左、中、右三面上下。正面看常层层缩短、侧面呈齿状退进，远看一圈圈收上去 | （江苏）苏州园林、民居、人流较活的入口；等级相对灵活、姿态亲切 |
| **云步踏跺** | 用天然石块不规则叠成，如云朵错落 | 园林山池边，求山林意趣 |
| **御路踏跺** | 在垂带踏跺正中加一条缓坡石道（不供人走） | 宫殿、高等级寺庙 |

#### 丹陛、御路与陛石

帝王宫殿正殿前的台阶礼仪系统常统称**丹陛**（殿阶；殿前丹漆/朱红礼仪空间亦与**丹墀**相关）。

* **御路（辇道）**：踏跺正中那条斜置巨石坡道，表面多雕龙戏珠、山海云气；象征御驾通道，**人不得行**，两侧才是臣僚上下的阶齿
* **陛石**：铺砌御路的那块（或那几块）石材；宫殿多用**汉白玉**（或贵重大理石），是石作等级最高的用法之一
* **御路踏跺**：御路 + 两侧踏跺的整套组合；（北京）故宫太和殿、保和殿等前可见多层汉白玉丹陛叠起，气势最完整

> [!NOTE]+ 园林里的如意踏跺
>
> （江苏）苏州园林常见的、不设垂带、三面可上、台阶一圈圈收进的，就是**如意踏跺**；若故意用自然石随意叠放，则近**云步**。与宫殿汉白玉丹陛对照：一为礼制威仪，一为可游可憩。

另有**礓礡**（斜面凿防滑横纹，如搓板）、高台前的长坡**慢道**、（陕西）唐大明宫含元殿一类分层折转的**龙尾道**等，属台基交通的延伸类型。

### 栏杆

栏杆（钩阑）有望柱、寻杖、栏板；宋式与清式样式不同，可作断代参考。宫殿汉白玉栏板常与丹陛、须弥座连成一套石作语言。

## 装修与色彩

“装修”在古建术语中多指门窗隔扇、栏杆、天花藻井等**非大木承重**的小木作及油饰彩画，而非现代室内装修之意。绪论所谓“玲珑木质之屋身”，正面观感大半由门窗装修决定。

### 门窗

门窗属小木作，兼出入、采光、通风、防卫与**礼制标识**。板门偏防卫与等级门面；隔扇、槛窗偏通透与室内外连续；合院中的**垂花门**则划分内外宅空间。

#### 门的类型

| 类型 | 特征 | 常见位置 |
| :--- | :--- | :--- |
| **板门** | 厚板拼合，实心厚重；多安门钉、铺首 | 宫门、庙门、宅门、城门洞内大门 |
| **隔扇门**（槅扇） | 格心透光 + 裙板；可拆可装，成排安装于柱间 | 殿堂明间、厅堂、园林花厅 |
| **屏门** | 多为固定或可卸之屏障，不主出入 | 垂花门内侧、室内遮挡视线 |
| **垂花门** | 檐下有不落地之**垂花柱（垂莲柱）** | 合院二门，分隔外宅与内宅 |
| **乌头门 / 棂星门等** | 牌楼式或仪门变体 | 坛庙、学宫、寺院前导 |

#### 板门构件

自上而下、由框到扇，常见一套：

* **门框 / 门楣**：框定洞口；上框一带可承门簪、连楹
* **门槛（阈、门坎）**：框下横木或石条，分内外、挡风沙虫鼠；高度常含身份意味。礼制上出入多**不践阈**（不踩门槛）
* **门簪**：穿出门头如簪，固定连楹，兼装饰；二至四枚不等，可雕花或刻“吉祥”等字。俗语“门当户对”中，**户对**常指门簪（对数、形制），**门当**多指门前石墩一类
* **门枕石 / 门墩**：门槛两侧承门轴；外侧雕饰者常做成**抱鼓石**（鼓形），内侧为枕门扇之石
* **门扇**：多板拼合，后有穿带；前露**门钉**加固钉帽
* **铺首衔环**：兽面（或素面门钹）为底座曰**铺首**，口中衔环（或叶状片）供拉门、叩门；合称铺首衔环
* **余塞板、走马板等**：门洞两侧或上部封板，补足柱间空档

#### 门钉

* 本为固定门板与穿带的结构钉，钉帽做成蘑菇状（宋或称浮沤钉），后成横竖成行的装饰与等级符号
* 质地有铁、铜、木、石等；宫门明清多见鎏金铜钉，朱扉金钉
* **清制大意**（以会典一类记载为准，实物偶有变通）：
  * 宫殿门庑：纵横各九（九九八十一）为极尊
  * 亲王府：纵九横七
  * 世子、郡王至辅国公等：递减（如减亲王七之二一类规定）
  * 公侯以下再减，材质亦降（铁钉等）
* 民居原则上不得僭用宫府门钉之制；庙宇、地方做法须对照时代与重修层

#### 铺首衔环

* 铺首多兽面，有镇宅闭藏之意；民间亦用圆形素面**门钹**
* 环为拉手兼叩门“响器”；院内人拉环闭门，外来人扣环传声
* **等级重在漆色与环材**（明制记载大意）：亲王府丹漆金钉铜环；公侯金漆兽面锡环；品官依品用绿油/黑油及锡环、铁环等——读门面时与门钉、门色一并看

#### 垂花门与垂花柱

* **垂花门**：合院轴线上常见“二门”，划分外宅（接待、下人、轿马）与内宅（起居、女眷）；旧所谓“大门不出，二门不迈”之“二门”即此
* **垂花柱 / 垂莲柱**：前檐（或前后）柱不落地，短柱悬于麻叶梁头之下，柱头雕莲瓣、花苞、石榴头等，故名。宋《营造法式》有“虚柱”“虚柱莲华蓬”一类做法，渊源更早
* 形制有一殿一卷、单卷棚、独立柱担梁、廊罩式等；朝外一面雕饰、彩画、抱鼓石往往最盛，朝内可装屏门以障景
* 功能：交通 + 分内外私密 + 点景障景；北京四合院与各地合院、园林中皆极常见

#### 隔扇

安装于柱间，可视为“可开启的装修墙”：

* 竖向**边梃**，横向**抹头**（清式常论几抹：六抹、五抹、四抹等，抹头越多越偏高等级或大体量）
* 上部**格心（花心）**：菱花、柳条、步步锦、灯笼框等棂格，决定通透度与装饰
* 中下**绦环板、裙板**：可雕花；园林落地明隔扇可减裙板以求通透
* 宫殿坛庙大体量多用五抹、六抹；一般寺观宅第四抹常见；宋多见三抹等较早做法

#### 窗

| 类型 | 特征 |
| :--- | :--- |
| **直棂窗** | 竖向直棂，早期与唐宋常见，朴素 |
| **槛窗** | 下砌**槛墙**，墙上安隔扇式窗扇，与隔扇门同一语言；官式殿宇、大型宅第庙宇多用 |
| **支摘窗** | 上扇可支起、下扇可摘下，调节通风；民居、园林极广 |
| **漏窗 / 空窗** | 墙上门洞式取景，园林框景、漏景常用（砖瓦什锦等） |

殿堂正面常“隔扇 + 槛窗”成排，形成绪论所说正面玲珑、少用厚墙开洞的观感；山墙则门窗常少。

#### 室内隔断

不承重、划分室内空间：

* **飞罩、落地罩、栏杆罩**：半隔断，限定空间而视线不断
* **太师壁、碧纱橱**：壁面或隔扇围合；碧纱橱常糊纱或安玻璃格心

> [!EXAMPLE]+ 读门面顺序
>
> 先辨板门还是隔扇/垂花门 → 看门槛与门枕抱鼓 → 数门簪、门钉路数 → 辨铺首材质与兽面 → 若是垂花门再仰看垂莲柱与一殿一卷屋面。合院中：大门（门面等级）→ 垂花门（内外宅）→ 正房隔扇（室内通透）。

### 室内顶棚

室内顶棚处理首先二分：

| 大类 | 含义 | 观感与用途 |
| :--- | :--- | :--- |
| **彻上明造**（彻上露明造） | 不装天花，梁架、檩椽直接外露 | 结构逻辑一目了然；厅堂、许多唐宋殿宇常用 |
| **有天花/藻井** | 梁架下另做顶棚，遮住草架 | 殿堂造常配合平棋；重点空间再凹入为藻井 |

《营造法式》把天花装修明确分为三类：**平闇、平棊（平棋）、藻井**。明清又发展出井口天花、海墁天花等清式说法。

#### 平闇（平暗）

* 以较小方木分格，上盖素板，格网较密、做法相对朴素
* 法式所谓“以方椽施素板者，谓之平闇”
* 遮挡草架为主，装饰性弱于平棋

<img src="https://raw.githubusercontent.com/YukinoshitaSherry/qycf_picbed/main/img/20260731133926723.png"/>

#### 平棋（平棊、平机、平橑）

* 梁下用桯、贴分成较大方格或长格，背上铺板，格内贴络花纹、彩画
* 俗亦称“平起”；棋盘状分格，一方格亦可称一“井”，但整体仍是**平面天花**，并不向上穹起
* 法式列举贴络华文多品：盘毬、斗八、叠胜、琐子、龟背、毬文等，并可于云盘、华盘内施**明镜**，或隐起龙凤、雕华
* 殿堂造有铺作层者，平棋往往正好托在铺作/梁格之下，把草栿隐藏于上

<img src="https://raw.githubusercontent.com/YukinoshitaSherry/qycf_picbed/main/img/20260731133945142.png"/>

读法提示：看见满顶方格天花板、中央无穹窿凹入 → 先判平棋（或清式井口天花），不要误叫藻井。




#### 藻井


##### 清式常见天花

* **井口天花**：支条纵横分井，井口内安天花板，绘团龙、团凤、花卉等——与宋平棋一脉，而名称、彩画程式已清式化
* **海墁天花**：不分井口，整片满画（如团花海墁、轱辘草等），或简化为纸裱、油漆满墁
* 高等级宫殿常井口天花 + 局部藻井并用：大面积井口，宝座/佛像上方单独凹入藻井

藻井是天花**向上凹进成穹窿状**的特殊处理，等级最高。罗哲文等概括：用于**寺庙主像上方**或**宫殿帝王宝座上方**。礼制上与“非王公之居，不得施重栱藻井”一类限制相关，不可滥用于常居。

**象征**：上圆下方、层层内收，象天；顶心明镜、莲花、蟠龙，强化“天人”与皇权/神权。名称或与古代穴居天井、以及“藻”饰压火等说法有关，诸说并存。

**宋式斗八藻井**（《营造法式》标准）：

自下而上三层——

1. **方井**：最下方形井口
2. **八角井**：中层
3. **斗八**：上层由八根角梁（阳马）聚向中心的八棱锥顶

顶心之下施**垂莲**或雕华云卷，内安**明镜**。另有**小斗八藻井**，多用于殿宇副阶等次要位置，高度与直径按法式另有减等。


<img src="https://raw.githubusercontent.com/YukinoshitaSherry/qycf_picbed/main/img/20260731134048782.png"/>

**形式演变与类型（观察用语）**：

| 类型/特征 | 说明 |
| :--- | :--- |
| 斗八 / 八角攒尖式 | 宋金常见；（天津）独乐寺观音阁木藻井为早期重要实例 |
| 方井套叠 | 层层方井套方井，北朝石窟平棋遗风在建筑中的延续 |
| 圆形 / 穹隆层层 | 明清宫殿寺观多见，层数与雕饰趋于繁密 |
| 八卦形 | 八边层叠，道教宫观尤喜 |
| 蟠龙藻井 | 顶心巨龙盘绕，如（北京）智化寺、（北京）故宫部分殿座，视觉焦点极强 |
| 螺旋 / 交错层叠 | 地方或晚期求变的穹隆做法 |

**与结构的关系**：藻井本身多为小木作装修，挂在梁架之下；其下有时另见斗栱、斜撑、角梁等装饰性或半结构性构件。殿内若中部升高、四周平棋环绕、中央凹入斗八，即“平棋 + 藻井”的经典组合。

##### 例：应县净土寺大雄宝殿（山西，金，国保）

俗称北寺，与应县木塔同城。大雄宝殿天花不是“只在明间挖一个井”，而是**三间殿顶几乎布满藻井**：梁架划分为九格，成**九井**；明间最大，作**斗八藻井**，正中木雕**双龙戏珠**；其余八角、六角、菱形等井形各异。井壁四周饰**天宫楼阁**小木作（八门九星一类格局），斗栱、楼阁镂刻极细，梁思成曾盛赞其构思精巧。金代小木作藻井的高峰标本——看完木塔的“大木斗栱”，进净土寺看“天花上的微缩宫殿”。

##### 例：故宫藻井（北京，明—清，国保）

宫殿藻井严格落在**帝座正上方**，与宝座垂直呼应，象征君权天授；清式常称“龙井”。

* **太和殿**：等级最高的**浑金蟠龙藻井**。下为方井、中为八角井、上为圆井（斗八逻辑的明清极致）；方井与八角交接处形成**角蝉**，雕龙凤云纹。顶心**蟠龙**口衔**轩辕镜**（宝珠），俯视金漆宝座——全称文献中有“龙凤角蝉云龙随瓣枋套方八角浑金蟠龙藻井”一类完整定名。
* **中和殿、保和殿**：中轴三大殿宝座上方皆有藻井，与太和殿同一礼制逻辑，体量与华丽程度随殿等略减。
* **养心殿等内廷**：亦多用蟠龙/龙井，规模小于外朝主殿，仍属帝居最高装修。

可与（北京）**智化寺**万佛阁等明代**蟠龙藻井**对照：同为龙井传统，故宫则把方井—八角—圆井与浑金、轩辕镜推到官式顶峰。

### 彩画

清式三大类（由尊到卑大致）：

| 类型 | 特征 | 使用 |
| :--- | :--- | :--- |
| **和玺** | 枋心龙纹（或龙凤），圭线如意头等；用金量大 | 宫殿主殿、最高礼制 |
| **旋子** | 旋花（圆形几何花）为主；又分金线大点金、墨线大点金、雅伍墨等档次 | 次要宫殿、官署、庙宇极广 |
| **苏式** | 包袱锦、人物故事、花鸟山水；写实趣味强 | 园林、住宅、南方影响下的殿座 |

梁枋分段常称：**箍头—藻头—枋心**。早期（唐辽）彩画遗存少，多赖洞窟、壁画与清以后重修层；看实物要分清**原构彩画**与**后世重绘**。

天花井口、藻井、斗栱、梁枋往往同一套彩画等级：殿内龙井、金龙和玺与汉白玉丹陛、黄琉璃屋顶一致，同属最高礼制配置。

柱、门常用丹红；连檐瓦口、椽飞或青碧；明清官式红墙黄瓦与青绿彩画对比强烈。油饰兼防腐。

### 墙、柱础与砖石建筑

* **墙**：木构中墙多为围护。硬山建筑山墙封至脊；南方封火山墙（马头墙等）高出屋面以防火。五花山墙露出叠梁断面，是硬山侧面的常见处理。
* **柱础**：防潮承柱。宋有覆盆等制度；清有鼓镜、磉墩。雕狮、莲瓣等纹样随等级与地区变化。
* **砖石专类**：
  * **塔**：见下节
  * **无梁殿**：砖券仿木构外观，如（江苏）南京灵谷寺无梁殿、（山西）太原永祚寺双塔寺无梁殿等
  * **城墙、长城、关堡**：夯土/包砖；敌台、瓮城、马面
  * **石桥、经幢、华表、石窟**：材料与木构并行的另一谱系

### 琉璃与砖石装饰

琉璃瓦、琉璃脊饰、砖雕、石雕（柱础、栏板、御路）构成材质层次。山西琉璃烧造传统深厚（晋南、太原一带），庙宇脊饰与（山西）广胜寺飞虹塔尤为可观。石窟壁画中的北朝、唐**平棋/藻井图案**（如（甘肃）敦煌），是理解木构天花纹样来源的重要旁证。

## 塔

塔随佛教传入，平面多方、六角、八角；材料有木、砖、石、琉璃及组合。

| 类型 | 特征 | 实例 |
| :--- | :--- | :--- |
| **楼阁式** | 可登临，层层有平座或腰檐，近木楼阁逻辑 | （山西）应县木塔（木）；（陕西）西安大雁塔（砖，经改建） |
| **密檐式** | 底层较高，其上密檐层层，一般不可登 | （河南）登封嵩岳寺塔（十二角砖塔，北魏）；（陕西）西安小雁塔；（北京）天宁寺塔 |
| **亭式 / 单层** | 单层亭状，上加顶 | （山东）济南四门塔（隋，石）等 |
| **花塔** | 塔身上半布满雕饰如花束 | （河北）正定广惠寺花塔等 |
| **覆钵式（喇嘛塔）** | 肚大颈粗，藏传形制 | （北京）妙应寺白塔；（山西）五台山部分塔院 |
| **金刚宝座塔** | 高台上五塔 | （北京）真觉寺（五塔寺）金刚宝座塔 |
| **琉璃塔** | 外壁琉璃构件 | （山西）广胜寺飞虹塔；（江苏）南京大报恩寺塔（历史名塔，已毁） |

木塔看铺作与平坐；砖石塔看仿木构件（斗栱、阑额隐刻）与收分。塔在寺院中的位置：早期多居中轴前部，如（山西）应县佛宫寺，后世常退至侧位或另成塔院。

## 风水与选址

风水（堪舆）是选址与布局的传统环境观，与礼制、防御、微气候经验缠绕在一起，不宜简单斥为迷信，也不宜全盘当作科学。

### 常见理想模式

* **背山面水**：后方有主山（靠山）为屏障，前方有流水或明堂开阔地；左右砂山环护（左青龙、右白虎一类表述）
* **藏风聚气**：避免强风直灌与水势直冲；宅、村、城皆求“有围合、有出口”
* **正向与朝向**：宫城、衙署、祠庙常取南向中轴；民居依地形、日照、风向折中

### 城市与建筑尺度

* **都城**：中轴、宫城居中或偏北、前朝后市等与《考工记》传统及历代规制相关
* **寺庙**：名山选址重视形胜——如（山西）五台、（湖北）武当；寺院本身仍多轴线院落
* **祠堂、住宅**：注重与水口、来龙、邻里关系；天井“四水归堂”兼具排水与聚财象征
* **陵寝**：山水环抱、神道序列，是风水观念的集中表达

### 与结构、礼制的交叠

风水话语常与下列实用需求重合：高燥防潮、近水而避涝、迎纳冬阳、夏日通风、军事与防灾视野。礼制则规定谁可用何种屋顶、色彩、开间——**选址讲环境，形制讲身份**，二者共同塑造最终面貌。

### 按时代

## 观法

现场可按固定顺序扫读，避免只看“美不美”：

1. **环境**：山势、水系、朝向、与聚落关系
2. **组群**：轴线、院落层次、主殿位置
3. **屋顶**：形式、重檐与否、瓦色、脊饰数量
4. **立面**：台基—柱额—斗栱—檐口比例；估测出跳与出檐深度
5. **柱网**：对照面阔进深，判断有无**减柱、移柱**；内柱是否升高（厅堂造线索）
6. **构架**：抬梁或穿斗；彻上明造还是平棋；有无叉手、托脚、乳栿、劄牵、大额；侧脚与生起是否明显
7. **铺作 / 平坐**：柱头/补间/转角；数外跳 → 定铺作；逐跳计心/偷心；楼阁看平坐与叉柱/缠柱
8. **顶棚**：彻上明造，还是平棋/井口/海墁；有无藻井
9. **门窗装修**：板门/隔扇/垂花门；门槛、门簪、门钉路数、铺首衔环；槛窗或支摘窗；彩画类型与题记
10. **断代意识**：形制常“早期遗制 + 历代修缮”叠压；普拍枋有无、补间多少、真假昂，都是线索

### 宋清对照

| 概念 | 宋（《营造法式》） | 清（《工程做法》） |

## 复习

| 概念 | 一句话 |
