## 脉络总览

古典文献学处理文献的**生产、流传、保存、整理与利用**。杜泽逊《文献学概要》将范围概括为：载体、形成与流布、收藏与散佚、版本、校勘、目录、辑佚与辨伪、类书与丛书、方志与家谱、总集与别集、出土文献、敦煌文献等。版本馆与古籍展陈中，最先映入眼帘的往往是**纸质印本**的板式、装帧与印刷痕迹，故笔记在版本章之外，另立板式、装帧、印刷三节，与原书「纸质文献的装潢形制」「印刷流布」相互补充。

| 块 | 对应原书 | 核心问题 |
| :--- | :--- | :--- |
| **定义** | 第一章 | 何谓文献；文献学做什么 |
| **载体** | 第二章 | 写在／刻在什么上 |
| **形成与流布** | 第三章 | 著、述、编、译；如何传播 |
| **收藏与散佚** | 第四章 | 官藏／私藏；为何亡佚 |
| **版本** | 第五章 | 写本／刻本／校本等称谓；善本；鉴定 |
| **板式** | 第五章「看版式」等＋展陈常识 | 版框、行款、鱼尾、象鼻、牌记 |
| **装帧** | 第二章纸质装潢 | 卷轴→经折→蝴蝶→包背→线装 |
| **印刷** | 第三章流布＋第五章类型 | 雕版、套印、饾版拱花、活字、石印等 |

读实物宜先定**装帧与制作类型**（写／刻／活字等），再拆**版本称谓**（官家坊、初印翻刻、校本批校），再看**板式行款**与**牌记序跋避讳刻工**，最后落到定名与校勘、目录问题。

## 定义

对应原书第一章。

### 文献

「文献」一词，经典语境中「文」多指典籍，「献」可指贤人、故实（如《论语》「文献不足故也」）。文献学意义上的文献，指**记录有知识的一切载体**——不限于纸书，亦包括甲骨、金石、简帛、敦煌写卷、碑拓等。狭义常指传世与出土的古籍文本；广义可扩及档案、谱牒、舆图等。

### 文献学范围

古典文献学（亦称传统文献学、古文献学）传统上以**目录、版本、校勘**为三大支柱，并旁及辑佚、辨伪、编纂（类书丛书）、专书（方志家谱、总集别集）与出土、敦煌等专门领域。其目的在于：弄清一书的来历与形态，求得尽可能可靠的文本，并指示检寻与利用之门径。

与现代「文献学／情报学」侧重检索与计量不同，古典文献学更重**书史、文本史与整理方法**。

### 为何学

整理古籍、阅读古书、鉴定版本、撰写提要、利用类书辑佚、理解目录分类，皆须文献学基础。博物馆与版本馆展陈中的「宋本」「元刊」「明钞」「白口双边」等标签，亦以此为知识骨架。

## 载体

对应原书第二章。载体变迁决定书写方式、保存条件与后来印本的形制遗痕（如栏线仿简册、版心服务折叶）。

| 载体 | 要点 | 文献学意义 |
| :--- | :--- | :--- |
| **甲骨** | 殷商占卜刻辞；龟甲兽骨 | 最早系统汉字文献之一；分期、缀合、释读自成学科 |
| **金** | 青铜礼器、兵器、度量衡、钱币、符玺等铭文 | 商周史与礼制第一手；与传世文献对读 |
| **石** | 碣、摩崖、碑、造像记、石经 | 耐久；汉魏石经、唐开成石经等具校勘价值 |
| **竹木** | 简牍、觚、检署；编绳成册 | 「册」「典」字源；栏界、契口影响后世版式想象 |
| **帛** | 缣帛书画；楚帛书、马王堆帛书 | 轻便昂贵；图画与长文并存 |
| **纸** | 东汉以降渐普及；写本→印本主战场 | 卷轴至线装演变；雕版印刷依赖纸 |
| **其他** | 莎草纸、羊皮纸、贝叶（域外／佛典） | 中西、中印交流背景下的载体对照 |

纸发明前，中国古典文献以甲骨、金石、简帛为主干；纸普及后，写本与印本爆炸式增长，版本学、板式学才有大规模实物基础。

原书第二章对「金」「石」尚有细目，便于与博物馆金石展对照（不改上表既有表述）：

| 类 | 原书细目／常见展陈 |
| :--- | :--- |
| **金** | 礼器；乐器；兵器；农器；度量衡；钱币；符玺；日用器 |
| **石** | 碣、摩崖、碑；展陈中另常见造像记、墓志、石经等（石经兼具定本与校勘价值） |

竹木简牍的编连（绳、契口）、检署，与后世纸书「册」「卷」「叶」概念相关；纸节详「装帧」。

## 形成与流布

对应原书第三章。

### 形成：著、述、编、译

| 方式 | 含义 | 举例意识 |
| :--- | :--- | :--- |
| **著** | 自出机杼，创为新说新文 | 诸子、史著、诗文创作 |
| **述** | 绍述、训释、发挥已有文献 | 传、注、疏、集解 |
| **编** | 剪裁、纂集、类次 | 选集、类书、丛书、方志 |
| **译** | 语际转换 | 佛典翻译；学术／西学翻译；文学翻译 |

一书之「作者」项，目录中须分清撰、注、疏、编、辑、译，避免张冠李戴。

### 流布

| 途径 | 要点 |
| :--- | :--- |
| **讲唱** | 口传、讲经、说唱；与写本、唱本互动 |
| **镌刻** | 金石、石经、摩崖；定本意图强 |
| **抄写** | 六朝唐宋写本高峰；官抄、私抄、坊抄；讹误亦由此生 |
| **印刷** | 唐末五代兴起，宋以后主流；详「印刷」节 |
| **摄影／影印** | 近代以降；保留板式影像，便利校勘与普及 |

流布方式决定异文多少：口传与多次传抄最易歧出；精校本、石经、善加校勘的刻本相对稳定。

## 收藏与散佚

对应原书第四章。

### 官藏与私藏

历代官府藏书（秘阁、馆阁、文渊阁等）与私家藏书互补。原书分述私藏兴替：周秦萌芽 → 汉魏晋南北朝 → 唐宋繁荣 → 元明 → 清代高峰 → 近代转型。常见名家／楼名如明之汲古阁、清之天一阁、海源阁、铁琴铜剑楼、百宋一廛等，既保存珍本，亦推动目录、题跋、藏印之学。近代公私递藏、散出海外，形成今日博物馆、图书馆与版本馆的馆藏格局。

### 散佚主因

战乱、焚禁、火、蠹、潮、人为毁弃反复打击藏书。原书第四章列举重大节点，便于与「书缺有间」对照：

| 节点 | 概要 |
| :--- | :--- |
| 秦始皇焚书 | 民间《诗》《书》、百家语等遭禁毁（博士官所职等例外，细节见史籍） |
| 西汉末／新莽乱、东汉末战乱 | 官藏屡遭兵燹 |
| 西晋永嘉之乱、侯景之乱与梁元帝江陵焚书 | 南朝藏书重创 |
| 隋末唐初、安史之乱、黄巢起义 | 唐前后官私藏书迭损 |
| 靖康之难 | 北宋馆阁、私藏北迁与散亡 |
| 李自成起义等明清之际战乱、乾隆禁毁 | 政治禁书与兵火并行（原书分列李自成起义与乾隆禁毁等条） |
| 嘉庆宫火、太平天国、英法联军火烧圆明园、庚子事变 | 近代以前又一波次 |
| 日本侵华、「文化大革命」等 | 近现代损毁与流散 |

认识散佚史，才能理解辑佚、影宋、求善本与「存目」书的意义。观展时，一书之**藏印、题跋、递藏印记**往往讲述其幸免于散佚的私人史。

<br>

## 版本

对应原书第五章。版本学研究一书在流传中形成的**不同文本形态**及其时代、地域、刊抄系统，并服务于鉴定与校勘。

### 「版本」释义

雕版印刷出现后，「版」本指书版；「版本」渐指一书之某次写、刻、印形态。今日广义包括写本、刻本、活字本、石印本、影印本等。著录习惯常写：时代＋地点／坊主＋类型，如「宋建阳刻本」「明汲古阁刻本」「清乾隆武英殿聚珍版活字本」。

同一书名下可有数十百种版本；内容、分卷、阙页、序跋、讳字皆可能不同，故「读古书须讲版本」。下节先拆**称谓轴**，再分写抄、刊刻、校批与工作用语，便于对读展签与书目。

### 称谓怎么叠

一书的版本名，常是多轴信息叠写，例如「清乾隆武英殿聚珍版木活字本」「明汲古阁影宋抄本」「清顾广圻校跋本」。常见分轴：

| 轴 | 例 |
| :--- | :--- |
| **制作方式** | 稿本、抄本、刻本、活字本、石印本、影印本 |
| **时代** | 宋本、元本、明本、清本（亦称宋版、宋刊等） |
| **刻书主体** | 官刻、家刻、坊刻；监本、殿本、局本等 |
| **地域／系统** | 浙本、建本（闽本）、蜀本；某书坊、某家塾 |
| **刊印先后** | 原刻、初印、后印、递修、重刻、翻刻、影刻 |
| **内容形态** | 足本、残本、节本、增订本、注本、白文本 |
| **校批题跋** | 校本、批本、批校本、题跋本、过录校本 |
| **流传稀见** | 孤本、珍本、通行本、配本、百衲本 |

「刊本」「刻本」「镌本」在著录中常互通，皆指雕版印本；「版」偏书版／印本总称，「本」偏某一具体书册。近代「第×版／印次」是出版业用语，与古籍「版本」概念勿简单等同。

<br>

### 写本与抄本

无雕版印行、以手写流传者，统称写本系统；其中据他本誊录者习称**抄本**（亦作**钞本**）。

| 类型 | 定义要点 |
| :--- | :--- |
| **手稿本** | 作者亲笔草稿，多勾改涂乙 |
| **清稿本** | 誊清定稿；或仍出作者手，或他人誊清而经作者校改、钤印 |
| **抄稿本** | 直接据稿本过录，次于稿本一等 |
| **影钞本**（影抄、影写） | 覆纸摹写，求行款字体逼真；佳者几可乱真宋元；劣者仅摹行款 |
| **抄本** | 一般传抄；有**官抄**、**家抄**、**坊抄**；又有精抄、旧抄、近抄之别 |
| **写本**（广义） | 亦可泛指手写书册，含唐以前卷子、敦煌写经等；与「刻本」对言 |

写本可有乌丝栏、朱丝栏，却无刻板意义上的「版心刻工」。精抄可胜过劣刻；劣抄则讹夺连篇。名家影宋抄（如毛氏汲古阁）文物与校勘价值皆高。另有**彩绘本**（带彩绘）、**进呈本**（进呈御览／官府）等特殊写／印称谓。

<br>

### 刻本与刊本

**刻本**＝以书版刷印之本，亦称**刊本**、**镌本**。宋以后传世古籍大宗。可再按主体、地域、先后细分。

#### 按刻书主体

| 类型 | 要点 |
| :--- | :--- |
| **官刻本** | 中央或地方官府出资刊刻；校勘往往较审 |
| **监本** | 国子监所刻（宋监本、明南监／北监等） |
| **殿本** | 清武英殿等殿廷刊刻；字体、纸墨常精 |
| **局本** | 晚清官书局（金陵、浙江、广雅等）所刻 |
| **藩府本** | 明代藩王府刻书，部分精善 |
| **书院本** | 书院所刻 |
| **家刻本**（家塾本） | 私人／家族出资；或传先集，或自著自刻，或为校勘传布 |
| **坊刻本** | 书坊、书肆营利所刻；产量大，精粗悬殊；宋临安棚本、建阳书林等著名 |

#### 按地域风气（宋元尤常用）

| 类型 | 印象（通则） |
| :--- | :--- |
| **浙本** | 杭州等；多欧体味，校刻相对精 |
| **建本**（闽本） | 建阳麻沙等；产量大，行密字小者多，亦有佳刻 |
| **蜀本** | 四川；字体或偏肥厚 |

#### 按刊印先后与复制关系

| 类型 | 要点 |
| :--- | :--- |
| **祖本**（母本） | 一书最早之刻／写源头；后出本多从此出；校勘上极受重视 |
| **原刻本**／**初刻本** | 首次开雕之本（相对后来重刻而言） |
| **初印本** | 同版第一次或早期刷印；字口清、墨色匀 |
| **后印本** | 同版多次后印；版片磨损、断版、糊墨常见 |
| **递修本**／**修补本** | 旧版残损后补刻再印；字形刀法或新旧不一 |
| **三朝本** | 如南宋版入元、明递修刷印，历经数朝 |
| **重刻本** | 另刻一版再印；内容或仍依旧，版片已非原版 |
| **翻刻本**／**覆刻本** | 据某本摹刻上版，求接近底本；有覆宋、覆元等 |
| **影刻本** | 高度依原书面貌影摹上版（乾嘉以后尤盛） |
| **仿宋本** | 清人依宋版行款字体风格所刻（未必真影摹某一宋叶） |
| **写刻本** | 请书家手写上版镌刻，字体近写，非方板匠体 |
| **影印本** | 近代照相／石印等复制旧本；著录须标「影印」，勿与原刻混 |

同版「初印／后印」与另开新版的「重刻／翻刻」层级不同：前者版同印次异，后者版已更换。

<br>

### 活字、套印与近代印本

| 类型 | 定义要点 |
| :--- | :--- |
| **套印本** | 多色分版套印（朱墨、三色至五色等） |
| **饾版与拱花** | 短版拼色如饾钉；拱花凹凸暗花；明末《十竹斋》等 |
| **活字本** | 泥、木、铜、锡等活字排印；明清铜活字、木活字；殿本**聚珍版** |
| **石印本** | 近代石印，据书写或影印上石 |
| **珂罗版** | 玻璃版影印，宜书画精细再现 |
| **排印本**／铅印本 | 近代铅字排印；与雕版「刻本」分列 |
| **拓本** | 碑帖、器物铭文椎拓之本（金石文献常用，非书版刷印） |

<br>

### 校本、批本与题跋本

「校」指校勘异文、「批／评」指评论圈点、「跋」指题记。常叠称，宜拆开理解。

| 类型 | 要点 |
| :--- | :--- |
| **校本**／校定本 | 经过校勘审定之本；或某人据他本手校过的本子 |
| **校刻本** | 校勘后付梓之本；强调「校而后刻」 |
| **批本**／评本 | 有批语、评点；天头者称眉批 |
| **批点本**／评点本 | 批语＋圈点 |
| **批校本** | 批语与校语兼有；名家批校尤贵 |
| **过录校本** | 后人把某家校语过录到另一部书上；非原校笔迹 |
| **题跋本** | 有题识、跋语，记递藏、鉴定、读书记 |
| **朱墨校本** | 以朱、墨等色笔分写校语（亦有套印朱墨） |

展签写「××校跋本」：看是**原笔**还是**过录**，价值差一截。校本不等于善本：校劣、妄改者反增乱。

<br>

### 底本、通校本与内容形态

整理、影印、校勘时的工作用语，与「这书卖什么版本」的收藏称谓交叉：

| 术语 | 要点 |
| :--- | :--- |
| **底本** | 整理／影印／校勘时选定为主的工作本 |
| **通校本**（参校本） | 用来与底本对校的其他本子 |
| **祖本** | 版本源流上的源头本（见上）；常优先考虑作底本，但残损严重时或选后出精校本 |
| **足本** | 内容相对完整 |
| **残本**／零本 | 缺卷缺叶 |
| **节本**／删本 | 删节 |
| **增订本** | 增补修订 |
| **白文本** | 仅正文，无注 |
| **注本**／笺注本／疏本 | 带注疏 |
| **单刻本** | 单行，相对丛书本而言 |
| **丛书本** | 收入某丛书之零种 |
| **配本** | 以他本补配残缺，使成全书；须注明配自何本 |
| **百衲本** | 多本零种拼配成一部（如百衲本《二十四史》） |
| **通行本** | 市面常见、刻印平常之本 |
| **精刻本** | 写刻／校刻精良之本（评价语，非严格类名） |
| **巾箱本**／袖珍本 | 开本特小，便携 |
| **孤本** | 已知存世仅此一份（或拓本原石已毁） |
| **邋遢本** | 版片模糊、印工粗劣之贬称 |

<br>

### 善本

善本有两层常用含义：

1. **珍贵、稀见、时代早、品相好**（文物／收藏义）——如宋元本、名家抄校、初印精拓。
2. **文字相对可靠、校勘精善**（学术义）——精校精注本、名家校本，未必宋元。

传统亦有「足、精、旧」一类概括（完整、校刻精、时代早），与今日馆藏定级标准不完全等同。二者有时一致，有时分途（残宋未必优于清精校；通行局本未必劣于残明）。观展标签「国家珍贵古籍」侧重前者；读书治学须兼顾后者。

<br>

### 版本鉴定

鉴定是综合判断，原书列举多途，宜并行，忌单证：

| 途径 | 看什么 |
| :--- | :--- |
| **撰著年代** | 书成于何时；是否后人伪托 |
| **序跋** | 序跋年代、作者、刊刻缘起；伪序须防 |
| **牌记** | 书名页、卷末、目录后之刊记、坊主、年月 |
| **避讳** | 缺笔、改字；定朝代／皇帝下限 |
| **刻工** | 版心下方刻工名；与已知年表比对 |
| **校阅人** | 衔名、时代是否合 |
| **字型** | 欧、颜、赵等风气；宋元明清字体演变 |
| **版式** | 见下节「板式」；行款、边栏、口线时代特征 |
| **纸张** | 麻纸、皮纸、竹纸；帘纹、色泽 |
| **装潢** | 装帧形式是否与声称时代合（后装须辨） |
| **藏印** | 真伪、时代、递藏链 |
| **类比／著录／旁证／书影** | 与标准器、书目、他书引征、图录对照 |

**避讳**尤须谨慎：有敬避、有未避、有回改；缺笔可作旁证，不宜孤证定年。**牌记**可挖改；须与字体、纸墨、序跋交叉验证。

<br>

## 板式

板式（版式）指一叶印面的排版格局。雕版普及后术语系统化；观展时「半叶十行二十字，白口，左右双边，单鱼尾」一类描述即板式著录。板式是版本鉴定的常规抓手。

### 一叶的结构

线装书一「叶」（页）多由一版印成后对折：有字的一面为正面，折缝在**版心**。习惯以**半叶**计行款。

| 部位 | 名称与说明 |
| :--- | :--- |
| **版框／边栏** | 围住文字的四边线。上栏、下栏、左右栏 |
| **界行／界栏** | 行与行之间的直线，仿简册分栏遗意 |
| **天头／地脚** | 版框上方／下方空白，供批校 |
| **版心**（书口、中缝） | 叶面对折处；常记书名简称、卷次、叶码、字数、刻工 |
| **鱼尾** | 版心中标示折缝的「▲／▼」形记号；单、双、三鱼尾；花鱼尾 |
| **象鼻** | 鱼尾上下连至版框的线；粗黑＝大黑口，细黑＝小黑口，无线＝白口 |
| **书耳** | 版框外左或右上的小框，或记篇名叶码（建本等常见） |
| **牌记／木记** | 刊刻者、地点、年月等印记，形式多样（长方、钟鼎龛式等） |

### 边栏类型

| 术语 | 形态 |
| :--- | :--- |
| **四周单边** | 四周仅一道栏线 |
| **四周双边** | 四周粗线内再加细线 |
| **左右双边** | 仅左右为双边，上下单边（宋本常见风气之一） |

### 书口：白口与黑口

| 术语 | 形态 | 时代印象（粗线，非绝对） |
| :--- | :--- | :--- |
| **白口** | 象鼻处无黑线 | 宋刻多白口疏朗 |
| **小黑口／细黑口** | 细黑象鼻 | 宋末元明渐多 |
| **大黑口／粗黑口** | 粗黑象鼻 | 元明部分刻本、坊刻常见 |

「黑口」指版心象鼻发黑的视觉效果，与装订后的「书口」端面相关但概念层次不同：著录「白口／黑口」多就版心而言。

### 行款

**行款**＝半叶几行 × 每行几字（小字双行注另计）。同书异刻行款往往不同，故为对板、鉴定的硬指标。著录例：「半叶八行，行十七字，小字双行同，细黑口，四周双边。」

另须注意：版心所记「字数」有时指本版字数，供计酬或核对，与行款相参。

### 字体与刀法（与板式连带）

宋浙本多欧体味、福建建本较挺劲或趋定型、蜀本或肥；元赵体影响；明中叶以后渐趋方板；清殿本、局本又有馆阁气。刀法生熟、断版裂痕、修版补版，皆可入鉴定视野。

### 时代板式印象（便于观展速记）

| 时代 | 常见印象（通则，例外甚多） |
| :--- | :--- |
| **宋** | 白口为多；左右双边常见；行宽字大，疏朗；避讳严 |
| **元** | 黑口增多；四周双边；字体变长趋赵；牌记花样多；建本封面／书名页萌芽 |
| **明** | 前期或承元；中后期行密字小；嘉靖仿宋；万历时局、书林繁盛 |
| **清** | 殿本、局本、私刻并盛；考据风下精校精刻；石印后板式近现代 |

<br>

## 装帧

对应原书第二章「纸质文献的装潢形制」。装帧是书叶组织成册的方式，与板式（单叶排版）不同层。后改装常见，鉴定时「装帧时代」未必等于「刊刻时代」。

### 演变序列

| 形制 | 做法要点 | 流行大致 | 阅读感受 |
| :--- | :--- | :--- | :--- |
| **卷轴装**（卷子） | 纸／帛连续裱接，左卷右轴；有时乌丝栏 | 六朝—唐写本主流 | 须展卷；不便抽检 |
| **经折装**（梵夹影响） | 长纸反复折叠如手风琴 | 佛经等；唐以后 | 可立放翻折 |
| **旋风装**／龙鳞装 | 叶错落粘于底卷等变体 | 较少；鉴定争议多 | 翻叶如鳞 |
| **蝴蝶装** | 有字面向内对折，中缝粘于背；翻开如蝶翼 | 五代—宋元常见 | 一版整图完整；常遇空白叶 |
| **包背装** | 有字面向外对折，书脊裹背粘皮，早期纸捻订 | 南宋—明 | 书口在外，免空白对翻之弊 |
| **线装** | 纸捻或线订，前后书皮，打眼穿线（常四针眼） | 明中叶后主流至近代 | 平放插架；易翻检；可衬纸 |

另有简册编连、帛书折叠等更早形态；石印平装、精装属近现代，不在古典主流序列内。

### 蝴蝶装与包背装对照

* **蝴蝶装**：文字面相对；优点是整版图不剖开、插架书口向下尘少；缺点是翻一叶常接两面空白。
* **包背装**：文字朝外成双叶；书脊包纸；是线装的直接前身。

### 线装细节（观展高频）

书皮、护叶、书签、眼线、包角、函套（四合套、六合套）、书根写书名卷次便于插架检索。金镶玉等装池技法属修复装潢，可保护薄脆原叶。

<br>

## 印刷

对应原书第三章「印刷」流布与第五章印本类型。印刷使文献复制量级上升，版本异同问题随之尖锐。

### 雕版

以梨枣等木板反刻文字，刷墨铺纸拓印。一套书页对应多块书版；书版可存于书楼、书坊，反复刷印，故有**初印／后印／递修**之别：初印墨色清、字口新；后印版片磨损、断版、糊墨；递修则补刻字形或异于原刻。

官刻（中央、地方儒学）、家刻、坊刻动机不同：官刻求典范，家刻或为传先集、或为学术，坊刻重流通与利，建阳书坊等产量巨大。

### 套印、饾版、拱花

* **套印**：各色各版对准套印，朱墨双色常见，亦有多色。
* **饾版**：短版分色拼印，如饾钉拼盘，宜绘书彩印。
* **拱花**：无墨或淡墨压出凸纹。明末十竹斋、饾版拱花代表彩印高峰。

### 活字

单字活字排版印刷，印毕可拆。毕昇泥活字见沈括记载；西夏、元代亦有活字实物与记载；明清铜活字（如华氏）、木活字通行；清乾隆**武英殿聚珍版**以木活字印《四库》未收书等，影响大。活字本特征：栏线或有不齐、字形大小微殊、同一字反复出现形态一致等（亦须防仿刻）。

### 石印与珂罗版

近代技术：石印便于快速复制；珂罗版宜精细图像。二者使「影印宋本」成为可能，既保真板式，亦须在目录中标明「影印」，勿与原刻混淆。

### 印刷与校勘

一经刊刻，讹误亦被放大固定；善本、精校、重修、挖改、撤卷，皆围绕「印成文本」的正确性与商业／政治需求展开。

<br>

## 校勘

对应原书第六章。校勘旨在发现并处理文本在传抄刊刻中的错误，求接近作者原貌或某一可说明的定本。

### 错讹类型

| 类型 | 含义 | 例方向 |
| :--- | :--- | :--- |
| **讹** | 错字 | 形近、音近而误 |
| **脱** | 夺文 | 脱字、脱句、整叶亡 |
| **衍** | 衍文 | 误增字句 |
| **倒** | 乙倒 | 二字／数句次序颠倒 |
| **错乱** | 错简、错卷、错叶 | 简册乱序；装订错叶 |

### 条件

主观须文字、史实、目录版本素养；客观须**广求异本**与相关引文、类书、石经、出土文献；并精熟本书体例与内容。

### 主要方法（陈垣系归纳为经典框架，原书亦述）

| 方法 | 做法 |
| :--- | :--- |
| **对校** | 以同一书之异本逐字比勘，找出异同 |
| **本校** | 据本书前后、体例、文理内证 |
| **他校** | 以他书引文、类书、注疏等外证 |
| **综合考证**／理校 | 无本可据时据义理、制度、史实推断（最险，须极慎重） |

### 校勘记与态度

校改须有交代：或改本文而出校，或不动本文仅在记中说明。态度重在**多闻阙疑**——证据不足则存疑，切忌臆改。

<br>

## 目录

对应原书第七章。目录是文献的「地图」：揭示有什么书、如何分类、版本与内容大要。

### 目录的产生

刘向、刘歆校书而有《别录》《七略》，为中国目录学典范源头；班固《汉书·艺文志》切为史志目录。其后公私簿录、提要目录、藏书志、经眼录、禁毁目、版本图录等层累出现。

### 古籍分类

四部分类（经史子集）自《隋书·经籍志》格局奠定，沿用至清《四库全书总目》。此前有六分、七分等。类目变迁反映学术结构；一书入何类有时两可，须看目录体例。

### 目录著录要素

书名（含同书异名、异书同名问题）、篇卷、撰人及朝代、版本、提要、大小序。古书命名方式多样：通称、摘字、姓名、朝代、时间、地点、隐括内容等。

**同书异名**：一书多名，检索须互见。**异书同名**：多名书共一名，须靠撰人、卷数、提要区分。目录学的实用处，首先在少走「找错书、读错本」之路。

### 目录类型

| 类型 | 举例意识 |
| :--- | :--- |
| **公藏目录** | 秘阁、馆阁、官修总目 |
| **私藏目录** | 藏书家簿录、题跋记 |
| **史志目录** | 正史艺文／经籍志 |
| **专科目录** | 经学、小学、史、子、集专题 |
| **特种子目** | 举要（如《书目答问》）、丛书目、知見／经眼、禁毁、版本图录、辨伪目录等 |

读古书前先查目录与版本，可少走盲读、误本之路。

<br>

## 辑佚与辨伪

对应原书第八章。

### 辑佚

古书大量亡佚。辑佚从类书、注疏、他书引文、敦煌残卷、石刻等中钩稽佚文，重编成书。清人辑佚成绩巨大（如《玉函山房辑佚书》等）。方法上须注明出处、辨别误引、理清篇第，忌把他书文字硬派给亡书。

辑佚所得往往是**佚文碎片**，未必恢复原书面貌；引用辑本时宜回核所据类书、注疏原文。原书将辑佚与辨伪同章：辑出之文亦须防误署书名、误连篇第，与辨伪意识相通。

### 辨伪

**伪书**指作者、时代、内容归属作假或严重不实之书。

**动机**（原书归纳）：传道、射利、炫名、争胜、逃禁、避嫌等。

**手段**（举要）：假托他人；后人改题著者；割去／伪撰序跋；沿袭旧名而作新书；节采更名；缀合群书为新编；变乱旧例充新编；自著自注；篆籀充古本；以假搀真窜乱旧帙等。

**辨识途径**（原书列约二十途，可归为数类）：

| 角度 | 例 |
| :--- | :--- |
| 授受与人物 | 源流、依托者、传出者、行事矛盾、时人揭发 |
| 语文与文体 | 文体、风格、语词时代、声韵系统 |
| 文献关系 | 因袭、称引、佚文 |
| 名物制度 | 史实先后、称谓、制度、地理沿革 |
| 思想学术 | 观点矛盾、学术水平／专长不符、思想史倒置 |

**伪书的价值**：未必废纸——可作史料（所托之外的时代）、文学、语言、思想史材料；惟不可当作所托作者／时代之直接史料。

<br>

## 类书与丛书

对应原书第九章。

### 类书

按类纂辑群书资料。起源常追溯至魏《皇览》一类；后世体量与门类不断扩大。

**功用**（原书四点）：

1. **查找史料**（事类、典故）
2. **查找辞藻**（作文用事）
3. **校勘、考订**古书（他校材料）
4. **辑佚**（保存他书已亡之引文）

**举要**（常用）：唐《艺文类聚》《北堂书钞》《初学记》；宋《太平御览》《册府元龟》《玉海》；明《永乐大典》（残存与辑佚极重要）；清《古今图书集成》等。用类书须注意：二次文献常有删改、误署书名篇名，引用须复核。

### 丛书

汇刊多书为一部，便保存、流通与配齐。宋已有雏形，明清大盛。

**举要**：明《津逮秘书》《汉魏丛书》等；清《知不足斋丛书》《抱经堂丛书》《士礼居丛书》等；近代《四部丛刊》（多影印善本）、《四部备要》（排印）、《丛书集成》等。丛书可含珍本影刊，亦可含劣刻；使用时仍须**逐书考版本**，勿因丛书名而一律信任。

<br>

## 方志与家谱

对应原书第十章。

### 方志

**种类**（原书）：总志；省志；府、州、厅、县志；乡镇志；都邑志；卫所志；边关志；土司志；盐井志；专志（山水、寺观、盐法、海关等）。

**用途**：政治治理参考；地理沿革第一手；文学创作与研究资料；历史资料渊薮（人物、艺文、金石、灾异、物产、风俗）。方志艺文、金石门常蕴集部与石刻罕见材料。

### 家谱

宋以后私修繁荣。常见内容模块：世系／世系录、谱序、恩荣录、谱例、像赞、图、传志、宗规家训、文献、修谱人员、领谱字号等。

**价值**：人物传记、诗文、人口与移民、宗族制度研究。同时存在攀附名贤、伪世系等问题，使用须批判对待。

<br>

## 总集与别集

对应原书第十一章。

**总集**：汇聚多人之作或一代／一体之全编、选编。如《文选》《玉台新咏》《文苑英华》《全唐诗》《全唐文》《全宋词》《全宋文》等。有保存文献之功，亦有去取标准与时代偏见；「全」系相对而言，后出补遗不断。

**别集**：一人之诗文集。起源与东汉以降文人集相关；内容或含诗、文、词、奏议、联语等。文献价值在于作者手定／家刻系统、佚文、交游与版本异同。集部版本学重点：稿本、钞本、家刻本、全集本、选集本、坊刻本之关系。

<br>

## 出土文献

对应原书第十二、十三章。

### 甲骨文

殷墟等出；乱掘与科学发掘两阶段。资料结集如《甲骨文合集》等。价值：语言文字；殷商祭祀、王室、历法、战争等史研究。

### 金文

与青铜器共生；著录自宋代金石学至现代《殷周金文集成》等。价值：语言文字；考订传世文献；古史、地理、官制、法制。

### 简帛（举要）

原书列举近世重要发现，观展／阅读常见者包括：曾侯乙墓竹简；楚简（鄂、湘、豫等地）；云梦／江陵秦简；马王堆帛书；阜阳、银雀山、武威、居延、敦煌、定州、尹湾等汉简；楼兰尼雅汉晋简；长沙走马楼吴简等。

**价值**：佚籍复出；考校传世古籍；历史与行政档案；文字学；书籍制度实物（简册形制）。

### 石刻与其他

碑刻、墓志、石经等：史料、文学、书法文字、经学与宗教。另有盟书、玺印、砖瓦文、纸质出土文书等。

整理通则：发掘报告 → 缀合／拼复 → 释文注解 → 与传世本对读。简帛尤其改变对早期经子「定本」流动性的认识。

<br>

## 敦煌文献

对应原书第十四章。

### 地点与发现

敦煌—敦煌石窟—莫高窟—**藏经洞**（约 1900 年发现）。封闭年代与原因有多种推测，尚无唯一定论。其后写本、绢画等经斯坦因、伯希和等运藏海外，亦有部分留存国内，形成分散度藏。

### 目录与整理

各国有馆藏目录；国内有总目、索引与大型图录影印（如《敦煌文献》类汇编）。研究须先确认**馆藏号**与图版。

### 内容与价值（原书分类意识）

| 类 | 例向 |
| :--- | :--- |
| 宗教 | 佛道经典、写经题记 |
| 儒家经籍 | 写本经书，可与传世本对校 |
| 语言 | 音义、俗字、白话资料 |
| 史地 | 地志、牒状 |
| 子部／科技 | 医占、算术等 |
| 文学 | 变文、曲子词、唐人诗 |
| 社会文书 | 契券、籍账、社邑 |

对版本学、写本学：可见唐五代**写本行款、乌丝栏、题记**实态，与宋以后印本传统对照。

## 观法清单

对照版本馆、博物馆线装书展陈时，可按序观察：

1. **装帧**：卷轴／经折／蝶装／包背／线装？是否后改装？
2. **制作类型**：稿／抄／影抄？刻本／活字／套印／石印／影印？官刻家刻坊刻？
3. **印次与源流**：初印或后印？原刻、递修还是翻刻／影刻／影印？
4. **板式**：半叶几行几字？单边或双边？白口或黑口？鱼尾单双？有无书耳、牌记？
5. **文字与讳**：字体风气；明显讳字缺笔？
6. **序跋牌记刻工**：刊刻年月、地点、坊主；是否挖改嫌疑？
7. **校批题跋**：有无批校？原笔还是过录？
8. **纸墨装潢藏印**：纸质帘纹；印鉴真伪与递藏。
9. **目录定位**：经史子集何类？单刻还是丛书本？与《四库》或馆藏目录如何对应？
10. **文本问题**：若为读书而非赏鉴：底本何选？通校何本？足本还是节本？
