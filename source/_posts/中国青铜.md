## 脉络总览

中国古代青铜器以**礼器**为核心，旁及兵器、乐器、车马器、工具及杂器。青铜时代约自二里头文化铜器出现，经商、西周至春秋战国仍高度发达，战国晚期至汉代礼器系统渐衰，日用铜器与铁器并行。博物馆观摩宜先辨三层：

* **技术**：合金（铜锡铅）、范铸／失蜡、嵌错
* **礼制与时代**：器类组合、形制纹饰阶段特征
* **地域**：中原礼器传统与周边文化系统（蜀、滇、北方草原等）

## 定义

对应马承源书第一章。

### 青铜与青铜时代

**青铜**一般指铜（Cu）与锡（Sn）为主的合金，常加铅（Pb）改善浇注流动性。相对纯铜（红铜），熔点较低、硬度与铸造性能更好，适合礼器与兵器。中国青铜时代的开端，学界多以二里头文化中较成熟的青铜容器、兵器出现为重要标志；上限、与「夏」王朝的对应关系，考古与史学仍有讨论，笔记中器物层面称「二里头铜器」，历史标签审慎使用。

### 研究对象

包括：器类与形制演变；纹饰主题与布局；铭文释读与史料价值；分期断代方法；采矿冶炼铸造工艺；区域文化比较；辨伪与著录史。礼器因与等级、祭祀、宴飨制度相关，为研究重心。

<br>

## 冶铸

对应马承源书第七章。技术史是理解器壁厚度、范线、补铸、嵌红铜／错金银的基础。

### 采矿与合金

古代铜矿、锡矿分布影响产地与贸易。合金配比随器类与时代变化：容器常含一定铅以利成形；兵器或提高锡以增硬。马承源书第七章专列「各个时期的青铜合金成分」：商至西周礼器常见铜锡铅三元；春秋战国嵌错、复合金属工艺增多，成分更因器制宜。具体百分率须以科学检测为准，不宜用单一配方概括全史。

### 块范铸造

商周主流为**陶范块范法**：制模→翻范→合范→浇注→整修。复杂器多分范；耳、足、提梁等可分铸再铸接。器表常见**范线**（合范缝）、垫片痕迹。殷墟时期合范技术已很高，大件礼器（如司母戊／后母戊鼎一类）体现分范与浇注控制能力。

### 失蜡铸造

以易熔材料制模，外包耐火材料，加热失模后浇注，宜复杂镂空附件。春秋战国部分精品（如曾侯乙墓部分附件）与此相关；具体器物是否失蜡，须个案分析，勿凡镂空即断为失蜡。

### 复合与装饰工艺

分铸、焊接（含金属焊接）、嵌红铜、错金银、鎏金、刻纹、线刻画像等，春秋战国尤盛，使装饰从范铸阳纹扩展到冷加工与镶嵌。

<br>

## 时代

对应马承源书第五章，并吸收考古通行文化期表述。下列为礼器风格与组合的大纲；细断代须依标准器与铭文历日、坑位。

### 断代方法（教材要点）

| 途径 | 说明 |
| :--- | :--- |
| **标准器** | 有明确铭文年代、王号、或可靠坑位的器／器群，作为标尺 |
| **形制** | 口沿、耳足、腹底、梁盖等型式演变 |
| **纹饰** | 主题与地纹组合、粗细风格 |
| **铭文** | 内容、书体、语词、历日、人物系联（「康宫」等专题） |
| **组合** | 墓葬／窖藏共出关系；爵觚斝、鼎簋等 |
| **工艺** | 范铸特征、分铸焊接、嵌错等是否合时代 |

金文学「标准器断代」与考古学类型学互补；单凭铭文或单凭花纹皆易误。

### 马承源五期与王朝对照（约）

| 五期 | 约略对应 | 风格印象 |
| :--- | :--- | :--- |
| **萌生** | 二里头等早期铜容器阶段 | 器类简、壁薄、嵌绿松石等 |
| **育成** | 商前期（二里冈）至盘庚迁殷前 | 礼器体制形成；爵觚斝组合 |
| **鼎盛** | 商后期至西周昭王前后 | 厚重繁缛；合范高峰 |
| **转变** | 西周穆王以后至春秋早期 | 周人风格确立；几何变形纹；长铭 |
| **更新** | 春秋中期至战国、秦 | 区域分化；嵌错画像；礼器日用化 |

汉代铜器生活化，马承源体系中常不纳入「青铜时代」主叙事（故「衰退期」后或省去）。与郭沫若五期名称不同，引用时须标明出自何说。

<br>

### 二里头

约当文献中夏商之际前后的考古学文化（绝对年代与王朝对应有讨论）。河南偃师二里头出土爵、斝（jiǎ）、鼎、铃、嵌绿松石牌饰、兵器等。器壁多较薄，器类相对简单，已见青铜容器与镶嵌工艺。绿松石镶嵌十字纹、兽面类纹样见于牌饰。此期奠定中原青铜礼器传统的早期形态，约当五期之「萌生」。

<br>

### 商前期

考古学上常与**二里冈**文化（郑州商城等）对应，约当「育成」期主体。器类扩展：鼎、鬲（lì）、甗（yǎn）、簋（guǐ）、爵、管流爵、觚（gū）、斝、罍（léi）、壶、盘等。**爵、觚、斝**一套酒器组合已普遍，商代青铜礼器体制初步形成。二里冈下层器壁往往更薄，上层有的已较厚重。出土地以郑州一带为中心，波及河南北部、湖北盘龙城、江西等地。

部分论著在二里冈与殷墟之间讨论「商中期」缺环与过渡；具体器群归属以考古报告分期为准。

<br>

### 商后期

以**殷墟**（安阳）为中心的晚商，进入「鼎盛」期。礼器体制庞大，器类齐全，花纹繁缛（常主题纹＋云雷地纹，所谓多层纹饰），合范精熟。酒器系统极盛；食器、水器、兵器、车马器、乐器（如铙 náo）均有发展。著名大件如后母戊（司母戊）鼎等反映王室铸造规模。分布上，符合殷墟风格的铜器北至内蒙古辽宁，南至两广，西至陕甘川，东至海滨，同时地方类型（如新干大洋洲、四川三星堆）并立，不可全部归为「殷墟一式」。

铭文：早期多族徽、日名、简短；晚商记事铭文增多，但仍短于西周长篇。殷墟内部再分期（考古三期／四期等）与甲骨分期相关，妇好墓年代等尚有讨论，观展记「殷墟期」即可，细断代须查报告。

<br>

### 西周

#### 早期（约武成康昭）

承晚商厚重庄严作风（鼎盛期末至转变前），又逐渐形成周人器用与铭文传统。食器地位上升，**鼎、簋**组合与列鼎观念发展——文献有天子九鼎等说，考古须据墓葬实数与身份综合判断，勿机械套用。酒器组合相对商代有调整。长篇册命、记事铭文出现并发展，成为断代重要依据（唐兰「康宫」原则等属专题）。

#### 中期（约穆共以降）

进入「转变」期：形制、纹饰由殷墟遗风向周人风格过渡；周原等地窖藏（如庄白微氏家族器群）为分期标尺。铭文记事、追孝发达。

#### 晚期（约夷厉宣幽）

器形趋于简朴或新范式，重铭文内容；窃曲纹、重环纹、波曲纹等几何化变形纹流行。与春秋早期风格衔接紧密。

西周铜器出土地以陕西周原、丰镐，河南洛阳等地为重心，诸侯国器亦多。

<br>

### 春秋

前期多承西周晚期（转变期末）。中后期进入「更新」期区域化：三晋、齐鲁、燕、楚、秦、吴越等风格圈凸显（马承源书第六章）。礼器比例相对下降，日用器上升；新见或流行敦（duì）、鉴、长剑等。工艺上分铸、焊接发展，部分地区出现失蜡；纹饰由粗放兽面转向细密蟠螭（pán chī）、蟠虺（pán huǐ），并见嵌错。铭文渐短，装饰性增强，媵（yìng）器铭常见。

<br>

### 战国

「更新」期高峰与礼制松动并存。实用器、兵器、车马器、度量衡、符节发达。错金银、嵌松石、细线刻画像等装饰极盛。曾侯乙墓（随州）编钟、尊盘等代表南方诸侯铸造与乐律铭文高峰。铭文多见「物勒工名」。战国晚期至秦，铁器与漆器冲击日用领域；汉代铜器转向灯、炉、洗、镜等生活器，商周式礼器系统衰落。

<br>

### 秦汉以降（附）

青铜礼器时代结束并不等于铜器消失：铜镜、带钩、玺印、钱币、度量衡、佛造像装銮等延续。观展「商周青铜器」专厅与「秦汉铜器」宜分概念：前者重礼制与铭文史料，后者重生活与工艺。李松《中国青铜器》侧重造型与工艺审美通识，可与马承源教材的类型学、铭文史料维度互补，而不替代分期标准器方法。

<br>

## 器类

对应马承源书第二章。分类可按用途（食器、酒器、水器、乐器、兵器、杂器），亦可按考古类型学细分为型式。下表以用途为主；生僻字附拼音。

<br>

### 饪食器

祭祀、宴飨中烹煮、盛放饭食之器。西周以后鼎簋组合在等级表达上尤为关键。

| 器名 | 拼音 | 形制与用途概要 |
| :--- | :--- | :--- |
| **鼎** | dǐng | 圆腹或方腹，三足或四足，双耳；煮牲、盛牲。列鼎制度以奇数为等级标志（文献与考古对应有讨论，须据墓葬组合判断） |
| **鬲** | lì | 袋足中空，宜煮粥羹；与鼎并见 |
| **甗** | yǎn | 上甑下鬲，蒸食器；或上下分体 |
| **簋** | guǐ | 圆腹圈足，或有耳、盖；盛黍稷等。常与鼎配套，文献有偶数簋与奇数鼎相配之说 |
| **盨** | xǔ | 椭方腹，圈足，双耳，多有盖；西周中晚期盛食器 |
| **簠** | fǔ | 长方口，斜壁，圈足外撇，盖器同形；盛稻粱等 |
| **敦** | duì | 春秋战国流行，上下半球相合如球；盛食器 |
| **豆** | dòu | 高柄盘形，盛醢酱等 |
| **铺** | pū | 浅盘高圈足一类食器（形制与豆有别，教材单列） |
| **盂** | yú | 大口深腹，盛水或饭食 |
| **盆** | pén | 大口器，用途视组合而定 |
| **鍪** | móu | 圜底缩口，军旅／炊器色彩较强 |
| **俎** | zǔ | 切肉承牲的几案形器 |
| **匕** | bǐ | 取食之匙形器 |

另有铏（xíng）等盛羹器，出现频率因时代而异。

<br>

### 酒器

商代礼器中酒器系统最为发达；西周以后部分酒器减少，壶等延续。功能上有温酒、斟酒、盛酒、饮酒之别，个别器类功用学界仍有讨论（如爵）。

| 器名 | 拼音 | 形制与用途概要 |
| :--- | :--- | :--- |
| **爵** | jué | 前流后尾，侧鋬（pàn），下三足，口沿常有柱；商代核心酒器之一 |
| **角** | jué | 形近爵而无柱，口呈凹弧；与爵并出 |
| **觚** | gū | 喇叭口，细腰，圈足；饮酒／礼器组合中与爵常成对 |
| **觯** | zhì | 小口鼓腹或椭扁，圈足，饮酒器 |
| **斝** | jiǎ | 口圆，双柱，无流尾，三足；温酒／盛酒，商代与爵觚配套 |
| **尊** | zūn | 大口或异形（鸟兽尊），盛酒；含方尊、圆尊 |
| **壶** | hú | 长颈鼓腹，盛酒或水；周代极常见 |
| **卣** | yǒu | 椭圆形或圆形，有盖与提梁，盛酒 |
| **方彝** | fāng yí | 长方有盖如屋，盛酒 |
| **觥** | gōng | 椭圆或兽形，有盖有流，盛酒／饮器 |
| **盉** | hé | 圆腹，管流，鋬，三足或四足；调酒或温酒，亦与盘配套作水器 |
| **罍** | léi | 大口或小口，圆／方腹，盛酒水 |
| **瓿** | bù | 敛口圆腹，盛酒水 |
| **缶** | fǒu | 小口大腹；尊缶等盛酒 |
| **禁** | jìn | 承放酒器的案形座 |

杯、饮壶、勺、斗（科）等为附属饮具或挹注器。鸟兽形尊（如鴞 xiāo 尊、象尊）属尊类异形。

<br>

### 水器

行礼前浇水洗手（沃盥）等仪式用器，盘匜配套最典型。

| 器名 | 拼音 | 形制与用途概要 |
| :--- | :--- | :--- |
| **盘** | pán | 敞口浅腹；承弃水。常与匜或盉配套 |
| **匜** | yí | 椭长腹，前流后鋬，四足或圈足；注水器 |
| **鉴** | jiàn | 大盆形，盛水照容或沐浴冰鉴；春秋战国多见 |
| **汲壶** | — | 汲水之壶形器 |
| **浴缶** | — | 浴沐相关缶形器 |

<br>

### 乐器

| 器名 | 拼音 | 形制与用途概要 |
| :--- | :--- | :--- |
| **铙** | náo | 大口朝上执奏或植奏；商代大型铙著名 |
| **钟** | zhōng | 甬钟、纽钟等；编悬成肆。西周至战国礼乐核心 |
| **镈** | bó | 大型纽钟类，常特悬 |
| **钲** | zhēng | 军旅／礼仪敲击器 |
| **铎** | duó | 有舌可振之铃形器 |
| **铃** | líng | 小型，车马、建筑、服饰亦用 |
| **句鑃** | gōu diào | 越系等特色打击乐器 |
| **錞于** | chún yú | 坛形或虎钮，军旅／仪式乐器，长江流域多见 |
| **鼓** | gǔ | 铜鼓（南方滇桂等系）与鼓座等 |

曾侯乙编钟显示战国乐律铭文与铸造工艺高峰。

<br>

### 兵器

| 器名 | 拼音 | 要点 |
| :--- | :--- | :--- |
| **戈** | gē | 勾兵；援、内、胡、穿结构演变是断代要点 |
| **戟** | jǐ | 戈矛合体 |
| **矛** | máo | 刺兵 |
| **铍** | pī | 剑形矛类兵器 |
| **钺** | yuè | 斧形，礼仪色彩浓 |
| **刀** | dāo | 边刃兵器 |
| **剑** | jiàn | 春秋战国发达；茎、腊、格、首 |

| **矢镞** | shǐ zú | 箭头 |

### 杂器

#### 生活用具

镜、带钩、洗、耳杯、樽（zūn）、炭炉、薰炉、熨斗、鐎斗（jiāo dǒu）、灯等。战国秦汉生活铜器比重大增。

#### 车马器

軎（wèi）、辖（xiá）、毂饰、銮铃、衔、镳（biāo）、当卢（dāng lú）、马冠、铜泡、节约等。殷墟与西周车马坑中成套出土。

#### 货币、度量衡、符玺

布币、刀币、铜贝、圜钱；尺、量、权；符、玺印。属青铜文化的制度延伸，马承源书归入杂器。

<br>

## 纹饰

对应马承源书第三章。

### 布局与时代印象

商至西周早期：主题纹加地纹（如云雷纹），中轴对称，庄严繁缛；精品常见「三层花」（地纹＋主题＋脊棱／羽状）。西周中晚期：变形、几何化加强。春秋战国：蟠螭、蟠虺细密铺地，嵌错与线刻画像兴起。

李松通识写法强调从**造型张力、工艺精度、纹饰与器形配合**欣赏青铜艺术；分期断代仍须回到马承源教材的标准器与类型学，二者分工不同。

### 主要类别

| 类别 | 说明 |
| :--- | :--- |
| **兽面纹** | 习称饕餮（tāo tiè）纹；以鼻梁为中线的对称兽面，商至西周早盛 |
| **龙纹类** | 夔（kuí）龙、蟠龙、交龙等 |
| **凤鸟纹类** | 凤鸟、鸟纹；西周早中期多见 |
| **动物纹** | 象、虎、蝉、龟、枭等 |
| **兽体变形纹** | 窃曲、鳞带、重环等 |
| **火纹** | 圆形火光状（旧或称圆涡纹） |
| **几何纹** | 云雷、弦纹、乳钉、波曲等 |
| **人物画像** | 战国嵌错或线刻宴乐、攻战、采桑等 |

纹饰是断代的重要依据，但须与形制、铭文、出土单位综合，忌单凭「有兽面即商」。

<br>

## 铭文

对应马承源书第四章。金文是商周史料的直接来源之一。

### 发展概貌

商：族徽、日名、简短记事。西周：册命、征伐、赏赐、诉讼、土地交换等长篇。春秋战国：多短铭、媵辞、物勒工名；书体与装饰性增强。

### 常见内容格式（教材归纳）

徽记；祭辞；册命；训诰；记事；追孝；约剂；律令；符节诏令；媵辞；乐律；物勒工名等。一篇铭文可兼数类。

### 书体

从商代填实书法，到西周早期肥笔、中晚期线条变化，再到春秋战国各国文字异形（如鸟虫书）。释读须据拓本、标准字编，勿用简化字臆测。

### 研究价值与限度

可补证史书、考证人物地名历法；亦有伪刻铭文，鉴定时铭文真伪为独立环节（见「鉴定」）。

<br>

## 地域

对应马承源书第六章。中原礼器传统之外，各区有自身器类、纹饰与合金习惯。下列按教材分区概括，细节以考古报告为准。

| 区域 | 要点 |
| :--- | :--- |
| **冀辽吉及内蒙古东部** | 北方系兵器、饰品；与商周中原有交流 |
| **晋北、陕北、河套** | 鄂尔多斯式青铜器：兵器、马具、动物纹牌饰 |
| **成渝** | 三星堆、金沙等：尊、罍、神像、树、面具等，礼器系统与中原有别 |
| **滇黔** | 滇文化贮贝器、铜鼓、扣饰；战国秦汉精彩 |
| **湘桂粤** | 南方铜铙、铜鼓传统；宁乡铜器群等 |
| **苏皖浙赣** | 吴越剑、句鑃、印纹硬陶区相关青铜；土墩墓系统 |

观展时须问：此器属**中原礼器序列**，还是**区域文化**？混称「商周青铜」易抹平地方性。

<br>

## 鉴定

对应马承源书第八章。传世器有伪作、真器假铭、拼凑改造。辨伪宜分途检查：

| 途径 | 观察 |
| :--- | :--- |
| **铸造** | 范线、垫片、浇口、壁厚是否合理；失蜡／翻模痕迹 |
| **器形** | 是否拼自不同器；足耳是否后配；比例是否合时代 |
| **铭文** | 凿刻与范铸铭差别；字口锈色；内容是否杜撰 |
| **纹饰** | 纹与地是否一体铸成；后刻纹刀口 |
| **锈蚀** | 矿物锈层次、分布；假锈、胶固锈 |
| **科学检测** | 合金成分、铅同位素、CT 等（馆方条件） |

无科学检测时，结论宜留有余地。出土有明确单位者，可信度通常高于来历不明的传世器。

### 著录简史（教材附录意识）

马承源书附录有「青铜器著录编年简介」。大势可记：宋代金石学兴起，有系统图录、款识著录传统（如吕大临《考古图》、王黼等《宣和博古图》一类）；元明续有著录；清代金石、金文之学大盛；近代田野考古与科学发掘后，著录与分期建立在出土单位之上。观展时「著录」「出土」信息层级不同：仅见著录的传世器，与有发掘报告的器，使用方式有别。

<br>

## 观法清单

1. **器类**：食／酒／水／乐／兵／杂？生僻名对照上表拼音与形制。
2. **组合**：是否鼎簋、爵觚斝、盘匜等制度性组合？
3. **时代风格**：壁厚、足式、耳式、口沿；兽面繁缛还是窃曲／蟠螭？可对照马承源五期印象。
4. **铭文**：有无？铸铭还是刻铭？内容大类？
5. **工艺**：范线、分铸、嵌错、鎏金？
6. **地域**：中原礼器还是蜀、滇、北方草原等？
7. **真伪与信息量**：出土单位？仅供赏形还是可作史料？

<br>
