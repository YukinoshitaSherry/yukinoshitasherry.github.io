## 脉络总览

以朝代为经、品种与工艺为纬。读实物时宜先辨三层：

* **胎**：黏土选择、淘洗、加砂/高岭；陶 ↔ 硬陶 ↔ 原始瓷 ↔ 瓷
* **釉与装饰**：无釉 / 灰釉 / 高温色釉 / 釉下彩 / 釉上彩；刻划印贴绘
* **窑业组织**：窑炉结构、烧成气氛、民窑与官窑、外销路线

跨时代技法见下节**工艺**（窑炉、装烧、成型、化妆土、釉路、釉上／釉下原因、气氛呈色、烧成次序及绞胎三彩紫砂等）。

分期依原书十章；下文按期展开，每期尽量覆盖：品种与产地、工艺突破、造型装饰、外销与交流。

## 工艺

朝代篇按时代展开；此处抽提**反复出现、馆藏最宜对照**的工艺条目。读实物时可先问：窑怎么烧、坯怎么装、**彩在釉上还是釉下（几次火）**、装饰靠刻还是绘。

釉下／釉上的**原因**（耐温与色谱）见「彩绘层次」；素烧→釉烧→烤花次序见「烧成次序」；气氛与铁铜钴呈色见「气氛与呈色」。下列各节相互参照，不互相替代朝代篇中的窑口专论。

<br>

### 窑炉

窑炉决定**最高温度、升温曲线、气氛（氧化／还原）与冷却速度**，直接约束能烧什么釉、什么彩。

| 类型 | 形制要点 | 优势与局限 | 代表时空 |
| :--- | :--- | :--- | :--- |
| **穴窑／竖穴窑** | 早期半地穴，火膛与窑室分化尚简 | 高于露天堆烧；控温粗 | 新石器 |
| **馒头窑**（马蹄窑） | 圆形／马蹄形窑室，火膛＋窑箅＋烟道；多半地挖 | 北方主流；装窑量相对有限；用煤时易生烟、气氛偏氧化 | 商周—宋元北方诸窑、汝民窑大窑 |
| **龙窑** | 依山坡斜长条窑，分段设投柴孔（腰门） | 升温快、装烧量大、易维持还原；抽力强、窑体薄则冷却快 | 商以降南方；越、龙泉、景德镇早期 |
| **椭圆形小窑** | 体量小，窑室扁椭圆 | 精控温与气氛；产量低，宜宫廷窗口窄之品种 | 汝官窑 |
| **葫芦窑／镇窑**（蛋形窑） | 景德镇：前室小、后室大如葫芦／蛋形 | 容量大，窑内前后上下温度分区，可同窑烧不同品种 | 宋元以后景德镇；明清御窑／民窑主流 |

#### 龙窑与馒头窑对照

* **龙窑**：自然抽力强，薄窑体快冷，利于青瓷还原，又减少冷却期铁的**二次氧化**（二次氧化则青瓷易泛黄）。分段投柴可调节各段温度。坡度约十余度常见；过陡火焰过快、过缓则升温困难。
* **馒头窑**：火焰自火膛经窑箅上升再折向烟道（倒焰或半倒焰），温度场相对均匀，但北方多用煤／柴，还原焰维持难于南方龙窑，故北方铁青釉往往更难烧出纯正青绿，多偏青黄、茶黄。
* **燃料与季节**：柴灰参与釉料（草木灰釉）；「九秋风露越窑开」反映湿度、风向影响抽力与气氛。煤灰、硫等杂质可致釉面瑕疵。

#### 看窑炉痕迹（馆藏）

匣钵粘疤、落渣、烟熏斑、阴阳面（向火面釉熔更好）、同窑不同窑位的色差，均可反推装窑方式与气氛是否均匀。

<br>

### 装烧

装烧解决三件事：防粘连、防落渣烟熏、提高窑位利用率。选择直接决定器表是「满釉无芒」还是「芒口实用」。

| 方法 | 做法 | 器表痕迹 | 用途／意义 |
| :--- | :--- | :--- | :--- |
| **裸烧／叠烧** | 直接入窑或器物相叠 | 粘疤、涩圈、变形 | 早期、粗器；成品率低 |
| **匣钵** | 坯入耐火匣钵再入窑；一匣一件或多件 | 器表相对洁净；匣钵内壁或有釉泪粘连 | 唐岳州已较早用；宋以后南北普及 |
| **垫饼／垫柱／垫砂** | 足底垫耐火饼、柱或砂粒 | 圈足涩圈、垫痕、火石红 | 龙泉、青白瓷、大量民窑碗足 |
| **支钉／裹足支烧** | 通体施釉，细钉支起 | 芝麻钉痕（汝常 3～5；亦有更多） | 汝、官等宫廷满釉 |
| **覆烧＋支圈** | 口朝下叠装于支圈／垫圈 | **芒口**（口沿无釉）；内底或亦涩 | 定窑大宗碗盘；常包金银铜扣 |
| **支烧具／托珠** | 间隔坯体的耐火珠、条 | 点状、条状支痕 | 先秦原始瓷至六朝渐精 |
| **涩圈叠烧** | 内底刮一圈釉再叠置 | 内底涩圈 | 金元民窑常见，提产量 |

**满釉 vs 芒口**：宫廷青瓷（汝、官）追求满釉玉质感，故用支钉，宁可钉痕；定窑面向市场，覆烧大幅提高装窑密度，芒口以金属扣补救观感与触感。观展时先看口沿与足端，往往即可缩小窑口范围。

<br>

### 成型

装饰与施釉之前，先有成型。成型方式在器内壁、接痕、厚薄上留下证据。

| 方法 | 做法 | 痕迹与适用 |
| :--- | :--- | :--- |
| **泥条盘筑** | 泥条螺旋叠筑，内外抹平 | 大型瓮罐；内壁或留叠层；先秦硬陶、原始瓷多见 |
| **轮制拉坯** | 快轮离心拉起器壁 | 碗盘壶罐主体；内底螺旋纹、外底线割痕 |
| **模制** | 内外模或对开模压坯粘合 | 扁壶、俑、花口、印花器；内壁接缝、按擦痕 |
| **镶器／方器** | 泥片裁切粘接 | 方形瓶、琮式瓶；棱角接痕 |
| **接胎（接坯）** | 大件分段拉坯，肩腹粘接 | 元明大罐大瓶肩腹接痕、台阶；非必粗制 |
| **修坯** | 半干时利刀修薄、挖足 | 定窑薄胎、影青；刀痕规整为精工标志 |

阴干过快易裂；大件须控制湿度。唐花枕、俑等常模制主体再手修细部。

### 胎与化妆土

#### 原料与加工

* **淘洗、练泥、陈腐**：瓷土／陶土经粉碎（东汉起江南或已用水碓）、淘洗去粗砂铁屑，练揉排气，陈腐增塑性与均匀性。
* **夹砂／加瘠**：炊器加砂或熟料，提高耐热急变，防炸裂；细瓷则追求低杂质、低气孔。
* **瓷石与高岭**：南方多石英—绢云母质**瓷石**；景德镇元以后普遍**瓷石＋高岭土**（二元配方），提高 Al₂O₃ 与耐火度，大件高温不易塌，支撑青花大器与高温色釉。宋青白瓷仍以瓷石为主，不宜径称已成熟二元。
* **胎色**：铁钛含量决定灰、白、香灰、铁骨；还原／氧化亦影响露胎呈色（火石红等）。

#### 化妆土

白色或浅色泥浆罩于胎表：

* **功能**：遮盖灰胎、粗胎；为透明釉与彩绘提供「白纸」；改善釉色纯净度。
* **时代与窑口**：东晋南朝青瓷已普遍；唐巩义白瓷、宋磁州窑、部分定窑粗器依赖化妆土。
* **与真白瓷区别**：邢窑精白、永乐甜白等多靠低铁胎本身发白，可不施或少施化妆土；磁州「白地」几乎必有化妆土，断面可见白层夹在胎与釉之间。

<br>

### 装饰（坯上）

坯上装饰在施釉前完成（或与釉结合一次烧），与釉上彩绘不同层。

| 技法 | 工序要点 | 视觉效果 | 代表 |
| :--- | :--- | :--- | :--- |
| **拍印** | 拍子拍外壁，内抵手；几何印模 | 方格、米字、云雷等 | 印纹硬陶、原始瓷 |
| **刻花** | 半干坯上斜刀／直刀刻 | 线条有深浅；釉填凹处「出筋」 | 定、耀州、青白 |
| **划花** | 尖工具划线 | 细线流畅 | 定、越、青白 |
| **篦划** | 篦状多齿工具划 | 水波、篦纹地衬托主题刻花 | 耀州刻花配套 |
| **印花** | 模范压印 | 纹样规整繁密、批量一致 | 定窑中晚、青白、元枢府 |
| **剔花** | 剔去化妆土：留花剔地或留地剔花 | 花与地强烈凹凸对比 | 磁州白剔／黑剔 |
| **珍珠地划花** | 划花后，地戳密珠点 | 类金银器錾花地 | 磁州系，河北观台尤精 |
| **堆塑／贴塑／镂空** | 泥条附加、模贴、透雕 | 立体装饰 | 谷仓罐、莲花尊、转心瓶 |
| **绞胎** | 深浅泥绞合后拉坯／镶片 | 胎内木理纹通透 | 唐巩义花枕；宋当阳峪 |
| **木叶／剪纸贴花** | 叶或剪纸入釉一次烧 | 叶脉、对称剪纸纹 | 吉州窑 |

**绞胎详说**：产地以河南**巩义窑**（唐黄冶、白河一带）为主，非河北磁州；仿木纹、犀毗漆器。白褐两色泥收缩率须接近，否则开裂。窑址有素烧花枕残片，证可先素烧再施透明／黄釉。枕面常镶团花、菱形纹，侧面用较简木理纹以省料。「杜家花枕」「裴家花枕」为作坊款。宋河南**当阳峪**续烧绞胎，并有**绞釉**（釉面搅色，与胎内绞纹有别）。

**磁州黑白花勿混**：河北磁州窑招牌是**白地黑花**（白化妆土地上绘黑／褐彩）；**黑地白花**另属剔填一类，数量远少于白地黑花。定窑在曲阳，是白瓷刻印花，不是黑白彩绘。详见宋「磁州窑系」节。

### 釉路：钙釉与铅釉

#### 两类助熔体系

| | **高温钙（灰）釉** | **低温铅釉** |
| :--- | :--- | :--- |
| 助熔 | CaO（石灰、草木灰、釉灰等）；后期常兼 K₂O／Na₂O（石灰碱釉） | PbO（铅丹、密陀僧等） |
| 温度 | 约 1200℃ 以上（成熟瓷更高） | 约 700–1000℃ |
| 路线 | 原始瓷→青瓷→白瓷→高温色釉（霁红、霁蓝等） | 汉绿釉、唐三彩、辽三彩、部分素三彩 |
| 特点 | 坚致、与胎结合好、耐用 | 色艳、流动性强、易溶蚀（墓中「银釉」） |
| 呈色 | 铁→青（还原）；铜→红（还原）／绿（氧化）等 | 铜绿、铁黄褐、钴蓝等，低温即鲜 |

二者长期并行：南方走钙釉成瓷；北方丧葬明器多用铅釉。钧窑在高温钙釉中引入铜，靠气氛窑变出红紫斑，仍属高温系统，不是铅釉。

#### 施釉方法

| 方法 | 做法 | 效果 |
| :--- | :--- | :--- |
| **浸釉／蘸釉** | 坯浸入釉浆 | 内外较匀；口沿或垂釉 |
| **荡釉** | 釉浆倒入器内荡匀倒出 | 内壁 |
| **浇釉** | 釉浆浇于器表 | 大件、厚釉 |
| **刷釉** | 刷涂 | 局部、补釉 |
| **吹釉** | 管吹成雾 | 薄匀；洒蓝、胭脂水 |
| **洒釉／点釉** | 异色釉点洒 | 花釉、玳瑁、三彩斑 |

**多次施釉／素烧**：龙泉粉青梅子青、钧釉常反复施釉或先素烧再釉烧，以获厚釉而不流塌、不开裂。薄釉透明者（定窑白、部分影青）一次即可。

#### 唐三彩流程（铅釉代表）

**塑形 → 素烧（约 1000℃）→ 施铅釉（铜绿／铁黄褐／钴蓝等）→ 低温烧（约 800℃）**。素烧使坯有强度并控制吸釉；铅助熔使低温即熔，着色氧化物浸润交融成斑。

### 彩绘层次

彩绘按颜料落在**釉层哪一侧**、经**几次火**，分成釉下与釉上两大路。选型首先不是审美偏好，而是**呈色氧化物耐温极限**与**釉熔温度**是否匹配。

#### 为何分釉下／釉上

| | **釉下彩** | **釉上彩** |
| :--- | :--- | :--- |
| **颜料位置** | 胎上（或化妆土上）→ 再罩透明釉 | 已成瓷的白釉（或涩胎）表面 |
| **主烧成** | 与胎釉同窑，**一次高温**（约 1200–1300℃） | 器先高温成瓷，再**低温烤花**（约 700–850℃） |
| **可用色料** | 须扛高温：钴（蓝）、铜（红／绿视气氛）、铁（褐黑）、锰等 | 耐温低的亦可：矾红、金红（胭脂）、锑黄、珐琅料、金彩等 |
| **优点** | 彩被釉保护，耐磨、耐酸碱、不掉色；画面与釉一体 | 色谱宽、可渲染、可金彩；宜细笔、油画式／工笔效果 |
| **局限** | 高温下许多艳色分解／挥发／变相，色谱窄；铜红极难控 | 彩在釉外，久用可磨损；二次烤花增成本与破损风险 |
| **代表** | 青花、釉里红、长沙褐绿彩、磁州白地黑花 | 五彩、粉彩、珐琅彩、广彩、矾红描金 |

**根本原因（写清）**：

1. 透明瓷釉必须高温才充分玻化、与胎结合，故「成瓷火」高。
2. 朱红、粉红、娇嫩黄、多数珐琅色、金箔在高温中会**分解、挥发或发乌**，无法与成瓷火同窑存活。
3. 历史上能稳定进釉下、又具强装饰力的，主要是**钴、铁、铜（及部分锰）**——色谱天然偏蓝、褐黑、红／绿。
4. 要红黄紫粉青绿金齐备，只能：**先**高温成瓷（或先烧白釉器），**再**在釉面用低温熔剂把艳色烤牢——釉上彩因此必然出现。
5. 斗彩则折中：能耐高温的钴先在釉下勾线，不能耐高温的色在釉上填，两次火各烧该烧的料。

#### 釉下彩工序（逐步）

以青花为典型，釉里红、磁州黑花同理替换色料：

1. **制坯**：拉坯／模制 → 修坯 → 阴干。大件或精细器可先**素烧**定型，降低运坯破损，并使坯吸水性稳定，利绘细线。
2. **（可选）施化妆土**：磁州、部分粗白胎必要；细白胎青花可直接绘于坯。
3. **绘彩**：钴料（珠明料、浙料、苏麻离青等）或铜料、高铁料，用水或胶水调和，勾线、涂染、分水。笔触被下一道釉覆盖，故须预判烧后晕散。
4. **施透明釉**：浸、荡、吹等，使彩完全处于釉下。釉厚薄影响呈色深浅与晕散。
5. **高温一次烧成**：约 1200–1300℃；还原焰下钴蓝稳定，铜红（釉里红）需强还原且窗口极窄，铁呈褐黑（磁州）。
6. **出窑**：彩料在釉—胎界面附近固着，透过釉看见，故名釉下。

釉厚积料处易晕散、结晶（苏麻离青**铁锈斑**下凹）；釉薄处色淡。康熙**分水**靠料中含水量不同分出头浓、正浓、二浓、正淡、影淡，近水墨皴染。

| 品种 | 呈色剂 | 气氛要点 | 备注 |
| :--- | :--- | :--- | :--- |
| **青花** | 钴 | 还原／中性均可，相对稳定 | 元明清装饰主脉；料分进口／国产见青料专节 |
| **釉里红** | 铜 | **强还原**，温域窄 | 易灰、花、发黑；精品少 |
| **青花釉里红** | 钴＋铜 | 同窑兼顾两料 | 元明困难品种 |
| **长沙褐绿彩** | 铁／铜 | 高温釉下 | 唐外销大宗；诗文、胡人纹 |
| **磁州白地黑花** | 铁（褐黑） | 化妆土＋透明釉 | 民间釉下绘路径；开明清彩绘先河 |

#### 釉上彩工序（逐步）

1. **高温成瓷**：先烧出白釉器或涩胎——景德镇称「白胎」「白釉器」。此步已完成胎釉烧结，器已是「瓷」。
2. **绘彩**：在釉面用低温彩料勾勒、平涂、渲染。粉彩须先施**玻璃白**（含砷等乳浊成分的白料）打底，再以油料／胶料晕染出明暗。珐琅彩多用进口珐琅料（含金之紫红等）。五彩多平涂硬色，少晕染。
3. **烤花**：入专门烤花窑或炉膛，约 **700–850℃**（随彩种略有出入）。此温度只熔化彩料中的低熔点熔剂（铅硼等体系常见），使彩附着釉面，**绝不把整器瓷釉再次高温熔化**——否则器变形、彩与釉混糊。
4. **冷却出窑**：金彩、部分料有时再经更低温罩固。
5. **检验**：缺彩、缩釉、惊釉（炸纹）等次品剔除；官窑瑕疵或打碎（明代「有瑕弃毁」传统）。

因彩浮于釉表，侧光可见微凸笔触与堆料；盘口、棱角、常摩处年久彩薄，是使用痕迹，也是辨伪时需综合判断的现象（仿者或故意做旧）。

| 品种 | 呈色／工艺要点 | 盛期与备注 |
| :--- | :--- | :--- |
| **五彩** | 釉上红绿黄紫黑等平涂，色硬清朗 | 嘉万、康熙；可与青花合用成青花五彩 |
| **粉彩** | 玻璃白＋渲染，色阶柔、立体 | 雍正最精；乾隆趋繁 |
| **珐琅彩** | 珐琅料，常宫廷画；诗、款、印 | 康创、雍乾峰；存世少 |
| **矾红／珊瑚红** | 低温铁红 | 可描金；嘉靖后曾代铜红作祭红用途之一 |
| **金彩／描金** | 金粉或金液低温固着 | 广彩、宫廷重器 |
| **广彩** | 景德白胎，广州加金彩粉彩 | 外销欧洲；金边繁缛 |

#### 斗彩、素三彩与吹釉

| 类型 | 层次逻辑 | 代表 |
| :--- | :--- | :--- |
| **斗彩** | 釉下青花勾轮廓 → 高温成瓷 → 釉上按线填彩 → 烤花；「斗」即釉下线与釉上色相逗合 | 成化鸡缸杯、天字罐；雍正斗彩 |
| **素三彩** | 素胎或涩胎上低温黄、绿、紫等，**少用红**（故称「素」） | 明正德、清康熙 |
| **吹釉／洒釉** | 管吹使釉或彩成雾状、斑点 | 洒蓝（雪花蓝）、胭脂水薄釉 |

斗彩的工艺意义：同一件器**兼有**釉下与釉上——钴线进高温，红黄绿等进低温，两次火各烧适合自己的料，同时解决「要细线稳定」与「要色谱齐全」。

#### 分水、粉彩、珐琅（技法补记）

**分水（混水）**：康熙青花以含水量不同的钴料分染，分出头浓至影淡五色阶，近水墨皴染，为翠毛蓝表现力的核心；依赖坯吸水与笔上水量的配合，烧后层次仍在釉下。

**粉彩**：异于五彩之平涂硬色；玻璃白造成乳浊与厚度，渲染后有粉润、凹凸感，宜花鸟阴阳。

**珐琅彩**：进口料呈色饱和；画工常按宫廷画样；小件碗盘瓶为主；与粉彩之别在料性、画风与生产制度（珐琅彩多造办处画彩）。

> [!NOTE]+ 观展怎么辨釉上／釉下
>
> - 彩在釉**里面**、釉面光滑一体、盘口磨损后纹样仍清晰 → 多釉下
> - 彩微凸于釉面、侧光见笔堆、棱角处易脱彩 → 多釉上
> - 青花勾线清晰＋线内填红黄绿 → 先想斗彩
> - 红绿黄齐全又极鲜艳 → 多釉上（或斗彩填色）；高温一次烧成的匀净「大红」极难，馆藏霁红、郎窑红是**色釉**不是彩绘
> - 断面或窑址标本：化妆土＋黑彩＋透明釉三明治 → 磁州白地黑花（釉下）

### 气氛与呈色

烧成时窑内氧气是否充足，决定金属氧化物价态，从而决定颜色。与「釉上／釉下」是另一条正交的知识轴。

| 呈色剂 | 氧化焰（供氧足） | 还原焰（缺氧，CO／H₂ 多） | 典型品种 |
| :--- | :--- | :--- | :--- |
| **铁 Fe** | Fe³⁺ → 黄、褐、酱、柿红 | Fe²⁺ → 青、青绿、天青 | 青瓷；氧化则黄釉／酱釉 |
| **铜 Cu** | Cu²⁺ → 绿、孔雀绿 | Cu⁺／胶体铜 → 鲜红、霁红、郎窑红、豇豆红 | 铜红釉；局部氧化则绿苔点（豇豆红） |
| **钴 Co** | 蓝（较稳） | 仍以蓝为主 | 青花、霁蓝、天蓝 |
| **金 Au** | — | 低温烤花呈胭脂红 | 胭脂水（釉上，非高温一次） |
| **锑 Sb** | — | 低温黄 | 雍正柠檬黄（釉上） |

**二次氧化**：还原烧成的青瓷若冷却阶段窑内进氧，Fe²⁺ 再被氧化，釉面可泛黄——故龙窑快冷、密封与投柴制度影响「青色是否纯正」。

**温度窗口**：汝官约 1200±20℃；铜红约 1250–1320℃ 且气氛极敏感；烤花 700–850℃。同一配方，温度偏高偏低都会改色、改乳浊度（如汝窑钙长石析晶过多回熔则乳光减）。

<br>

### 烧成次序（总览）

把窑炉、釉路、彩绘串成时间线，解释「为什么要二烧、三烧」：

| 次序 | 内容 | 温度约 | 目的 |
| :--- | :--- | :--- | :--- |
| ① 素烧（可选） | 坯干后低温／中温定型 | 约 800–1000℃ | 运坯、绘细、吃釉均匀；唐三彩、部分绞胎、厚釉器、精细青花常用 |
| ② 釉烧／成瓷 | 施釉（及釉下彩）后高温 | 约 1200–1300℃＋ | 胎釉烧结；釉下彩在此步一并完成 |
| ③ 烤花（釉上） | 成瓷后绘彩再烧 | 约 700–850℃ | 只固着釉上彩，不毁器、不重熔瓷釉 |
| （铅釉明器专线） | 素烧→施铅釉→低温釉烧 | 釉烧约 800℃ | 唐三彩等；与高温瓷分途 |

**铁律**：高温钙釉成瓷与低温铅釉／烤花是两套温度制度；若同器既要高温瓷性又要低温艳彩，必须**先高温、后低温**。若颠倒，低温彩与铅釉会在成瓷火中烧飞或流毁。

**次数与品种对应**：

* 单色青瓷／白瓷／多数青花：可一次高温（或素烧＋釉烧）。
* 釉上五彩、粉彩、珐琅：至少成瓷＋烤花两火。
* 斗彩：釉下高温＋釉上烤花，两火（坯或另素烧则更多）。
* 唐三彩：素烧＋铅釉低温，两火，且通常不成高温瓷。

### 特种工艺

#### 唐三彩

低温铅釉陶（**非**高温瓷）。白／红胎雕塑或模制，素烧后浇／点黄、绿、白、褐、蓝等铅釉，二次低温烧成，釉汁熔流交融。「三彩」泛指多彩，单彩、二彩亦常见。多明器（俑、马、骆驼、建筑模型），亦有日用器。主要产地：**河南巩义黄冶窑**、陕西铜川黄堡、河北邢台／内丘一带等。工艺要点在塑工与铅釉流动性控制，以及素烧吸釉程度，而非成瓷烧结。盛唐写实高峰；辽三彩、金三彩、日本奈良三彩为后续支脉。

#### 绞胎

深浅两色（或白褐）坯泥绞合、切片、镶贴后成型，施透明／黄釉烧成，胎内纹理通透如木纹、大理石。唐代以**巩义窑**为中心（花枕、三足盘、小杯等；「杜家花枕」「裴家花枕」款）；宋河南**当阳峪窑**续烧绞胎与绞釉。勿与磁州窑白地黑花彩绘混为一谈——一是胎泥绞纹，一是化妆土上绘彩。

#### 花釉与窑变

唐鲁山等**花釉**：黑褐底上洒月白斑，高温窑变。宋钧铜红窑变、吉州玳瑁、清炉钧，皆属「底釉＋异色料＋气氛／温度」路线，与单色匀净的霁红、霁蓝不同。窑变强调过程不可全控，「入窑一色，出窑万彩」。

#### 建盏析晶

黑釉高铁，冷却制度合适时析出兔毫、油滴、曜变等铁结晶，属**釉内析晶装饰**，非彩绘、非绞胎。冷却过快或过慢都难出理想结晶；曜变极稀。

#### 宜兴紫砂

非瓷非普通陶：用宜兴特有紫砂泥（紫泥、红泥、团泥等），**一般不施釉**（清以后偶见挂釉品种除外），一次烧成，靠泥色、造型、印章与透气性。明供春、时大彬以降壶艺成熟；清陈鸣远、邵大亨等名家。与景德镇釉上彩绘系统并列的另一条「文人器用」工艺线。

#### 德化白瓷与瓷塑

高白度瓷土，厚釉温润称「象牙白」「猪油白」。何朝宗等以**模塑＋手修衣纹**做观音、达摩，外销称 Blanc de Chine。重点在胎釉白度与雕塑，而非青花彩绘。

#### 石湾窑

「广窑」陶胎厚釉，善仿钧、翠毛釉及人物陶塑、建筑花脊；民窑造型活泼，与官窑样制异趣。

### 观法清单

对照馆藏时可按序检查（由外而内、由工艺而窑口）：

1. **窑与装烧**：有无匣钵光洁？芒口还是支钉？足端垫饼、垫砂还是满釉裹足？涩圈叠烧？
2. **胎**：断面是否有化妆土白层？香灰／铁骨／细白／夹砂？接胎痕、模接缝？
3. **釉**：钙釉玻璃质坚亮，还是铅釉酥光易蚀？厚釉多次（垂流、桔皮）还是薄釉透明（泪痕、出筋）？
4. **呈色与气氛**：铁青是否纯正（或泛黄＝还原不足／二次氧化）？铜红是否匀、是否带绿苔？钴蓝晕散与铁锈斑？
5. **装饰在哪一层**：刻划印在坯上？彩在釉下（耐磨、色谱窄）还是釉上（可艳、可磨损）？斗彩则两层都有。
6. **特殊工艺**：绞胎看断面通纹；木叶看叶脉；析晶看兔毫油滴；紫砂无釉；三彩铅釉流淌。
7. **烧了几次**：仅高温一次？另有素烧？另有烤花（釉上彩、斗彩填色必有）？铅釉明器是否两火低温？
8. **窑口归类**：先定工艺类型（青瓷／白瓷／釉下绘／釉上绘／铅釉／绞胎），再对照产地（如绞胎→巩义；白地黑花→磁州观台彭城；覆烧芒口白瓷→定窑）。

## 新石器时代

对应原书第一章（p.1–50）。陶器发明是人类最早主动利用化学变化（黏土经火变而坚致）的成果之一，与定居农业、贮粮汲水、烹煮食物等需求同步。中国境内早期线索可溯至约万年前后；北方磁山（约前 8000–7000）、裴李岗（约前 7000–6000）与南方仙人洞、甑皮岩等遗址，分别奠定黄河流域仰韶—龙山与长江流域诸文化的制陶基础。此期完成选料、成型、窑炉与装饰的基本技术库存，为夏商周灰陶、印纹硬陶与原始瓷奠基。

> [!NOTE]+ 读此期实物
>
> - **彩陶**：仰韶半坡、庙底沟类型；几何纹、动物纹、人面纹
> - **黑陶**：龙山快轮、蛋壳陶；薄胎高柄杯、袋足鬶
> - **南方系**：河姆渡夹炭陶、良渚黑陶与刻纹；印纹软陶先声
> - **工艺轴**：手捏—盘筑—轮制；露天堆烧—穴窑—馒头窑前身

<br>

### 起源与工艺轴线

#### 陶器出现的社会背景

新石器时代早中期，农业定居点扩大，对贮盛、炊煮、滤水器具的需求推动制陶业独立。陶器使粮食加工、发酵、储存与礼仪活动具备稳定容器；与石器、骨角器、木器并列为日常用具体系。早期制陶常与女性家庭劳作相关；轮制与专业窑炉发展后，制陶渐趋专业化、区域化。

#### 成型技术演进

| 阶段 | 方法 | 特征与局限 |
| :--- | :--- | :--- |
| **手捏** | 手捏成器 | 小型、厚壁；适用于钵、罐雏形 |
| **模制** | 内模或外模 | 形制规整；适用于簋、豆等对称器 |
| **泥条盘筑** | 泥条螺旋叠筑，内外抹平 | 大型瓮、罐、釜；内壁可留叠层痕迹 |
| **慢轮修整** | 盘筑后于慢轮上修口沿、腹壁 | 过渡至轮制 |
| **快轮拉坯** | 快轮离心拉坯 | 龙山晚期普及；器壁薄、形制匀整 |

#### 烧成与窑炉

* **露天堆烧**：陶器与燃料相间堆放，温度有限，多烧红陶、褐陶。
* **横穴窑／竖穴窑**：半地下穴室，火焰经烟道通过器堆；温度可达约 900–1000℃，可烧灰陶、黑陶。
* **馒头窑前身**：新石器晚期黄河流域已见圆形竖穴窑，窑室、火膛、窑箅分置，为商周馒头窑直接先声；南方多见沿山坡的**长形穴窑／坡地窑**，利用自然坡度延长火焰路径（成熟龙窑形制多认为战国—汉以降才普遍）。

气氛控制决定呈色：氧化焰多红陶、褐陶；还原焰或封窑烟熏可获灰陶、黑陶。原料含铁量、颗粒粗细亦影响胎色与强度。

#### 装饰手法

划纹、戳印、堆贴、彩绘、磨光等并用。彩陶以黑、红、白、黄等矿物颜料在素烧前或素烧后绘制，再经二次烧成固定；几何纹、动物纹、人面纹构成仰韶彩陶装饰主体。磨光黑陶则靠反复打磨与渗碳工艺获光泽，不依赖彩绘。

<br>

### 黄河流域

#### 裴李岗与磁山（前 8000–5000 前后）

河北**磁山**（约前 8000–7000）、河南**裴李岗**（约前 7000–6000）等早期遗址出土红陶、灰陶，器形以罐、钵、壶、鼎雏形为主，多为手捏或简单盘筑，胎厚，火候较低。裴李岗文化陶器以红陶为主，部分施红彩；磁山文化夹砂陶比例高，适应炊煮。二者代表黄河中游最早一批农业聚落制陶，为仰韶文化提供直接来源。

#### 仰韶文化彩陶

仰韶文化（约前 5000–3000）以泥质红陶为主，彩陶发达，分若干类型：

| 类型 | 分布 | 彩陶与器形特征 |
| :--- | :--- | :--- |
| **半坡类型** | 陕西关中 | 人面、鱼纹、网纹等具象纹；尖底瓶、盆、钵、罐 |
| **庙底沟类型** | 豫西、晋南、关中 | 花瓣纹、弧边三角纹等抽象几何纹；双唇口尖底瓶 |
| **大河村类型** | 郑州一带 | 白衣彩陶；盆、罐、豆组合 |
| **后岗类型** | 豫北、冀南 | 红陶为主，彩陶较少；与仰韶、大汶口交汇 |

半坡类型彩陶重具象装饰，庙底沟类型几何纹高度抽象，影响后续马家窑彩陶谱系。器形以尖底瓶、盆、钵、罐、瓮为大宗；三足器（鼎、鬲雏形）渐增。

#### 大汶口与龙山文化

大汶口文化（约前 4300–2500）承仰韶而启龙山，白陶、黑陶、快轮技术先行。山东龙山文化（约前 2500–2000）代表黄河流域新石器晚期高峰：

* **黑陶**：快轮拉坯，胎薄如蛋壳（**蛋壳陶**），色黑光亮；高柄杯、豆、鬶、斝、鼎、盆、罐等。
* **灰陶**：与黑陶并行，日用大宗。
* **白陶**：高岭土系，数量少，为商周白陶先声。
* **工艺**：轮制普及，火候提高，部分黑陶胎壁仅约 0.2–0.3 mm，体现高超轮制与烧成控制。

龙山文化社会分层加剧，精美黑陶与高柄杯等礼器化倾向明显，与文献所载「陶寺」等早期复杂社会考古相呼应。

<br>

### 长江流域与其他

#### 河姆渡文化（约前 7000–5000）

浙江河姆渡遗址出土**夹炭黑陶**：胎中掺入植物碎末，减轻重量、提高耐热性。器形有釜、罐、盆、盘、支脚等；刻划猪纹、鸟纹、水草纹等，为南方刻划装饰先声。火候较北方仰韶略低，但已具地方特色。

#### 马家浜—崧泽—良渚序列

* **马家浜**：夹砂红陶、泥质红陶；豆、罐、釜；开始出现慢轮。
* **崧泽**：灰黑陶增多，刻划纹、戳印纹；器形趋规整。
* **良渚**（约前 3300–2300）：**黑陶**与**灰黑陶**发达，刻划、戳印、透雕并用；鼎、豆、壶、罐与玉礼器并行，体现礼制社会。良渚陶业与玉器、漆器共同构成江南文明标志。

#### 其他区域

| 区域 | 代表文化 | 陶业要点 |
| :--- | :--- | :--- |
| **长江中游** | 大溪、屈家岭、石家河 | 红陶、黑陶；刻划与戳印 |
| **东南沿海** | 昙石山、石峡等 | 几何印纹软陶萌发；为商周印纹硬陶先声 |
| **东北** | 新乐、红山 | 夹砂陶、筒形罐；与中原交流 |
| **华南** | 咸头岭、甑皮岩 | 夹砂陶、绳纹；早期沿海聚落 |
| **西南** | 宝墩、三星堆前身 | 地方陶系；与中原联系渐增 |

### 成就与影响

新石器时代中国陶业形成**南北双线**格局：黄河流域以仰韶彩陶、龙山黑陶为轴，长江流域以夹砂陶、黑陶、刻纹陶为轴；东南沿海几何印纹传统则为商周印纹硬陶直接先声。工艺上完成选料（高岭土白陶、夹砂耐热陶）、成型（盘筑至快轮）、窑炉（穴窑至馒头窑／龙窑前身）、装饰（彩绘、刻划、磨光、印纹）的全套技术库存。博物馆观摩彩陶盆、蛋壳黑陶高柄杯、良渚刻纹陶时，宜与后文商周灰陶、印纹硬陶、原始瓷对照，观察胎质、火候与器形礼制化的延续与变革。

## 夏商周春秋

对应原书第二章（p.51–93）。整理重点自书页 67（商代后期灰陶与窑炉）起；此前夏代二里头、商代前期至中期灰陶、白陶亦作衔接，以便脉络完整。此期核心线索有三：**灰陶**日用体系与青铜礼器并行；南方**印纹硬陶**与**原始瓷**开拓高温釉陶路线；**建筑用陶**（水管、板瓦、筒瓦、瓦钉）进入宫室工程。中原以灰陶＋青铜为主轴，南方以硬陶＋原始瓷为副轴，二者通过贡赋、贸易与文化传播相交织。

> [!NOTE]+ 读此期实物
>
> - **灰陶**：日常炊食器与明器主力；泥质／夹砂分工；绳纹、弦纹为主
> - **白陶**：高岭土系，礼器化；商代后期殷墟鼎盛，西周渐衰
> - **印纹硬陶／原始瓷**：南方高温路线；拍子、抵手、Fe₂O₃ 控制；同窑合烧
> - **原始瓷三项条件**：选料降铁、1200℃ 级高温、石灰釉施釉
> - **建筑陶**：二里头水管；西周板瓦筒瓦瓦钉；春秋瓦榫头

### 灰陶与白陶

#### 定义与成型

灰陶器以易熔黏土为主要原料，分**泥质灰陶**与**夹砂灰陶**。泥质器较精，多作饮食、贮盛；夹砂器耐热，多作炊器与厚壁大器。成型多用轮制、模制、手制结合：器身、足、耳、流等部件分制后再接合。夏商周春秋亦并存红陶、黑陶、褐陶，但灰陶数量最巨，构成此期陶业基本盘。

#### 夏代（二里头文化）

河南偃师**二里头**遗址为夏文化典型。陶器承豫西龙山晚期传统：

| 用途 | 代表器形 | 特征 |
| :--- | :--- | :--- |
| 炊器 | 鼎、罐、甑 | 敞口深腹；足有尖锥、扁平、袋足等 |
| 饮器 | 盉（小口长流袋足）、觚（敞口束腰平底） | 礼器化雏形 |
| 食器 | 豆、簋、钵、三足盘 | 组合初具规模 |
| 贮盛 | 各类罐 | 含捏制花边口沿 |

灰陶（泥质、夹砂）为主，黑褐陶次之，红陶极少。二里头亦见**陶水管**（商代以前最早建筑陶实例之一）、陶爵、陶斝等仿铜器，反映礼制与宫室建设并进。

#### 商代前期至中期

灰陶仍为大宗。器类丰富：鬲、甑、甗、爵、觚、斝、簋、豆、尊、罍、盆、瓮等。郑州**二里岗**等地**馒头窑**已较成熟，为商代窑炉代表：

* **窑室**：下部直径约 1.8 m，圆形。
* **火膛**：高约 1.1 m、径约 1.7 m；与窑室以**窑箅**相隔。
* **窑箅**：五孔——中一圆孔，四周四椭圆孔，利于聚热与通风。

白陶、印纹硬陶、原始瓷在中期前后陆续出现，开始分流「高端」器用。商中期郑州出土**原始瓷尊**，为黄河流域原始瓷名例。

#### 商代后期（书页约 67 起）

**器形演变**

* 夹砂陶罐数量减少；陶甑由高变矮，多平底，箅孔作对称叶形。
* 陶爵、陶觚数量增加，爵出现圈足；斝趋少，卣出现。
* 陶簋、陶豆数量增多：簋由敛口趋向敞口，豆圈足由高变矮。
* 瓮、盆减少，罍增多；大口尊渐少。

**仿铜与明器分化**

青铜礼器兴起后，出现精工仿铜陶器。河南安阳**殷墟**见陶爵、觚、卣、斝、豆、尊等。日用实用器种约十余种（鬲、簋、瓮、豆、罍、罐、盆等）；另有粗制**明器**专供随葬。白陶、印纹硬陶、原始瓷分担礼器与高档器用后，日用灰陶装饰趋简、制作趋粗。

**馒头窑改进（殷墟）**

窑型仍为圆形**馒头窑**，结构较二里岗进一步改进：

* **火膛**：取消中心支柱，可加燃料；底呈锅底形，径约 1.1–1.15 m。
* **窑箅**：孔径加大，通风改善。
* **烧结痕迹**：火膛壁烧结呈硬红或青灰色；积草木灰厚约 19–25 cm。
* **意义**：去支柱、加大箅孔，使升温与通风改善，为硬陶、原始瓷所需 1100–1200℃ 高温提供窑炉基础。

#### 西周灰陶

承关中、晋南先周传统，并吸收商末因素。早期多见高领鬲、深腹圜底盆、深腹双耳罐等；晚期趋于统一：袋足、圈足、平底组合更常见。

| 用途 | 代表器形与特征 |
| :--- | :--- |
| 炊器 | 鬲（敞口卷沿深鼓腹短袋足）、甗（束腰短袋足）、甑（盆形平底穿孔） |
| 食器 | 簋（敞口斜腹圜底喇叭圈足）、豆（浅盘喇叭座） |
| 贮盛 | 罍、罐、瓮、盆、盂 |

器形演变：晚期豆柄中部可有凸节；簋由商末式渐趋简化至消失；盆由卷沿改折沿；盂出现于晚期；罍由双耳趋向无耳；瓮由直领小口改卷沿斜肩。部分地区仿铜礼器与专用明器并行；爵、斝、觯、壶等日用饮器反而少见或不见。

**窑炉**：陕、豫等地仍为馒头窑。结构多见窑室、窑箅、火膛、支柱、火门五部；亦有无中心支柱者（如长安沣东洛水村窑，近殷墟做法）。西周晚期至春秋，窑室与火膛扩大，利于提高窑温与质量。

#### 春秋灰陶

以平底器与袋状三足器为主，圈足器较少；区域差异明显。泥质灰陶最常见，次为夹砂灰陶。

* **炊器**：鬲（敞口或卷沿、深腹短袋足）、釜（似鬲而圜底无足）、甑（敞口或微敛、直壁平底穿孔）。
* **食器**：豆（浅盘高柄）、盂、盘。
* **贮盛**：瓮、盆、罐（高领斜肩或卷沿圆／折肩）。

中原墓葬前期多实用器；春秋晚期郑州一带出现仿铜明器（鼎、壶、匜、盘等）。江南有仿本地印纹硬陶风格的灰陶瓮、罐。装饰较西周简化：腹饰粗绳纹，肩部见瓦纹；豆、盂多素面或磨光。

**器形总趋势**：鬲袋足由肥硕趋扁，终向釜过渡；豆柄加高、盘腹由折变圆；罐领由矮趋高而成壶。日用灰陶品种收缩至约七种常见组合：鬲、釜、簋、盆、豆、瓮、罐。山西**侯马牛村**等窑址显示窑室扩大，并出现**烟囱**，为窑炉重要进步。

白陶、印纹硬陶、原始瓷、青铜器与漆器分流后，灰陶装饰以绳纹为主，品种减少而建筑用陶（板瓦、筒瓦）自西周起成规模。

#### 白陶器

表里与胎体皆白，原料为含铁较低的高岭土类，约 1000℃ 左右烧成。龙山、大汶口已见白陶鬶等；夏商继承发展，**商代后期殷墟达到鼎盛**，器形仿青铜礼器（斝、盉、爵、豆、簋；晚期另有罍、壶、卣、尊等），纹饰精细，为统治阶级日用与随葬。胎质硬度接近普通灰陶，烧成温度远低于硬陶、原始瓷。西周后白陶骤减，其礼器功能逐渐由印纹硬陶与原始瓷取代。

<br>

### 印纹硬陶与原始瓷器

#### 印纹硬陶

胎较泥质陶、夹砂陶细硬，烧成温度更高（约 1100℃ 上下），表里多呈紫褐、红褐、灰褐、黄褐；紫褐者火候最高，可近烧结，击之有金石声；偶因高温熔出类似薄釉的光泽。

| 项目 | 内容 |
| :--- | :--- |
| **原料** | 与同期原始瓷接近，一般 Fe₂O₃ 略高（约 2%–4% 或更高） |
| **成型** | 泥条盘筑为主；器内抵以蘑菇形**抵手**，器外以带纹**拍子**拍打，故内壁常留凹窝，外壁成印纹 |
| **纹饰** | 方格、云雷、回纹、曲折、菱形、波浪、夔纹等几何拍印 |
| **产地** | 长江中下游与东南沿海最盛；黄河下游亦有，但远少于南方 |
| **合烧** | 绍兴、萧山等地春秋战国窑址常见硬陶与原始瓷**同窑合烧** |
| **用途** | 商至西周与原始瓷制法、纹饰、用途相近；春秋起分工渐明——硬陶多作贮盛，原始瓷多作食具 |

#### 原始瓷器：三项基本条件

中国至迟在**商代中期**已创制原始瓷。具备瓷器三项基本条件：

1. **选料**：提高 Al₂O₃、降低 Fe₂O₃（陶器 Fe₂O₃ 常 6%–10%，原始瓷约 2% 上下），胎色趋白。
2. **高温**：约 1200℃ 及以上，胎致密、吸水率低，击之清脆。
3. **施釉**：高温**钙（石灰）釉**，与胎化学结合；CaO 约 16%（可至 20%），Fe₂O₃ 约 2%，还原焰下呈青绿、豆青、黄绿等色系。

釉层厚薄不匀，常见流釉；较白陶、硬陶更坚致、易清洁，故受贵族青睐。化学组成与显微结构上，原始瓷介于陶与成熟瓷之间：Fe₂O₃ 降低、温度升高，玻璃相与莫来石增加，但仍未稳定达到东汉成熟青瓷标准。

#### 商—春秋发展

| 阶段 | 器形与胎釉 | 分布与备注 |
| :--- | :--- | :--- |
| **商中期** | 敞口长颈尊、深腹瓮、簋、高柄豆等；胎灰白至灰褐；釉青绿、豆青、黄绿；方格、篮纹、叶脉、席纹、S 纹等 | 黄河、长江中下游多省遗址；**郑州**出商代原始瓷尊为名例 |
| **商后期** | 器种增加（罐、盆、盖等）；釉色增酱、淡黄、深紫等；水波、云雷、网纹等；施釉面扩大 | 江南数量增幅尤著；江西吴城遗址比例突出 |
| **西周** | 罍、簋等礼器形增多；**洛阳**等地出土原始瓷罍、簋 | 白陶退出后，原始瓷承接部分礼器功能 |
| **春秋** | 胎釉改进；江南窑址密集；与硬陶明确分工 | **东苕溪流域**（德清为中心）窑群连续生产 |

#### 东苕溪德清窑群与龙窑

浙江**东苕溪流域**（德清龙山、湖州青山、火烧山、亭子桥等）为目前已知出现最早、延续最长的先秦原始瓷窑区之一。考古揭示：

* **龙窑**起源与发展与此区密切相关：沿山坡建窑，利用自然坡度延长火焰路径，提高窑温。
* **独立窑区**形成：春秋战国窑场密集，硬陶与原始瓷分工明确。
* **装烧具**：春秋**托珠**、战国多样支烧具，与瓷器烧造密切相关。
* **北运**：中原高等级城址、墓葬所见硬陶与原始瓷，科技分析多显示南方「高硅低铝」瓷石特征，部分为南产北运。

> [!INFO]+ 原始瓷与成熟瓷的界限
>
> 商周原始瓷已具备选料、高温、施釉三要素，但胎质杂质与气孔仍多，釉层常局部、厚薄不匀，吸水率高于东汉成熟青瓷。学界主流以东汉上虞小仙坛为成熟瓷器公认节点；战国德清亭子桥等窑部分产品烧结良好，有学者讨论成熟瓷上限前移，尚存争议。

### 建筑用陶和其他陶制品

建筑用陶由日用陶业分化而来，标志宫室工程与陶业专业化。

#### 陶水管

* **商代早期**：河南偃师**二里头**已见陶水管。
* **商代中晚期**：郑州、**殷墟**续有发展；商后期出现**三通管**。
* **工艺**：泥质灰陶为主，泥条盘筑加轮修；外表多绳纹，接口处可去纹加「瓦环」以便套接。

#### 板瓦、筒瓦与瓦钉

* **西周早期**：**板瓦、筒瓦**出现；扶风、岐山、长安沣镐一带大量出土。
* **胎质**：泥质灰陶（偶红、黄灰），多粗绳纹，部分加划纹或云雷纹。
* **尺寸**：筒瓦、板瓦可很大（筒瓦长可至约 50 cm）。
* **固着**：内／外壁可附**瓦钉、瓦鼻**，插入草泥或系绳防滑。
* **春秋**：出现陶管、少量薄方砖／长方砖；固着方式由连体瓦钉改为端孔加钉，筒瓦出现**瓦榫头**以便衔接。

「秦砖汉瓦」之前，商周瓦与排水陶管已标志礼制宫室与城垣建设水平。

#### 其他陶制品

纺轮、网坠、陶拍，以及鸟、人面、兽首等小件陶塑（吴城、沣镐、侯马等地），以动物造型为多。

<br>

### 中原以外各区

#### 东南地区

浙、闽、台、粤、桂、赣沿海及附近：新石器晚期至夏商之际，由印纹软陶提高火候发展为印纹硬陶；泥质／夹砂灰陶、红陶、黑陶、橙黄陶并存。装饰有磨光、划纹及方格、篮纹、曲折等几何纹。器形兼具地方特色（小口折肩瓮等）与中原影响（袋足鬲、高圈足豆、大口尊等）。

| 遗址 | 要点 |
| :--- | :--- |
| **福建昙石山** | 沿海早期聚落；地方陶系 |
| **广东石峡** | 几何印纹与中原器形交流 |
| **江西筑卫城／吴城** | 商代城址；硬陶、原始瓷比例突出 |

商时期与中原交流加强，但几何印纹与地方器形仍强。春秋战国时吴越地区成为印纹硬陶与原始瓷生产高潮区（萧山茅湾里、德清火烧山／亭子桥等）。

#### 其他地区（概要）

长江中游、西南及北方边地各有地方灰陶、硬陶传统；器形组合随族群与礼俗而异。总趋势是：**中原以灰陶＋青铜为主轴，南方以硬陶＋原始瓷开拓高温釉陶／瓷之路**，二者在商至春秋通过贡赋、贸易与文化传播相交织。

<br>

## 战国秦汉

对应原书第三章（p.94–135）。战国列国改革与筑城、秦统一与汉帝国营建，推动灰陶、建筑陶、铅釉陶与明器繁荣；江南印纹硬陶与原始瓷在战国达高峰，楚灭越后浙江瓷业一度中断，秦汉际复兴，东汉晚期于上虞**小仙坛**等处烧出**成熟青瓷**，完成陶向瓷的质变。此期南北分途明显：北方重灰陶、彩绘陶、铅釉陶、建筑陶；南方以龙窑烧硬陶／原始瓷，东汉形成**曹娥江窑群**。

> [!NOTE]+ 读此期实物
>
> - **战国品种**：灰陶、彩绘陶、印纹硬陶、原始瓷、建筑陶、铅釉萌芽（齐临淄）
> - **度量与陶范**：登封阳城陶量「阳城」「廪」戳记；侯马、告成陶范
> - **秦俑**：泥质灰陶分段模塑拼装
> - **汉铅釉**：绿釉、银釉（潮湿墓溶蚀沉积）；与南方高温钙釉非同一体系
> - **东汉青瓷**：小仙坛 1260–1310℃；FeO/Fe₂O₃ 还原比 2.17；帐子山、凌湖等七处窑址

<br>

### 战国背景

战国为封建社会形成期。人口增长、千丈之城与万家之邑常见；齐、秦、燕、楚、韩、赵、魏变法，秦以商鞅变法成西方强国，前 221 年统一六国。秦虽仅十五年，郡县制与「书同文、车同轨、人同伦」及驰道、水路、市制、度量衡划一，经西汉巩固，使国家统一成为历史主流。汉代生产力长足发展，蔡伦改进造纸；陶瓷突出成就有二：**西汉低温铅釉陶**出现，**原始瓷经秦汉复兴于东汉烧成成熟青瓷**。

<br>

### 战国陶瓷

#### 灰陶与彩绘陶

泥质／夹砂灰陶为全国大宗，约 900–1000℃ 烧成，普遍**快轮**；瓮、釜等大型器仍泥条盘筑。山西侯马、河南登封等地制陶作坊兼产陶范（母范、内范、外范），质地细腻，刻饰精美，供铸铜铁农具、兵器、礼器。登封**阳城**出土陶量：一种筒形平底，口径 15.6、高 11、壁厚 1.1 cm，口沿三处「阳城」戳记；一种敛口斜鼓腹平底，口沿「廪」字戳记，为研究战国度量制度的重要资料。

巴蜀地区口沿陶杯、壶、罐形式多样，饰指甲纹、弦纹，具强烈民族色彩。战国丧葬制度变化：三晋两周贵族墓早中期起以陶礼器代铜礼器，小型墓亦见；仿铜鼎、豆、壶、盉、罍等成套生产，磨光、暗花、彩绘、线刻并用。各国组合与形制差异显著：

| 区域 | 随葬组合与器形特点 |
| :--- | :--- |
| **三晋两周** | 早中期鼎、豆、壶；晚期豆为盆所代 |
| **楚** | 盛行鼎、敦、壶；壶修长，圈足或假圈足高 |
| **韩** | 壶颈长，底与圈足小，比例欠协调 |
| **燕** | 壶圆底矮圈足，盖钮高竖 |
| **赵** | 壶口沿外翻莲瓣 |
| **齐** | 壶敛口鼓腹或椭圆腹，大方，肩部活动环耳；豆把特别高 |
| **中山** | 豆敛口深腹，盖顶圆钮 |

**彩绘陶**烧成后再绘，不再入窑；楚地尤盛，仿铜礼器色彩丰富。

大型灰陶瓮高可达 82 cm（口径 41、腹径 90 cm），釜高 55 cm（口径 88 cm），为秦代陶俑、陶马高大器物的烧成提供技术基础。

战国陶拍、印模与纺轮等制陶工具，与陶范并用，反映手工业分工细化。

<br>

#### 印纹硬陶

长江下游及两广、湘南、赣南最盛，约 1100–1200℃ 烧成。胎土含铁较高，烧成后多紫褐或砖红色；高温者胎壁坚硬，击之有金属声，器表偶带薄透明层。成型仍泥条盘筑，拍印几何纹。

吴越常见米字纹、方格纹、藤布纹、回纹、米筛纹；西周春秋曲尺纹、云雷纹减少。颈肩部常加弦纹、水波纹；两广另有栉齿纹、圆珠纹、篦纹（点线状）。大瓮、坛、罐拍粗纹（米字、方格、米筛、粗麻布）；小盂、缶拍细藤布纹，纹饰与器形协调。器类以瓮、坛、缶、罐、盂为主；浙江、江苏多罐、坛；两广有小口四耳平底大瓮壶、双三足罐、三足盖盆等地方特色。印纹硬陶坚固耐用、质地粗糙，几乎不作饮食器，主要为贮盛容器。

<br>

#### 原始瓷

江、浙、赣一带胎呈灰白色。山西侯马、浙江绍兴**富盛**、萧山**茅湾里**原始瓷片测定 Fe₂O₃、TiO₂ 含量（%）分别为：侯马 1.97、1.25；富盛 2.12、1.18；茅湾里 1.68、0.70。胎质细腻致密，经粉碎淘洗，轮制规整，器壁薄匀；碗、盘、盂内底有细密螺旋纹，外底有切割线痕。较西周原始瓷，坯泥处理更精，由盘筑改轮制，效率与质量大增。外施薄石灰釉，烧成后多青或青中泛黄；釉层厚薄均匀或凝聚成芝麻点。两广、湘南胎近当地硬陶，多紫、灰红；釉有黄褐、黄绿、墨绿等，均属铁呈色剂青釉系统。

饮食器有碗、盘、缶、盂、盅、碟、鼎等，盘、碗大小成套；并仿铜礼器鼎、钟、于等。广东、湘南等地印纹硬陶与原始瓷手工业在战国继续缓慢发展。

<br>

#### 楚灭越与瓷业中断

绍兴富盛、萧山进化区窑场规模大、距越都近，疑为越国官营或奴隶主作坊。楚灭越后，上层西汉文化层中不见印纹硬陶与原始瓷，或与战争破坏有关。浙江等地战国晚期墓随葬泥质**灰陶**鼎、豆、壶，为楚与中原影响；嘉定外冈墓出陶「郢爰」，墓主或为楚人。偏僻小窑或幸存，故战国晚期墓葬、遗址仍见少量印纹硬陶。江、浙原始瓷并非自商周直线演进，战国曾短暂中断，战国末至秦汉之际出现工艺有别的原始瓷，再经发展，于东汉烧成真正瓷器。

<br>

#### 建筑用陶

战国各国都城大兴土木，砖瓦技术达较高水平。砖多用于铺地、砌壁，似尚未用于筑墙。铺地砖分小型薄方砖与较大长方形砖；空心砖饰几何纹、动物纹、人物纹。筒瓦、板瓦、瓦当、瓦钉、瓦鼻齐备；瓦当纹饰有云纹、兽纹、文字等。陶井圈、陶水管用于城市供水排水；各地城址大量陶水管证明战国城市建设已系统解决用水排污问题。空心砖、陶井圈服务都城与陵墓工程。

> [!NOTE]+ 战国建筑陶要点
>
> 临淄、邯郸、燕下都、郑韩故城等城址出土铺地砖、空心砖、板筒瓦与排水管，反映列国都城营建规模。陶水管截面圆或方，套接处去纹加「瓦环」便于衔接，为后世宫室排水系统先导。

<br>

#### 工艺与窑业

* **龙窑**：战国出现大型支烧具；窑身沿山坡延伸，分段烧造。
* **同窑合烧**：硬陶与原始瓷常同窑——前者胎粗无釉作贮盛，后者胎细有釉作食具。
* **铅釉萌芽**：齐地（临淄一带）低温铅釉陶，约 700–900℃，为汉铅绿釉先导。
* **南北格局**：北方重灰陶、彩绘陶、建筑陶；南方龙窑烧硬陶／原始瓷，形成「北陶南瓷」。**铅釉**（氧化铅助熔）与**高温钙釉**为两条不同技术路线。

<br>

### 秦汉品种与产地

秦汉为陶瓷史重要时期：雕塑现实主义传统深远；**低温铅釉陶**为重大成就；建筑陶技术提高；**原始瓷向瓷器演变完成**，陶瓷史进入新阶段。

#### 生产三阶段

| 阶段 | 时代 | 特征 |
| :--- | :--- | :--- |
| **一** | 秦至汉初（武帝元狩五年前） | 面貌变化小，地方特色强；官营重砖瓦，私营重日用；咸阳空心砖、瓦当，始皇陵兵马俑，杨家湾与任家坡汉初彩绘骑俑、侍女俑 |
| **二** | 武帝至西汉末（含王莽） | 地方色彩减弱，统一性增强；铅釉自关中迅速推广，绿釉明器流行；仿铜礼器仍产，仓、灶、井、炉、猪圈等模型明器急增 |
| **三** | 东汉 | 旧式陶礼器减少至绝迹；中期后庄园经济模型明器、画像砖、楼阁城堡模型大量出土；晚期浙江烧成瓷器，结束瓷器「发生期」 |

<br>

#### 秦

* **灰陶**：遍及全国；咸阳、临潼砖瓦工程量巨大。
* **原始青瓷**：秦始皇陵附近出原始青瓷盖罐等。
* **兵马俑**：临潼**秦始皇陵**陪葬坑；泥质灰陶**分段模塑**烧成后拼装；个体高大，神态各异，代表古代陶塑高峰。

<br>

#### 汉：主要品种

| 品种 | 特征 | 代表 |
| :--- | :--- | :--- |
| **灰陶** | 青灰坚致，日用与明器并重 | 仓、灶、井、磨、楼阁、猪圈等；戳印「河亭」「河市」 |
| **彩绘陶** | 灰胎上绘红黑黄白等 | 仿漆器云气、四灵；满城汉墓、无影山杂技俑 |
| **铅釉陶** | 普通黏土砖红胎；Cu 绿、Fe 黄褐；约 700–900℃ | 西汉早期关中盛；东汉绿釉几乎专作明器 |
| **建筑陶与画像砖** | 「秦砖汉瓦」 | 关中瓦当；南阳、洛阳、四川画像砖 |
| **陶俑明器** | 汉承秦制而体量趋小 | 说唱俑、杂技俑、陶仓楼 |
| **南方硬陶** | 长江以南继续生产 | 方格纹等拍印，部分施薄釉 |

**明器演变**：陶仓秦墓已见，武帝时盛行——初为手制圆身束腰连顶、绳纹；西汉轮制圆肩折肩筒腹平底、覆盆盖，中期肩弧化并加三足，东汉下身内收、削三足成平底。陶灶西汉早期长方形一大灶眼、前灶门后烟窗；中期灶面出沿，大灶眼后加模印小釜，边缘饰纹。陶鼎耳西汉早中期条形，中期铺首形，晚期兽面形，东汉即消失。

**铅釉与银釉**：铅釉陶釉层清澈透明、光泽强，然墓中几乎均为明器，疑与低温不耐实用有关。除鼎、盒、壶、仓、灶、井、畜圈外，还有水碓、陶磨、作坊、楼阁、池塘、碉楼模型；甘肃武威雷台东汉墓丘层楼院模型高 1.05 m，通体翠釉。潮湿墓中铅绿釉表面或现**银白色金属光泽**，称「银釉」。上海硅酸盐研究所试验表明：银釉实为铅绿釉上半透明沉积衣，可刮去，下层仍为绿釉；显微镜下呈层状，少者数层、多者二十余层，每层约 3 μm；化学组成与基底铅绿釉相近，室温电阻约 10⁵ 欧姆·厘米。潮湿环境中水与大气使釉面轻微溶蚀，溶出物与可溶性盐类在釉面及裂缝析出所致。

**区域分布**：

| 区域 | 侧重产品 |
| :--- | :--- |
| **关中** | 灰陶、铅釉、建筑陶、陶俑 |
| **河南** | 明器、画像砖、铅釉、陶仓楼；洛阳烧沟汉墓陶罐、陶壶形制典型 |
| **山东** | 灰陶、铅釉（承战国齐地） |
| **广东** | 印纹硬陶、地方特色瓮罐；汉初赵佗割据保留地方风格，武帝平南越后面貌近中原；东汉陶屋、水田模型 |
| **江南** | 硬陶、原始瓷→东汉青瓷 |

#### 广东与南方硬陶

广州汉墓陶器组合大致四类：瓮、甑、釜、罍；鼎、盒、壶、钫；三足盒（或小盒）、三足罐（或联罐）等；井、灶、仓等模型明器。地方特色强的是瓮、罐、三足盒、联罐；鼎、盒、壶、钫则受中原影响；仓、灶、井模型明器西汉中期后方见于广州墓，盛于西汉晚期至东汉。

广州汉初陶器特点：（1）以细泥质为主，火候高低致色泽、硬度差异，灰白色硬陶占绝大多数，戳记方格印纹比重大；（2）容器最多，烹饪器仅甑、瓶、鼎；（3）三足罐、三足盉、三足格盒及双联、四联、五联罐为特色，温壶、鲍（匏）形器尤为特殊；（4）约 74% 器物有纹，几何戳印纹达七十余种，还有弦纹、**篦纹**（西汉初广州最常见）、**绚纹**（西汉中期广州独有，仅施于罍、壶腹）、镂孔、彩绘与肩部文字记号；（5）硬陶胎表或附黄绿、黄褐、近灰黑釉状层，形制与长沙、广西贵县西汉陶接近。

两广、湘南、赣南硬陶胎含少量细砂，断面青灰，器表灰褐，常细方格、叶脉、水波纹；罐、壶多见，罐肩常刻符号。东汉广州动物园建初元年墓出陶城堡模型：四角角楼、碉楼、望台、飞桥、门楼与武士，坞堡缩影；另有水田模型插秧收割、旁系小舟，再现南方水乡农业。

<br>

#### 画像砖与建筑陶

南阳、洛阳、四川等地画像砖西汉中期后盛行，模印宴饮、出行、神话、生产劳动等。空心砖战国已有，秦咸阳宫、汉茂陵等大量出土；板瓦、筒瓦、瓦当与陶井圈、井栏构成「秦砖汉瓦」体系。洛阳烧沟等中原汉墓灰陶罐、壶形制规范，反映中央地区日用陶标准化程度。

<br>

#### 陶塑与瓦当

汉初陶塑承秦风，体较大，细节精，明快洗练。杨家湾等地汉初墓出二千余件陶俑、五百余骑马俑，骑士与马分制装配，马臀、尾、背刻数字记号，批量化生产；大骑马俑通高约 68 cm，小约 50 cm，立俑约 44.5–48.5 cm，反映西汉前期骑兵建设。无影山出土彩绘乐舞杂技宴饮陶俑盘（长 67、宽 47.5 cm），二十余人物，以表演者为中心。东汉四川「说书俑」、彭山持铲执箕俑、水田劳动俑等，题材广泛，情态生动。

**瓦当**：秦瓦当融合列国特点，主纹为云纹——边轮内弦纹分内外圆，直线分四扇面填云纹，内圈方格、网纹、点纹、四叶纹等；文字瓦当少，「维天降灵、延元万年、天下康宁」十二字瓦当为统一中国产物。亦见奔鹿、立鸟、豹纹、双鹿对鸟、葵纹、莲瓣纹等。汉瓦当大量为**文字瓦当**（宫殿、署、祠墓、吉语四类）；茂陵出「与民世世，天地相方」「永安中正」十二字瓦当；霍光墓附近吉语瓦当「嘉气始降」等。王莽时青龙、白虎、朱雀、玄武四神瓦当为代表。制法：秦至西汉初瓦心、边轮、瓦当分三次制作，瓦当背面有切痕；西汉中期起一次范成；汉瓦当中央必有大圆柱，边轮齐整，面积较秦瓦略大。

### 原始瓷复兴与瓷器出现

#### 西汉波折与器形

楚灭越后浙江原始瓷一度中断，秦汉际逐步复兴。汉初原始瓷壶口微侈、颈长、肩斜鼓、人字纹双耳、矮圈足；中期口缘喇叭状、颈短腹深、圈足低矮至平底，耳半环形或贴铺首、堆塑龙头；晚期口明显喇叭形、腹球圆、极少圈足，耳多铺首衔环（长沙五里牌壶耳配活动铁环）。另有长颈壶、蒜头壶、匏壶等。装饰前期简朴（弦纹、水波纹）；中后期凸弦纹（贴泥条），刻划水波、卷草、云气、人字纹，云气间配神兽飞鸟；义乌西汉中期壶耳堆塑龙头、腹刻武士、盖顶蟠蛇钮等，题材特殊。产品行销浙江、苏南及江西、两湖、陕、豫、皖、苏北等地。

<br>

#### 东汉：盘口壶与窑业分家

东汉原始瓷品种变化：西汉广流行的鼎、盒等停烧，洗、碗、盘、钵等日用器急增。**盘口壶**盛行——口颈高、口内盘面小、球腹、平底，由喇叭口壶演变：西汉喇叭口壶口颈交接处已有棱线，东汉前期棱线突出，中期成盘口；直口平唇，肩双系，上腹鼓、下斜收平底。盘直口斜壁、浅腹大底，常与耳杯相配作承托。四峰山等窑址印纹瓮、罐已改瓷土制作并施釉，结束印纹陶与原始瓷同窑兼烧；部分窑仍产原始青瓷，质量提高，多数专烧青瓷，**陶瓷分家**，瓷器成为独立手工业。永嘉东岸、宁波郭扩乔等地调查试掘，证明演进不限于上虞。

<br>

#### 东汉成熟青瓷

| 指标 | 原始瓷 | 成熟青瓷（东汉晚期） |
| :--- | :--- | :--- |
| **胎** | 杂质、气孔较多 | 细腻灰白，完全烧结 |
| **吸水率** | 较高 | 极低（小仙坛标本约 **0.16%–0.28%**） |
| **釉** | 薄、常局部施釉 | **通体施釉**，玻璃质，胎釉结合紧 |
| **温度** | 约 1200–1250℃ | 约 **1260–1310℃** |
| **窑炉** | 龙窑尚不完善 | 火膛—窑床—排烟室改进；龙窑升温快、薄窑体快冷，利于还原与防铁二次氧化 |

**纪年器**：延熹七年（164）麻布纹四系青瓷罐；熹平四年（175）耳杯、五联罐、水井、熏炉、鬼灶；熹平五年青瓷罐；初平元年（190）同墓麻布纹四系罐。出土地：洛阳中州路、烧沟，河北安平遂家庄，安徽亳州，湖南益阳，湖北当阳刘家冢子，江苏高邮邵家沟等。

**小仙坛**：瓷片与附近瓷石化学成分接近，就地取材。CaO 釉料 15% 以上，还原气氛烧成，釉透明有光泽，胎釉结合紧密。

**还原控制**：青瓷烧成分氧化、还原、冷却三阶段。弱还原釉青中带黄，强还原呈深青；冷却过慢二次氧化致泛黄，过快则「惊风」开裂。小仙坛瓷片胎 FeO 1.26%、Fe₂O₃ 0.58%，还原比 **2.17**，还原焰烧成，釉色纯正，少流釉、开片。

**东汉浙江窑址**（上虞最多）：联江**帐子山**、**凌湖图箕岙**（旧籍亦记「图箕吞」，地名用字或异）、倒转岗、石浦龙池庙后山、**小仙坛**、大陆岙等七处；慈溪、宁波、永嘉亦有发现。瓷石为石英—高岭—绢云母型伟晶花岗岩风化产物，含铁较高，适宜还原烧成；温州、永嘉 Al₂O₃ 较上虞略高，Fe₂O₃、TiO₂ 较低，胎釉因此差异。可能已用水碓粉碎瓷土。

**黑釉瓷**：胎 SiO₂ **73–76%**，Al₂O₃ **15–18%**，Fe₂O₃ **2.3–2.8%**；烧成约 **1200±20℃ 至 1240±20℃**。石灰釉 CaO 约 16%，釉内 Fe₂O₃ **4–5%** 呈绿褐至黑色；施釉不到底，底与近底露深紫胎；碗、洗内壁常涂薄红褐涂料；有蜡泪痕与釉层聚集。导源于酱色釉原始瓷，扩大原料使用范围。湖北当阳刘家冢子东汉画像石墓四系罐肩饰莲瓣纹，为佛教传入后在瓷器装饰上的反映。

**产地转移**：中心由战国东苕溪（德清）经波折转至**曹娥江流域（上虞）**，开越窑先河。

#### 技术小结

东汉瓷器出现是长期实践的结果：原料粉碎与淘洗（可能已用水碓）、轮制与拉坯工具改进、石灰釉配方（CaO≥15%）与还原气氛控制、龙窑结构改进（升温快、冷却适中）共同作用。小仙坛、帐子山、凌湖等窑场证明瓷业已由点状生产扩展为宁绍平原窑群；青釉与黑釉并行，为六朝越窑、德清黑瓷与唐代「南青北白」奠定物质基础。

> [!INFO]+ 瓷器成熟三要素
>
> 原料精选加工、高温胎釉一次烧成、窑温与气氛有效控制——三者齐备，方称成熟瓷器。东汉浙江青瓷标志中国由陶到瓷的质变，并为三国两晋南北朝瓷业大发展奠基。

## 三国两晋南北朝

对应原书第四章（p.136–179）。三国至南北朝三百六十年间，除西晋短暂统一外，南北长期分裂。江南战乱较少、经济开发加速，建康、山阴、江陵、成都、番禺等城市兴起；孙权破岗渎通吴会，制瓷业自东汉晚期新兴工业迅速成长。江苏、浙江、江西、福建、湖南、四川等地瓷窑遗址遍地开花，唐代越窑、婺州窑、洪州窑等皆已在此期创烧或大量生产。北方经北魏统一、均田制恢复经济，在南方影响下先烧青瓷，再发展黑瓷、**白瓷**；**范粹墓**（575 年）白瓷与**莲花尊**为北朝亮点。

> [!NOTE]+ 读此期实物
>
> - **江南窑系**：越、瓯、婺州、德清、均山、洪州与岳州前身
> - **分期**：东吴承东汉；西晋最盛；东晋简朴、盏托兴起；南朝莲瓣
> - **工艺**：元康七年越窑罐 Fe₂O₃ 2.72%；1300℃；吸水率 0.42%
> - **北朝**：范粹墓白瓷；莲花尊；铅釉陶俑

<br>

### 历史背景

中原永嘉之乱后士族与民众大量南迁，江南人口激增；「荆城跨南土之富，扬部有全吴之沃，丝、棉、布、帛之饶，覆衣天下」。山阴（绍兴）为豪门聚居、富饶之地。四世纪末鲜卑拓跋部南下建北魏，439 年太武帝统一北方；485 年孝文帝均田制恢复农业，手工业得以复兴。南方青瓷普遍发展，金属器、漆器部分为瓷器取代；北方先学青瓷，再出现白瓷，为隋唐「南青北白」奠基。

### 分期与器形演变

#### 东吴（220–280）

多承东汉。日用器：钵、罐、**盘口壶**、唾壶、水盂、香熏；明器：堆塑谷仓罐、虎子、灶、碓、鸡笼、动物形尊。胎淡灰白，釉灰青；弦纹、斜方格纹、堆塑、镂空。纪年器「赤乌十四年」虎子、「甘露元年」羊尊等。

#### 西晋（265–316）

成就最突出。新增**鸡首壶**、**扁壶**（汉晋因材质偏旁异写：铜曰**钾**、漆曰**柙**、陶曰**匣**一类，皆从「甲」；宋以后通称扁壶）、兽形尊、多子槅、镂空香熏、镇墓兽、俑；模印斜方格、联珠、忍冬带，刻划水波、海星纹；谷仓堆塑复杂；晚期**褐彩点染**打破单色釉。器上刻「会稽上虞」「会稽上虞范休可作」及「先姑坤一枚」等，反映商品生产。瓯窑带嘴双系罐、敛口深腹钵等造型独特。

#### 东晋（317–420）

生产普及，造型简朴实用，明器衰落。碗、盘、壶、砚、虎子配套；弦纹为主，**晚期莲瓣纹**；褐彩仍流行。**盏托**由耳杯、托盘演变——东汉耳杯仿漆杯，三国西晋腹浅底小，东晋两端微翘；托盘由一盘托四至六杯缩小至一至二杯，盘壁内弧，内底出现凸起托圈；直口深腹假圈足盏出现，耳杯、大托盘渐被取代。

#### 南朝（420–589）

胎致密灰胎；器形偏小，鸡头壶、盘口壶、四系罐常见；**浮雕、刻划莲瓣**为最具时代特征装饰，与佛教盛行相关；褐点更小而密。托盏普遍，为饮茶饮酒风行用具。江西等地熏炉炉盖多层乳尖或螺旋堆纹似烟云，有的贴仰莲；高足杯、盖碗、内底重瓣莲花盘、多管灯、瓷明器（斗、火盆、虎子、鬼灶等）具强烈地方色彩，反映当地仍盛行瓷明器随葬。

#### 东吴至西晋器形补充

**盘口壶**自东汉延续，三国西晋颈渐长、腹渐鼓，肩系由横系向竖系过渡。**鸡首壶**西晋流行，流作鸡首，与羊首、兽首流并存。**谷仓罐**（魂瓶）堆塑楼阁、人物、飞鸟，西晋最繁；**镇墓兽**、对俑、武士俑随葬制度反映门阀政治与玄学丧葬观念。**扁壶**（钾／柙／匣）横宽扁腹，便于携带，金属、漆、陶瓷同名异旁，西晋越窑划飞鸟奔兔、刻工匠名例为商品化标志。

#### 龙窑与施釉

南方龙窑普遍沿山坡而建，利用自然坡度延长火焰路径。三国至南朝窑身由宽短向狭长演变，坡度趋平（约 10° 余），利于提高窑温至 1300℃ 左右并增大装烧量。早期瓷窑与陶窑同烧，后渐分离；越窑体系在上虞、余姚、宁波等地形成连续窑场网络。

施釉由浸釉、刷釉并用，西晋起釉层普遍加厚，玻璃质感增强。东晋南朝**化妆土**（白色瓷土或陶土浆）罩施于胎表，遮盖灰胎、改善釉色呈现，为北方白瓷与后世彩绘瓷所借鉴。西晋晚期**褐彩**以铁或锰为着色剂点于釉上，打破东汉以来单色青釉传统；南朝褐点更小更密，与莲瓣纹并用。

#### 洪州、岳州与四川

江西丰城罗湖窑场三国东吴墓已见同类青瓷，南朝正式形成洪州窑传统：胎浅灰，釉豆青或蟹壳青，开细碎片。湖南湘阴窑场两晋南朝墓器与当地出土一致，为岳州窑前身；较早采用匣钵装烧，提高成品率。四川邛崃固驿、十方堂等地南朝始烧，器形有四系壶、罐、敛口碗等，胎釉带巴蜀地方特色，唐代邛窑极盛即奠基于此。

西晋八王之乱至十六国混战百余年，北方制瓷几乎独让南方。439 年北魏统一北部后，485 年均田制下手工业复兴。

| **白瓷萌芽** | 河南安阳北齐**范粹墓**（**575 年**）；**相州窑**（安阳）可能产地 | 胎细，常施**化妆土**；釉白而多泛青黄，玻璃质强，细碎开片；白釉绿彩等 | 纪年最早白瓷群之一 |
| **铅釉陶** | 中原及北方 | 黄、绿、酱等低温铅釉 | 承汉魏，下启唐三彩 |
| **莲花尊** | 河北、江苏等地北齐、北周墓 | 青瓷或白瓷，堆塑、贴塑多层仰覆莲瓣，器形硕大 | 礼佛用瓷，佛教艺术与制瓷结合 |

> [!INFO]+ 范粹墓瓷器要点
>
> 1971 年河南安阳洪河屯范粹墓出土瓷器十余件：约 10 件白瓷、白釉绿彩器及黄釉乐舞扁壶等。白釉绿彩长颈瓶为已知最早白瓷与早期釉下加彩实例之一；黄釉胡腾舞扁壶为早期胡腾舞图像资料。该批器物将三彩式铅彩加彩上限前移至 6 世纪下半叶。

**相州窑**（安阳一带）承范粹墓白瓷与三彩式铅釉传统，北朝至隋继续烧白、青、黄釉器，为唐代安阳窑与巩义、关中三彩产区提供工艺基础。北方青瓷窑场分布于河北、河南、山东、山西、陕西、安徽等地，胎多灰白或灰褐，釉青或青黄，产量与精美程度不及江南，但在本地日常用瓷中占重要地位。

**莲花尊**多见于北齐、北周贵族墓，河北、江苏等地均有出土；器身堆塑、贴塑多层仰覆莲瓣，有的器形硕大，为礼佛陈设专用，体现佛教艺术北传与制瓷结合。北朝铅釉陶俑继承汉魏传统，黄、绿、酱等色釉施于武士、镇墓兽、胡人、乐舞俑，技法与色彩实验为唐三彩直接准备。

<br>

### 制陶

六朝制瓷与制陶分工渐明：瓷器江南为盛，陶业遍及南北。

* **陶俑**：北朝彩绘陶俑发达，武士、侍从、乐舞、胡人、镇墓兽，施红、绿、黄铅釉或彩绘；南方西晋镇墓兽、男女俑与明器模型盛行，东晋后明器减少。
* **砖瓦**：宫室、陵墓、寺院建设推动文字砖、画像砖、莲花纹砖生产。
* **建筑陶**：排水管、瓦当、脊饰、栏板；佛教兴起带来塔砖、造像相关陶作。

六朝三百六十年间，江南瓷业由东汉点状窑场发展为跨州郡窑网，越窑体系确立全国制瓷标杆；北方经北魏恢复，白瓷萌芽与莲花尊等特殊器形出现，南北在技术、器形、宗教题材上交流频繁，直接导入隋代南北合流与唐代「南青北白」格局。

<br>

## 隋唐五代

对应原书第五章（p.180–226）。隋统一南北，唐在更宽阔基础上建大帝国；经东晋南朝三百年开发，长江流域经济赶上并超过黄河流域，隋大运河促进南北交流。《旧唐书·食货志》载各地漕船所运名产，豫章郡即有「名瓷、酒器、茶铛、茶碗、茶臼」。安史之乱后刘晏盐铁兼营商业，「四方物价之上下，虽极远不四五日知」，全国市场形成。唐代陆海交通发达，瓷器随丝路与海上航路外销；形成**「南青北白」**，越窑秘色、邢窑白瓷、长沙釉下彩、**巩义窑**（白瓷、三彩、绞胎、唐青花）、花釉异彩纷呈；五代越窑贡瓷仍精，秘色面貌与晚唐越窑基本一致。

> [!NOTE]+ 读此期实物
>
> - **南青北白**：越窑青瓷 vs 邢窑白瓷（《国史补》「天下无贵贱，通用之」）
> - **秘色瓷**：法门寺地宫与物账碑；五代与晚唐越窑相似
> - **巩义窑**（旧称巩县窑）：河南巩义白河—黄冶；白瓷、三彩、绞胎、唐青花
> - **长沙釉下彩**、**唐三彩**（约 800℃ 低温铅釉）
> - **外销**：宁波余姚江乾宁五年（898）沉船；奈良三彩与绞胎枕

<br>

### 隋代

隋与秦相似，历年短促，继唐而起。隋瓷窑址见于今河北、河南、安徽、江西、浙江、湖南、四川等十县。

| 窑场 | 胎釉特征 | 时代意义 |
| :--- | :--- | :--- |
| **越窑（延续）** | 胎灰，釉青黄、青绿；器形继承南朝而渐趋浑厚 | 南方青瓷为主，为唐越窑鼎盛奠基 |
| **邢窑** | 胎洁白，釉白而常略泛青 | 白瓷产量质量提高，与青瓷并列 |
| **巩义窑**（旧称巩县窑） | 白瓷进展；后兼三彩、青花、绞胎 | 中原综合窑场 |
| **相州窑（安阳）** | 白、青、黄釉及三彩式铅釉器 | 承范粹墓传统，为唐三彩重要产地 |

隋器形浑厚、创新少；纹饰较简，常见**波浪纹**（口沿、盘心弦纹处）、**贴花**（五叶与印花穿插，饰颈肩）。龙窑、馒头窑并用，装烧与胎釉配方在南北交流中继续改进。

隋代虽享国短，但结束南北分裂，使越窑、邢窑、巩义窑、相州窑等此前分途发展的窑口处于同一政治与市场框架内，为唐代窑址数量激增（约为隋之五倍）与品种竞争创造条件。

<br>

### 青瓷

| 窑场 | 主要窑址 | 胎釉特征 | 时代意义 |
| :--- | :--- | :--- | :--- |
| **越窑** | 上虞窑寺前、**帐子山**、**凌湖**；余姚**上林湖**至慈溪上岙湖、白洋湖 | 胎灰，釉青黄至青绿莹润；晚唐追求「类玉」 | 唐五代南方魁首；陆羽《茶经》列越州瓷为上 |
| **秘色瓷** | 越窑贡瓷 | 釉色淡青，光泽晶莹 | 1987 年陕西法门寺地宫与物账碑「秘色」器相符；吴越贡唐及政治交换 |
| **婺州窑** | 金华及周边 | 胎深灰，釉青中带乳白星点 | 地方青瓷，与越窑同系而异貌 |
| **瓯窑** | 温州、永嘉 | 胎薄釉淡青，结合紧密 | 浙南精品，晚唐质量提升 |
| **岳州窑** | 湖南湘阴 | 胎灰白，釉青、酱绿、酱黄；玻璃质强，多开冰片 | 产量大，《茶经》与越窑并提；较早普遍匣钵 |
| **长沙窑** | 长沙铜官镇、望城 | 胎较粗，釉青或青黄；**釉下褐、绿彩** | 中晚唐釉下彩绘，突破单色调；壶文「家小口，天下有名」 |
| **邛窑** | 四川邛崃什坊堂 | 青釉为主；褐绿彩斑、釉下彩；**省油灯**（夹层注水降温） | 西南青瓷与彩绘中心；瓷塑杂技俑传神 |
| **耀州窑前身** | 陕西铜川黄堡 | 唐五代烧青瓷 | 为宋代耀州窑成熟奠基 |

**越窑装饰**：线刻莲荷、流云、花鸟、云龙及人物故事；部分口沿包金，称「金扣」「金棱秘色」。唐墓中青瓷出土量仍多于白瓷，越窑代表青瓷最高水平。

**秘色瓷**：陆羽《茶经》以越州瓷为上，邢窑白瓷与之并称。1987 年陕西扶风**法门寺**地宫出土与物账碑所载「秘色」瓷器相符，釉色淡青、晶莹润泽，为吴越国贡唐及外交礼品。秘色并非独立窑口，而是越窑精选贡品；五代吴越继续进贡，典型秘色与晚唐越窑一脉相承。

**岳州窑与洪州窑**：岳州（湘阴）产量大，釉色青、酱绿、酱黄，玻璃质强，冰片纹多，《茶经》与越窑并提。洪州（丰城）青瓷胎釉具江西特色，与越窑、瓯窑共同构成唐代江南青瓷网络。

**邛窑特色**：提梁罐口大于底、斜直罐身、口缘弓形提梁；油灯夹层中空可注水减热、省油，南宋《老学庵笔记》省油灯形式与此相近。罐肩褐绿彩斑、点彩与长沙窑有共通之处；成都灌县窑为淡黄釉无光，具四川特色，五代仍烧淡黄绿彩。

<br>

### 白瓷

白瓷自北朝晚期经隋至唐成熟。**邢窑**（河北内丘、临城）胎质细洁，釉白润；初唐多闪青，盛唐后趋纯正；精粗并用，李肇《国史补》称「天下无贵贱，通用之」。可刻「盈」「翰林」款或「丁大刚作瓶大好」等工匠、广告文字；造型吸收波斯金银器忍冬、葡萄、胡人乐舞纹样。

| 窑场 | 主要窑址 | 特征 |
| :--- | :--- | :--- |
| **定窑前身** | 河北曲阳涧磁村 | 晚唐兴起，胎釉渐轻薄 |
| **巩义窑** | 河南巩义白河、黄冶等 | 白瓷常施化妆土；兼烧三彩、绞胎、唐青花（详下节） |
| **其他** | 曲阳、鹤壁、密县、登封、郏县、荥阳、安阳、浑源、平定、耀州、萧县等 | 形成「南青北白」中北方白瓷网络 |

长江以南迄 20 世纪 70 年代末考古普查时尚未确认唐烧白瓷窑址；苏、浙、湘、粤、闽唐墓中或见白瓷，产地与窑址关系仍有讨论，不宜断言南方从未烧造。

邢窑、巩义、曲阳、定窑前身等共同构成北方白瓷带，与南方青瓷带对峙，形成「南青北白」格局。

<br>

### 巩义窑

**巩义窑**（旧称**巩县窑**）位于今**河南巩义市**，沿伊洛河支流西泗河两岸分布，自上游**白河**至下游大小**黄冶**、铁匠炉、水地河等，有「十里窑场」之称；国保单位统称巩义窑址。北朝—隋兴起，**唐代鼎盛**，晚唐至宋渐衰。北方综合窑场，品种远不止白瓷一端。

| 品种 | 窑址重心 | 要点 |
| :--- | :--- | :--- |
| **白瓷** | 白河一带 | 胎较邢窑粗，多施**化妆土**；碗盘多见玉璧底、花口 |
| **唐三彩** | **黄冶窑** | 目前确认最早、规模最大的唐三彩窑址之一；俑、马、骆驼、日用器 |
| **绞胎** | 黄冶、白河 | 唐代绞胎**主产地**；花枕、盘、杯；窑址有素烧残片 |
| **唐青花／白釉蓝彩** | 巩义诸窑 | 釉下或釉中钴蓝点绘；元明青花先声 |
| **单色釉** | 各窑 | 黑釉、酱釉、黄釉、白釉绿彩等 |

#### 绞胎（巩义为主）

**绞胎**（亦称搅胎）：白、褐（或黄褐）两色坯泥分别制泥片／泥条，叠合绞揉后切片、镶贴或拉坯，纹理深入胎体，再施透明釉或黄釉烧成，外观如木理、大理石。仿犀毗漆器与织纹趣味。

* **产地**：唐代以**巩义窑**为中心（非河北磁州）；陕西等地亦有出土／仿烧；宋河南**修武当阳峪**续烧绞胎、**绞釉**（釉面搅色，与绞胎有别）。
* **器形**：长方**花枕**最著，另有碗、杯、三足小盘；枕面常作团花、菱形镶片，侧面或为木理纹以省料。
* **款识**：传世／出土见「**杜家花枕**」「**裴家花枕**」等，反映商品化作坊。
* **工艺**：窑址采集花枕**素烧**残片，证可先素烧再施釉；懿德太子墓出绞胎骑马俑，为罕见绞胎塑像。
* **外销**：日本奈良大安寺等出唐绞胎枕，与三彩同路。

> [!WARNING]+ 勿混产地
>
> - **绞胎** → 河南**巩义**（唐）／当阳峪（宋）
> - **白地黑花** → 河北**磁州窑**（观台、彭城）
> - 二者皆「花」，一为**胎泥绞纹**，一为**化妆土上彩绘**

<br>

### 色釉与花釉

| 品种 | 产地 | 胎釉特征 | 时代意义 |
| :--- | :--- | :--- | :--- |
| **黄釉** | 安徽淮南、河南、河北 | 铁作呈色剂 | 丰富单色釉体系 |
| **黑釉** | 陕西铜川黄堡窑等 | 釉黑或茶叶末 | 宋代黑瓷著名窑系先导 |
| **花釉**（鲁山花釉） | 河南鲁山、郏县，山西、陕西 | 黑褐／天蓝底上窑变月白、蓝褐斑 | 唐代窑变装饰高峰 |

花釉与巩义绞胎、长沙釉下彩并列为唐装饰突破；钧窑铜红窑变可视为其北方色釉窑变传统之后续。

### 三彩与雕塑

**唐三彩**为低温铅釉陶器（非瓷）：白色黏土胎，铜、铁、钴、锰等着色，炼铅熔块与铅灰助熔，约 **800℃** 烧成。釉色深绿、浅绿、翠绿、蓝、黄、白、赭、褐等，「三彩」实指多彩；单彩、二彩、三彩并存。铅降低熔点，着色氧化物扩散浸润，形成斑驳彩釉；铅亦增釉面光亮度。

主要产于**河南巩义黄冶**、关中**黄堡**、河北等地，多作**随葬明器**；唐典章规定各等级官员随葬明器数量。品类：文官、武士、仕女、胡人、镇墓兽、天王俑；马、骆驼；壶、罐、枕、建筑模型。造型写实，盛唐达高峰；范粹墓北朝铅釉加彩可视为前驱。

| 步骤 | 内容 |
| :--- | :--- |
| **制坯** | 白色黏土或坩土 |
| **素烧** | 约 1000℃ |
| **施釉** | 含铅硅酸铝釉，加 Cu、Fe、Co、Mn 等着色 |
| **釉烧** | 约 800–900℃；各色互相浸润 |

除三彩外有素胎或单彩俑；骆驼、胡人、胡乐胡舞与丝路胡风相应。唐亡后辽三彩、金三彩及日本**奈良三彩**（仿唐）均未能再现盛唐水平；奈良大安寺、安部寺址出唐三彩与绞胎枕数十件。

<br>

### 五代

中原战乱波及三彩产区，南方青瓷相对延续。吴越越窑贡瓷仍精，典型秘色瓷与晚唐越窑在造型、釉色、制作与装饰上基本一致——整体感强、空间开阔、简练浑厚。划花壶四面刻划，疏朗朴素，可窥五代秘色真实面貌。

<br>

### 造型与外销

#### 造型与装饰

唐瓷器形饱满丰劲，口足变化多；碗、盘、碟、壶、瓶、罐、枕、炉、文具齐备。装饰：刻划、模印、堆贴、褐彩点彩、釉下彩绘、绞胎、窑变花釉并存；越窑重线刻，长沙窑重绘画与诗文警语，并饰胡人乐舞、狮子、椰枣对鸟等迎合海外市场。

#### 窑址扩展与外销

隋瓷窑址约七省十县；唐扩至**十二省五十余县**，山东、江苏、陕西、福建、广东等纳入，唐窑址约为隋**五倍**，为宋代繁荣准备条件。

| 路线 | 主要品种 | 发现与影响 |
| :--- | :--- | :--- |
| 海上 | 越窑青瓷、长沙窑褐彩、邢窑白瓷、巩义三彩／绞胎 | 1974 年**宁波余姚江**出海口唐沉船数百件越窑、长沙窑瓷及黑釉器；同出「**乾宁五年**」（898）砖，证为明州出海赴朝鲜、日本之船 |
| **东亚** | 越窑、长沙窑、三彩 | 朝鲜出长沙窑「家小口，天下有名」褐彩壶；日本太宰府出瓜棱褐绿斑青瓷壶；奈良出三彩、绞胎枕、越窑瓷；福冈、平城京亦有越窑发现 |
| **陆路** | 青瓷、白瓷、三彩 | 经西域至西亚；白瓷与金银器造型互鉴 |

至迟 9 世纪下半叶起陶瓷已输出国外，为宋代外销开先路；史书或失载，瓷片记录古代友好往来。

#### 经济背景

韦坚江淮漕运各郡贡物中，豫章郡贡「名瓷、酒器、茶铛、茶碗、茶臼」，反映瓷器已与茶叶、酒器同为区域名产。刘晏盐铁转运兼营商业，物价信息「极远不四五日知」，全国市场形成有利于窑业规模扩大与品种竞争。唐三彩骆驼俑、胡商形象与丝路繁荣相应；瓷器与丝织品同样经陆海输出。

#### 五代与宋的衔接

五代十国战乱中，中原三彩产区衰落，越窑、瓯窑等南方青瓷相对延续；吴越钱氏保境安民，越窑贡瓷质量不坠，为宋代龙泉、官窑兴起保留技术与审美积累。隋七省十窑、唐十二省五十余窑的扩展，使名窑分布圈涵盖后世定、汝、官、哥、龙泉、建窑、德化等所在区域，唐代因此被视为承上启下的陶瓷扩张期。

## 宋辽金

对应原书第六–七章（p.227–330）。北宋（960—1127）、南宋（1127—1279）为古代瓷业制度与品种最繁富的时期；辽（916—1125）、金（1115—1234）与两宋并立，中原窑业北传并与游牧民族文化交融。

收藏史常称**「五大名窑」**：柴、汝、官、哥、定（明清文献一系）；或以钧代柴，作**汝、官、哥、钧、定**。下文**柴、汝、官、哥（及弟窑）、定、钧**六者专节并列，不可缺漏；另述六大窑系商品瓷（耀州、磁州、龙泉、青白等）与建窑、吉州黑釉。读实物宜先辨窑口，再察胎釉与装烧痕迹，最后联系贡瓷制度、榷场互市与海路外销。

| 维度 | 宋代核心特征 | 辽金附加线索 |
| :--- | :--- | :--- |
| 窑业布局 | 南青北白；民窑为主、官窑精品化 | 中原窑口北延；契丹、女真造型与釉彩 |
| 胎釉 | 高铝质瓷土；一次或多次上釉；还原焰青瓷、氧化焰白瓷 | 定窑白瓷续烧；钧釉北传；辽三彩 |
| 装饰 | 刻划印贴、白地黑花、窑变、黑釉结晶 | 鸡冠壶、凤首瓶等民族器形 |
| 装烧 | 匣钵、支钉、覆烧芒口、垫圈叠烧 | 缸瓦窑、龙泉务等北方窑场 |
| 制度 | 《宣和博古图》、官窑贡瓷、市舶司 | 榷场互市；战争后工匠北迁 |

> [!NOTE]+ 读此期实物
>
> - **名窑（必辨）**：柴（文献）、汝（清凉寺天青、芝麻钉、冰裂纹）、官（修内司／郊坛下）、哥（传世开片）／弟（龙泉）、定（曲阳）、钧（神垕）
> - **呈色**：铁还原→青；铜还原→红；铜氧化→绿；温度与气氛窗口决定成败
> - **窑系**：耀州（黄堡）、磁州（**磁县观台**—**峰峰彭城**，主打白地黑花）、景德镇（湖田）、龙泉（大窑）、建窑（水吉）、吉州（永和）
> - **勿混**：定窑白瓷 ≠ 磁州白地黑花；绞胎在巩义／当阳峪 ≠ 河北
> - **装烧**：汝官裹足支钉、定窑覆烧芒口、匣钵单件烧造
> - **外销**：泉州、广州、明州海路；高丽、日本、东南亚、福斯塔特等地宋瓷堆积层

### 时代背景

#### 制度与经济

宋代城市商业与海外贸易空前发达。**市舶司**（广州、泉州、明州、秀州等）管理舶货与抽分，瓷器为大宗输出品之一。宫廷用瓷需求推动**官窑**体系形成：北宋晚期汝窑为宫廷烧造；南渡后于临安设**修内司官窑**、**郊坛下官窑**。民窑则面向城乡市场与外贸，定窑、磁州窑、景德镇青白瓷、龙泉窑产量巨大。

《宣和博古图》（约 1123 年成书）系统著录古代铜器形制，间接推动瓷器仿古铜造型（炉、尊、觚、奁）。斗茶风尚使黑釉盏（建窑、吉州）与**建茶等末茶**配套——斗茶以**沫色鲜白**衬黑盏，文献如蔡襄《茶录》、宋徽宗《大观茶论》均有专论。

#### 窑业格局

「六大窑系」之说见叶喆民等学者归纳：以**定窑**（白瓷）、**钧窑**（窑变釉）、**耀州窑**（刻花青瓷）、**磁州窑**（白地黑花）、**龙泉窑**（厚釉青瓷，即文献「弟窑」一系）、**景德镇青白瓷**（影青）为代表，覆盖南北主要商品瓷。收藏史上的**柴、汝、官、哥、定**（或以钧代柴）属精品／文献层，与「窑系」概念不同：汝、官、哥传世稀少而考古进展显著（清凉寺、修内司、郊坛下已确认；传世哥窑窑址仍无公认结论；柴窑仅见文献）。

| 区域 | 代表窑口 | 主要产品 |
| :--- | :--- | :--- |
| 华北 | 定窑、磁州窑、钧窑、介休窑、鹤壁集窑 | 白瓷、白地黑花、钧釉 |
| 西北 | 耀州窑 | 刻花青瓷 |
| 江南 | 景德镇、龙泉、越窑系残脉 | 青白瓷、龙泉青瓷 |
| 闽赣 | 建窑、吉州窑 | 黑釉盏 |
| 辽金境 | 缸瓦窑、龙泉务、喀左水泉 | 辽三彩、鸡冠壶、仿定白瓷 |

### 定窑及磁州窑系

#### 定窑

定窑为宋代北方白瓷典范，窑址主要在今**河北曲阳涧磁村**及**燕川、野北、东燕川、北镇**等地；1980 年代以来考古揭示窑场规模宏大，烧造上限可溯至唐，五代、北宋中晚期为全盛，金元仍续烧。

**原料与胎**：采用当地高岭质瓷土，经多次淘洗、沉淀，胎质细坚，胎色白或略泛黄（部分见「黑定」「紫定」等色釉品种，属少数）。北宋中晚期胎体趋薄，修坯精整，圈足处理利落。

**釉**：白釉为透明或半透明石灰釉，釉层薄而匀，呈「象牙白」或白中微闪黄；釉面常见因施釉流动形成的「泪痕」。刻花、划花器因釉层厚薄差异呈现「出筋」效果——纹样凸起处釉薄而胎色透显。

**装饰技法**：早期以刻花、划花为主，纹样有莲瓣、缠枝、游鱼、水波、云纹；中晚期**印花**高度发达，模印纹样繁密规整，与刻划并用。代表器有碗、盘、罐、瓶、炉、枕；**净瓶**、**孩儿枕**（故宫博物院藏白釉孩儿枕为北宋定窑名例）、折腰碗、花口盘等为名品。

**装烧——覆烧与芒口**：北宋中晚期普遍采用**覆烧**法——碗盘口沿朝下叠置于锥形或筒形**垫圈**（「支圈」）上，内底无釉，口沿亦因叠压而无釉，形成**芒口**（涩口）。为提高使用品质，芒口常包以铜、金、银扣，文献称「定州花瓷瓯，颜色天下白……又有芒口，便于使用」类记述。覆烧大幅提高窑位利用率，影响北方诸窑（定窑系、部分磁州窑）装烧方式。

**支烧与款识**：部分精细小件采用**支钉烧**（裹足支烧），足端见细小支痕；传世与出土定窑器中偶见「官」「新官」「尚食局」等款，与贡御或官府定货相关，具体制度学界仍有讨论。

**时代意义**：定窑将白瓷日用化、商品化推向极致，与邢窑传统一脉相承而工艺更精；汝窑、官窑、景德镇均曾仿定白釉；金代曲阳定窑仍产印花白瓷，元明渐衰。

#### 磁州窑系

磁州窑是宋金元北方最大的**民间彩绘瓷**窑系。窑址不在「河北随便一处」，而集中在古**磁州**辖境两片：

| 中心 | 今地 | 流域 | 时代重心 |
| :--- | :--- | :--- | :--- |
| **观台窑** | 河北**磁县观台镇**（及东艾口、冶子等） | 漳河 | 宋金代表；珍珠地划花、白地黑花精 |
| **彭城窑** | 河北**邯郸峰峰矿区彭城镇**（及临水等） | 滏阳河上游 | 金元以降更盛；「南有景德，北有彭城」 |

创烧可溯北朝，宋金元为繁荣期。同系窑场遍及河北、河南、山西、山东、陕西等地（鹤壁、扒村、当阳峪、介休、淄博、陈炉等），统称「磁州窑系」。

**胎釉**：灰白／浅灰胎，含铁较高，**必须先罩白色化妆土**再绘彩、施透明釉——白地效果来自化妆土，不是定窑那种细白瓷胎。

#### 白地黑花 ≠ 黑地白花

河北磁州窑给人印象的「黑白花」，正称与主次如下，勿颠倒：

| 名称 | 地／花关系 | 做法 | 地位 |
| :--- | :--- | :--- | :--- |
| **白地黑花**（白釉黑彩、铁锈花绘） | **白底上画黑花** | 化妆土上用高铁黑／褐料绘画，罩透明釉一次烧 | **招牌品种**，数量最多；婴戏、花鸟、鱼藻、诗词 |
| **黑地白花** | **黑底上显白花** | 多先划出花纹，花外填黑或剔去化妆土露深色胎／黑彩，使花留白 | 有，但**远少于**白地黑花；常与剔花技法交叉 |
| **白釉剔花** | 白地上凸起花纹 | 剔去花外化妆土，花部留白凸起 | 浮雕感强 |
| **黑釉剔花** | 黑釉地上露胎花 | 黑釉地剔出纹样 | 另路对比 |
| **珍珠地划花** | 白地＋珠点地纹 | 划花后再戳密珠点 | 观台窑尤精；枕、瓶常见 |

> [!INFO]+ 河北黑白对照
>
> - 磁州窑黑白装饰以**白地黑花**为主（白化妆土地＋黑彩画花），不是黑地白花
> - **黑地白花**是次要／变体，不能当成磁州窑总称
> - **定窑**在河北曲阳，是**白瓷刻印花**，不是黑白彩绘；「黑定」指黑釉定瓷，与磁州白地黑花无关
> - **绞胎**在河南巩义，也不在河北磁州

**装饰技法表**：

| 技法 | 工序要点 | 典型纹样 |
| :--- | :--- | :--- |
| **白地黑花** | 化妆土上绘黑（褐）彩，罩透明釉 | 婴戏、花鸟、鱼藻、诗词 |
| **黑地白花／剔填** | 留白花、地填黑或剔地 | 缠枝、开光花卉 |
| **剔花** | 剔化妆土留花或留地 | 缠枝牡丹、游鱼 |
| **珍珠地划花** | 地子戳印细密珠点，上划花纹 | 禽鸟、花卉 |
| **铁锈花** | 黑釉上泼洒高铁彩料 | 斑彩流动 |
| **红绿彩** | 釉上或低温二烧彩 | 金代后更盛 |

纹样取材民间：婴戏、花鸟、鱼藻、山水、诗词题款（如「清沽美酒」），构图疏朗自由；瓷枕底常戳「张家造」「李家造」等作坊款。与定窑宫廷—士人白瓷审美形成对照。

**窑址扩散**：**山西介休窑**、**河南鹤壁集窑**、**禹州扒村窑**、**修武当阳峪窑**（兼烧绞胎、绞釉，勿与磁州黑白花混称产地）、**山东淄博窑**、**陕西铜川陈炉窑**等，均产白地黑花或同类装饰。

**时代意义**：磁州窑系面向广大城乡市场；**白地黑花**开创釉下彩绘民间路径，直接影响元磁州彩绘及明清民窑；与定窑精白瓷形成河北「雅俗」双轨——曲阳定窑 vs 观台／彭城磁州。

### 耀州窑与钧窑系

#### 耀州窑

耀州窑位于今**陕西铜川黄堡镇**（亦烧陈炉、立地坡等地），创烧于唐，五代、**北宋**为青瓷高峰，金元仍烧造，明终烧。

**胎**：灰白或灰褐胎，质坚，部分施化妆土。

**釉**：青釉为主；北宋中晚期釉色呈**橄榄绿**或**青绿**，玻璃质感强，釉层较厚。部分器外壁施**半釉**——器身下半截刮削露胎，称「半刀泥」式处理，露胎处可见规整刀痕与旋坯纹。

**装饰——刻花**：在半干坯上刻出纹样，线条犀利流畅；常配合**篦划**（篦状工具划出水波纹、篦纹地）。纹样多缠枝牡丹、莲花、飞凤、婴戏、水波游鱼。印花、划花、贴塑亦见。

**器形**：碗、盘、瓶、尊、壶、盒、枕、罐；**刻花梅瓶**、多曲柄执壶、镂空熏炉等为代表。宋人诗「巧如范金，精比琢玉」即指耀州刻花；陆游诗中「耀州出青瓷器，越州出秘色瓷器」反映其知名度。

**装烧**：普遍使用**匣钵**单件或数件装烧，减少烟熏与落渣，提高成品率；足端见垫砂或垫片痕。

**时代意义**：耀州窑为北方青瓷代表，刻花技法影响河南等地（如临汝窑、宝丰窑部分产品）；产品行销关中及中原，与南方龙泉青瓷形成南北呼应。

#### 钧窑系

钧窑中心在今**河南禹州神垕镇**；创烧于唐，北宋、金为全盛。钧窑属北方青瓷系统，以**铜红窑变**釉色著称，与耀州刻花青瓷风格迥异。

**胎**：多数呈「**紫口铁足**」——口沿因釉薄而显酱紫色，圈足刮釉露胎处呈铁褐色；胎色灰或紫灰，质坚。

**釉**：基本釉色为**天蓝**、**月白**；在青釉基料中加入铜作着色剂，经窑内气氛变化形成**玫瑰紫**、**海棠红**、**茄皮紫**等窑变斑块，「入窑一色，出窑万彩」。釉层厚，有自然流淌形成的「蚯蚓走泥纹」（开片与釉流交织）。钧窑普遍采用**二次施釉、二次烧成**（或先素烧再施釉正烧），以容纳厚釉。

**器形**：北宋多**炉、尊、花盆、盆、奁**等陈设器与花盆类，碗盘相对较少；器底常刻数字「一」至「十」，与宫廷陈设配套有关（具体对应关系学界尚有讨论，或指器形大小排序）。金代钧瓷产量扩大，碗、盘、炉、盆等日用器增多。

**窑系扩散**：禹州**钧台窑**、**刘家门窑**，**郏县黄道窑**、**鲁山段店窑**、**安阳相州窑**部分产品带钧釉特征；金元时期钧釉窑场遍及豫西。

| 对比项 | 耀州窑 | 钧窑 |
| :--- | :--- | :--- |
| 窑址 | 陕西铜川黄堡 | 河南禹州神垕 |
| 釉色 | 橄榄青绿 | 天蓝、月白、窑变紫红 |
| 装饰 | 刻花、篦划 | 窑变为主，少刻花 |
| 器类 | 日用碗盘瓶 | 陈设器、花盆（北宋） |
| 足端 | 常规露胎或垫烧 | 紫口铁足 |
| 施釉 | 一次或两次 | 多次施釉为常 |

**时代意义**：钧窑将铜红窑变釉推向成熟，为后世钧瓷所宗；与汝窑、官窑同属宫廷赏玩体系；金元扩大生产，影响磁州窑「钧紫」装饰。

### 青白瓷与龙泉窑系

#### 景德镇青白瓷（影青）

青白瓷因釉色介于青白之间，宋人称为「青白」；后世称「**影青**」，因釉层透明可映刻划纹样。窑址以今**江西景德镇湖田**、**湘湖**、**南河**、**落马桥**为核心；并波及**江西**（南昌、丰城、吉安等地）、**福建**（德化、同安、南安）、**安徽**（繁昌、歙县）、**浙江**（金华）、**湖北**（武昌）等地，形成「青白瓷系」。

**胎**：以**瓷石**为主（高岭土系统掺入至元以后才普遍成熟，宋青白瓷不宜径称二元配方），胎质细白坚致，胎体轻薄，可做成镂空、瓜棱、花口等精细造型。

**釉**：青白釉，釉色分档——**粉青**（偏青）、**月白**（偏白）、**影青**（透明映纹）；北宋中晚期釉色最精，南宋因原料或烧成略趋灰黄。釉为石灰釉，玻璃质透明。

**装饰**：刻花、划花、印花、堆塑；常见缠枝、莲瓣、牡丹、飞凤、婴戏、梅竹。器形极丰：碗、盘、盒、瓶、壶、炉、枕、塑像；**瓜棱壶**、**多管瓶**、**魂瓶**（南方随葬）、**观音像**等为代表。

**装烧**：龙窑、葫芦窑并用；**匣钵**装烧普及，垫饼、垫柱支烧，圈足内常留涩圈（垫饼痕）。

**外销**：青白瓷为宋元外销瓷大宗。考古发现：**印度尼西亚**爪哇、**菲律宾**、**马来西亚**、**越南**、**埃及福斯塔特**、**肯尼亚**等地均有大量江西—福建系青白瓷；**南海 I 号**等沉船出水以青白瓷、龙泉瓷为主。福建、广东窑场仿烧，称「外销青白瓷」，器形常适应伊斯兰市场（如无猪纹、扁壶、执壶）。

**时代意义**：景德镇由此奠定千年瓷都基础；青白瓷技术为元代卵白釉、青花提供胎釉基础。

#### 龙泉窑系

龙泉窑位于今**浙江龙泉大窑**、**金村**、**溪口**、**茶碗窑**、**道太**等地；受越窑影响，五代、北宋始烧，**南宋**至元明为鼎盛。

**胎**：灰白胎或「**白胎**」（南宋官窑系统影响下部分精品胎色更白、更细）；一般产品胎体厚重，胎色灰白。

**釉**：青瓷釉；北宋早期偏青黄；南宋形成**粉青**、**梅子青**——**粉青**釉色青绿柔和，釉层厚如堆脂，失透温润；**梅子青**釉色葱绿，玻璃质感强，为龙泉巅峰釉色。采用**多次施釉、多次素烧**（或反复施釉一次烧成），釉层可达 1—2 mm 以上。

**装饰**：总体倾向「少纹重釉」；部分刻划莲瓣、云纹、双鱼；南宋晚期印花、贴花增多。器形：碗、盘、洗、炉、瓶、尊、觚、罐、奁；**贯耳瓶**、**凤耳瓶**、**双鱼洗**、**荷叶形盖罐**、**奁式炉**为名品。

**装烧**：龙窑长段烧造；**垫饼**、**垫柱**支烧，圈足常留火石红与垫痕；精品小件偶见支钉。

**龙泉窑系扩散**：**浙江**庆元、云和、**福建**同安、泉州、**广东**新会等地有龙泉风格青瓷窑场；**海牙**、**东京国立博物馆**等藏南宋龙泉精品，多经海路输出。

| 品种 | 核心窑址 | 釉色关键词 | 装饰倾向 | 主要外销期 |
| :--- | :--- | :--- | :--- | :--- |
| 青白瓷 | 景德镇湖田 | 青白、影青、月白 | 刻划印花 | 北宋—元 |
| 龙泉青瓷 | 浙江龙泉大窑 | 粉青、梅子青 | 厚釉少纹 | 南宋—明 |

**时代意义**：龙泉窑为南宋青瓷主流，与官窑、哥窑（传世）并立；「梅子青」「粉青」代表古代石灰碱釉青瓷高峰；产品通过明州、泉州海路大量外销。

### 宋代黑釉

宋代**点茶**、**斗茶**盛行：茶末入盏，注汤击拂起沫，以沫色鲜白、水痕咬盏为胜；**黑釉盏**衬托白沫，为必备器。同时黑釉瓶、罐、炉等亦流行。

#### 建窑

建窑位于今**福建建阳水吉窑**（含芦花坪、大路后门、牛皮仑等窑址）；创烧于晚唐五代，**宋代**为高峰，元明续烧。

**胎**：**厚胎**，胎色紫黑或灰黑，质坚，含铁量高，利于黑釉呈色。

**釉——析晶与窑变**：黑釉富铁；在适宜冷却速度下铁氧化物析晶，形成：

| 名称 | 外观 | 成因概要 |
| :--- | :--- | :--- |
| **兔毫** | 细线状放射纹 | 赤铁矿析晶成丝 |
| **油滴** | 点状银彩或异色点 | 铁富集相析晶 |
| **曜变** | 蓝紫至天青斑块 | 极稀，窑内特殊气氛与冷却 |
| **鹧鸪斑** | 白褐斑点 | 窑变或人工洒斑 |

釉层厚，口沿常因釉薄而呈酱色（「酱口」）。代表器为**束口盏**、**敞口盏**，口径与斗茶点汤相适应（常见 9—12 cm）。

**装烧**：龙窑；匣钵或圈足叠烧；入盏常作随葬或窖藏整组出土。

**文献与影响**：蔡襄《茶录》「茶色白，宜黑盏……建安所造者绀黑，纹如兔毫」；宋徽宗《大观茶论》详述盏品。建盏经**天目**路径影响日本茶道（抹茶碗）；朝鲜、东南亚亦有出土。

#### 吉州窑

吉州窑位于今**江西吉安永和镇**；五代至元烧造，**宋代**为盛，与建窑形成闽赣黑釉对照。

**胎**：**砂胎**（含铁砂、局部粗松）或施化妆土；与建窑厚胎紫胎不同。

**釉**：黑釉为主，另有青釉、白釉、绿釉、**玳瑁釉**（黄、褐、黑交融）、**鹧鸪斑**等。

**装饰——木叶与剪纸**：

* **木叶纹**：将经处理的**桑叶**（或类似叶脉清晰之叶）贴于黑釉上，一次烧成，叶脉清晰呈黄褐，为吉州窑标志性品种。
* **剪纸贴花**：剪纸图案贴于胎或釉上，施釉烧成，形成对称纹样（如梅花、团花）。
* 另有洒釉、贴花、白地绘花、**窑变玳瑁**等。

**器形**：盏、瓶、罐、炉、枕；**长颈瓶**、**双耳罐**、**菩萨像**等亦见。

**时代意义**：吉州窑产品面向民间与禅茶；木叶纹体现一次烧成工艺高度；与建窑「重析晶」不同，吉州重贴花、窑变斑彩。

| 窑口 | 窑址 | 胎 | 黑釉特色 | 典型器 |
| :--- | :--- | :--- | :--- | :--- |
| 建窑 | 福建建阳水吉 | 厚胎紫黑 | 兔毫、油滴、曜变 | 束口盏 |
| 吉州窑 | 江西吉安永和 | 砂胎、化妆土 | 木叶、剪纸贴花、玳瑁斑 | 盏、瓶 |
| 玳瑁系 | 赣闽多地 | 各异 | 黄褐黑交融 | 盏、瓶 |
| 黑定 | 河北曲阳 | 白胎 | 黑釉变体 | 碗、瓶 |

### 柴、汝、官、哥（弟）、定、钧

明清鉴赏文献常以**柴、汝、官、哥、定**为序（张应文《清秘藏》「论窑器，必曰柴、汝、官、哥、定」；《宣德鼎彝谱》作柴、汝、官、哥、钧、定）。柴窑实物与窑址未确证，故近现代「宋代五大名窑」多作**汝、官、哥、钧、定**。下文六者并列：柴（文献）、汝、官、哥与弟窑、定、钧——定、钧前文已详窑系工艺，此处补名窑脉络与辨识要点。

| 窑口 | 时代重心 | 窑址／文献 | 核心特征 | 考古现状 |
| :--- | :--- | :--- | :--- | :--- |
| **柴窑** | 传五代后周 | 传郑州等地 | 「雨过天青」；青如天、明如镜、薄如纸、声如磬 | 窑址未确认；无公认传世标准器 |
| **汝窑** | 北宋晚期 | 宝丰清凉寺等 | 天青／粉青；香灰胎；裹足芝麻钉 | 清凉寺已确认；张公巷仍有讨论 |
| **官窑** | 北宋存疑／南宋确 | 修内司、郊坛下 | 紫口铁足；薄胎厚釉；大开片 | 南宋两处已确认 |
| **哥窑** | 传南宋 | 传世器；龙泉黑胎青瓷一说 | 金丝铁线；紫口铁足 | 传世哥窑窑址未公认；龙泉哥窑／黑胎青瓷另立 |

#### 呈色机理（铁·铜·温度·气氛）

釉色由**呈色剂价态 × 窑内气氛 × 烧成温度 × 釉料助熔／显微结构**共同决定。读汝窑天青、钧窑窑变、霁红豇豆红，宜先把握此表：

| 呈色剂 | 氧化焰（供氧足） | 还原焰（缺氧、CO／H₂ 多） | 典型品种 |
| :--- | :--- | :--- | :--- |
| **铁 Fe** | 高价 **Fe³⁺（Fe₂O₃）** → 黄、褐、酱、柿红 | 低价 **Fe²⁺（FeO）** → **青、青绿、天青** | 青瓷（汝、官、龙泉、越）；黄釉／酱釉（氧化） |
| **铜 Cu** | **Cu²⁺（CuO）** → 绿、孔雀绿 | **Cu⁺／胶体铜** → **鲜红、霁红、郎窑红、豇豆红** | 铜红釉；氧化则绿斑（豇豆红苔点即局部氧化／分相） |
| **钴 Co** | 较稳定呈蓝 | 仍以蓝为主 | 青花、霁蓝、天蓝 |
| **金 Au** | — | 低温烤花呈胭脂红 | 胭脂水（非高温一次烧） |

**温度档位（约）**：

* **低温釉**（约 700–1000℃，常加铅助熔）：唐三彩、汉铅绿釉、矾红、珊瑚红、**雍正柠檬黄（锑黄）**、胭脂红烤花——色艳，胎釉结合相对弱。注意：**弘治娇黄／鸡油黄**为高温铁黄，勿与低温锑黄混称。
* **中高温／高温釉**（约 1200–1350℃）：青瓷、白瓷、铜红、霁蓝、**娇黄（鸡油黄）**——玻璃相充分，色稳。汝官青瓷约 **1200±20℃**；成熟龙泉、景德镇高温瓷可更高。
* 同一铁量：还原不足或冷却期**二次氧化**，青瓷易**泛黄**（「米色青瓷」）；还原过强或铁过高则偏灰黑。铜红对气氛极敏感，窗口窄，故「最难全美」。

**显微结构**：汝、钧等乳浊青／窑变釉除化学呈色外，靠**钙长石析晶、分相**造成光散射（乳光、玉质感）；钧窑铜红斑与铁青底釉叠加，遂「入窑一色，出窑万彩」。

#### 柴窑

柴窑之名见于明以后著录，相传为**五代后周世宗柴荣**敕烧，故以国姓称「柴」。《清秘藏》谓柴器「**青如天，明如镜，薄如纸，声如磬**」；又传世宗批示釉色「**雨过天青云破处，者般颜色作将来**」（此语亦常被移用于汝窑天青之形容）。《夷门广牍》等记「柴窑出北地，天青色，滋润细媚，有细纹，足多现黄土」。

**现状**：

* 迄今**未发现公认柴窑窑址**，亦无经科学考古确认的标准器。
* 「五大名窑」中柴居首位，多属文献谱系；近人因柴不可得，常以**钧窑**补入，遂有「汝官哥钧定」之说。
* 部分旧说疑将景德镇**影青**、汝窑天青或其他青瓷误指为柴；鉴定上须与文献、地层严格区分，不可据釉色孤证定名。

> [!WARNING]+ 柴窑
>
> 博物馆与拍卖所见「柴窑」标名多属传称或争议品。笔记中保留柴窑条目，意在完整呈现名窑谱系与文献史，而非认定某件实物即柴。

#### 汝窑

宋人叶寘《坦斋笔衡》：「本朝以定州白瓷器有芒不堪用，遂命汝州造青窑器……**汝州为魁**。」汝窑继定窑之后为宫廷烧造青瓷，窑址在今**河南宝丰清凉寺**（宋属汝州）；宫廷烧造约仅**二十余年**（约哲宗元祐至徽宗崇宁，1086—1106 前后），故传世极少，明清视为至宝。

##### 天青瓷

釉色以**天青**为主，兼**粉青、天蓝、月白、淡粉**等。理想天青如雨后晴空，莹厚如脂，视如碧玉；文献「雨过天青」意象常与柴窑、汝窑并提。故宫藏淡天青釉弦纹三足樽式炉等，可代表满釉支烧、细碎开片之典型面貌。

**胎**：细洁，香灰色（「香灰胎」）；露胎处（支钉痕）呈香灰或浅褐。

**釉质**：釉层薄而莹润（相对龙泉厚釉仍属「薄釉玉质」一路）；釉泡大而稀疏，有「**寥若晨星**」之称。文献载釉中入**玛瑙**；科学检测显示釉属北方青瓷系统——**低硅、高铝、高钙、含磷**，是否特意掺玛瑙仍有讨论，但高 CaO、较高 Al₂O₃ 确为析晶—分相之条件。

##### 胎釉配方与烧成

相对同窑北宋**民汝**青瓷，汝官釉适度提高 **Al₂O₃、CaO**，使接近 SiO₂–Al₂O₃–CaO 系共晶区，利于**钙长石**针状晶簇析出；CaO 约可在 **11%–13%** 量级（官窑制釉技术共性），K₂O 亦相对偏高，增高温黏度，便于较厚、较乳浊之釉层。民汝烧成温度略高；汝官约在 **1220℃ 上下（1200±20℃）**，温度窗口窄，保温不可过长，否则钙长石回熔、乳浊度下降。

**窑炉**：民汝多用北方传统**马蹄形（馒头）大窑**；汝官改用**椭圆形小窑**，更利精确控温控气氛。

**气氛**：**强还原焰**。釉中铁主要以 **Fe²⁺（FeO）** 存在，呈较纯正青色；若还原不足，Fe³⁺ 增多则青中泛黄。降温宜相对缓和，利于析晶—分相结构形成，物理散射叠加化学呈色，产生**蓝色乳光**与玉质感。

| 环节 | 要点 |
| :--- | :--- |
| 呈色剂 | 以**铁**为主（非铜）；铁量适中，过高铁则灰浊 |
| 气氛 | 强还原 → Fe²⁺ → 天青；氧化／二次氧化 → 泛黄 |
| 温度 | 约 **1200±20℃**；过高乳浊减、过低生烧 |
| 显微 | 钙长石析晶＋分相 → 乳光、莹厚 |
| 施釉 | 可多次施釉，增厚以增强玉质感 |

##### 开片：冰裂纹、蟹爪纹、鱼子纹

瓷釉开片因**胎、釉膨胀系数不同**，焙烧后冷却时釉面张应力开裂而成；流传中遇冷热仍可继续开片。本属缺陷，宋人转以为饰。

* **冰裂纹**：层层相叠、如冰破裂之开片，汝窑青瓷釉面多见，自然天成。
* **蟹爪纹**：细小曲折片纹，状如蟹爪，为汝窑常见称谓。
* **鱼子纹**：更细密如鱼子的开片。

汝窑开片一般较官窑、哥窑之「金丝铁线」大片为**细碎**；哥窑刻意强化文武片对比，汝则在天青釉下隐现细纹，不夺釉色。

##### 装烧：裹足与支钉

汝窑典型装烧为**满釉裹足支烧**：

* 通体施釉（含足端），以细小**支钉**支起，避免垫饼涩圈破坏满釉效果。
* 外底常留 **3 或 5** 枚细小支钉痕，状如**芝麻**，称「芝麻钉」；钉痕处露香灰胎。
* 与定窑**覆烧芒口**、龙泉**垫饼露胎**形成对照：宫廷青瓷追求满釉无芒，故用支钉。

故宫淡天青三足樽式炉：外壁弦纹，外底**五支钉**，足端无釉（足端刮釉或支烧变体须据器细辨；官汝以裹足满釉支钉为大宗）。

##### 器形与时代

多仿青铜、玉器：出戟尊、玉壶春、胆瓶、樽、洗、盘、碗、水仙盆、三足炉等；尺寸偏小，制作精整。专供宫廷，非大宗商品瓷。

**考古**：1987 年起清凉寺地层与传世汝窑高度吻合；椭圆形水仙盆、裹足支烧器等可对应。**张公巷**窑址性质（是否同属汝官）仍有讨论。

**时代意义**：五大名窑说中汝常居首（柴不可得时）；明清御窑「仿汝釉」不断。天青＝铁还原青瓷审美巅峰之一；支钉、冰裂、香灰胎为鉴定核心三件套。

> [!INFO]+ 汝窑速记
>
> - **色**：天青为主，铁＋强还原＋析晶乳光
> - **温**：约 1200±20℃，小窑精控
> - **纹**：冰裂纹／蟹爪纹细碎开片
> - **底**：裹足满釉＋芝麻支钉（常 3～5 枚）
> - **胎**：香灰色

<br>

#### 官窑

**传世**：多「**紫口铁足**」，釉色粉青、月白、**油灰**，开片较大；胎色黑或深灰，薄胎厚釉。

**考古——南宋官窑已确认**：

| 窑址 | 位置 | 产品特征 |
| :--- | :--- | :--- |
| **修内司官窑** | 杭州凤凰山（老虎洞窑） | 早期灰青釉，开片细；胎黑薄 |
| **郊坛下官窑** | 杭州乌龟山 | 晚期粉青、灰青，厚釉；支烧与垫烧并用 |

北宋官窑窑址尚存争议：或与汝窑、汴京附近贡窑相关，缺乏如南宋般明确地层。南渡后「袭故京遗制」设官窑，文献与老虎洞、乌龟山考古可互证。

**胎釉**：薄胎厚釉，多次施釉；开片与胎釉膨胀系数差异有关；大开片风格与传世哥窑有交叉讨论。

**时代意义**：南宋宫廷专烧之青瓷规范；上承汝窑，下启明清御窑样制。

<br>

#### 哥窑与弟窑

##### 文献与传说

明人记载：南宋处州龙泉有**章生一、章生二**兄弟各主一窑——兄所烧称**哥窑**，弟所烧称**弟窑**（即龙泉窑典型青瓷，亦称章窑）。郎瑛《七修类稿》等述两窑皆出龙泉，色皆青而足铁色。传说中弟妒兄，混土入釉致开片，开片器反得盛名——属故事层，不可当作工艺史唯一解释。

##### 哥窑（传世与龙泉两系）

**传世哥窑**：以「**金丝铁线**」开片著称——大纹片呈黑褐（铁线）、小纹片呈黄褐／米色（金丝），或称文武片、百圾碎；釉色粉青、灰青、米黄、油灰；胎黑灰，「紫口铁足」；垫烧为主，少数支烧。宋墓罕出、宋人文献未明提「哥窑」之名；元人始有「哥哥洞窑」「哥哥窑」记载，明《宣德鼎彝谱》正式列入名窑。窑址**至今无公认结论**；杭州说、龙泉说并存。

**龙泉哥窑／黑胎青瓷**：龙泉大窑、溪口等地出土**黑胎青瓷**，紫口铁足、开片，釉粉青、灰青，造型近南宋官窑。有学者主张此即文献中的龙泉哥窑，与「传世哥窑」尚有釉面润泽度、开片形态等差异，学界多主张二者分论，再求是否合一。

##### 弟窑（龙泉窑）

弟窑即**龙泉窑**典型产品：白胎或灰白胎，**粉青**、**梅子青**厚釉，少开片或开片不显，釉面温润如玉，「少纹重釉」。南宋至元为盛，考古窑址明确（大窑、金村等），详见上文「龙泉窑系」。与哥窑对照：弟窑重釉色葱翠饱满，哥窑重开片与铁骨胎色。

| 对比 | 哥窑（传世／传说） | 弟窑（龙泉） |
| :--- | :--- | :--- |
| 胎 | 黑灰「铁骨」为典型 | 白胎／灰白胎 |
| 釉 | 粉青、灰青、米黄；开片为饰 | 粉青、梅子青；厚釉少纹 |
| 足 | 紫口铁足 | 垫烧露胎，可有火石红 |
| 窑址 | 传世器窑址未定；龙泉黑胎青瓷已发现 | 龙泉大窑等明确 |
| 审美 | 金丝铁线、百圾碎 | 如玉厚釉、梅子青 |

**时代意义**：哥窑在收藏史与汝、官并列，明清景德镇仿哥釉成大宗；弟窑＝龙泉，代表南宋青瓷商品与外销高峰。笔记中「哥／弟」并置，可避免只记开片而漏掉粉青梅子青一系。

<br>

#### 定窑（名窑要点）

窑址**河北曲阳涧磁村**等，北宋中晚全盛。象牙白釉、刻划印花、**覆烧芒口**（常包金银铜扣）；「官」「新官」「尚食局」等款与贡御相关。详「定窑及磁州窑系」节。名窑谱系中定窑代表北方白瓷巅峰，与汝官哥钧之青／窑变并列为「定」。

<br>

#### 钧窑（名窑要点）

窑址**河南禹州神垕**、钧台等。天蓝、月白底釉＋**铜红窑变**（玫瑰紫、海棠红等），「入窑一色，出窑万彩」；紫口铁足；北宋陈设器底刻「一」至「十」。详「耀州窑与钧窑系」节。因柴窑不可得，钧窑常被列入「宋代五大名窑」以补足青／色釉一席。

<br>

> [!INFO]+ 名窑谱系怎么记
>
> | 说法 | 窑口组合 | 说明 |
> | :--- | :--- | :--- |
> | 文献五大名窑 | 柴、汝、官、哥、定 | 明《清秘藏》等；柴无确证 |
> | 通行五大名窑 | 汝、官、哥、钧、定 | 以钧代柴 |
> | 哥弟传说 | 章生一哥窑、章生二弟窑 | 弟窑＝龙泉粉青／梅子青 |
> | 六大窑系 | 定、钧、耀州、磁州、龙泉、青白 | 商品瓷格局，与「名窑」概念不同 |

### 造型纹饰与外销

#### 造型

宋代瓷器造型趋向秀巧、典雅，比例协调；除日用碗、盘、瓶、罐外，仿古铜礼器（炉、尊、觚）、花器（花盆、花插）、文房（水丞、笔洗）、瓷塑（菩萨、童子）增多。瓜棱、花口、多曲柄、出筋、相环耳等为常见手法；定窑孩儿枕、钧窑花盆、龙泉贯耳瓶等为典型名品。

#### 纹饰

题材以花卉（莲、牡丹、菊、梅）、缠枝、鱼藻、婴戏、禽鸟、云水为主；少见人物故事大图。技法分釉上（较少）、釉下彩（磁州白地黑花）、釉中刻划印花（定、耀州、青白瓷）、窑变（钧）等。宋瓷总体倾向「少装饰、重釉色」或「装饰与胎釉融为一体」，与明清繁缛绘瓷不同。

#### 外销

宋代海外贸易发达，瓷器为主要输出品之一。输出路线包括：① 海路——从东南沿海（广州、泉州、明州等）至东南亚、南亚、阿拉伯、东非；② 陆路——经西北、辽金榷场等。主要外销品种：青白瓷、龙泉青瓷、建窑黑盏、磁州系、广东福建窑青白瓷等。外销器在器形、装饰上常适应海外市场（如伊斯兰金属器造型、堆塑等）。考古发现：韩国、日本、越南、印尼、菲律宾、埃及福斯塔特等地均出土大量宋瓷。

| 外销品种 | 主要窑口 | 主要市场 |
| :--- | :--- | :--- |
| 青白瓷 | 景德镇及闽粤系 | 东南亚、南亚 |
| 龙泉青瓷 | 龙泉及浙闽系 | 东亚、东南亚 |
| 黑釉盏 | 建窑、吉州 | 日本、东亚 |
| 白地黑花 | 磁州系 | 东北亚、东南亚 |

<br>

### 辽瓷

辽朝辖境涵盖今华北、东北及内蒙古东部；瓷业受中原影响，又具契丹游牧文化特色。

**主要窑址**：① **赤峰缸瓦窑**（内蒙古）——辽代早期官窑性质；② **辽宁喀左水泉、阜新查海、法库辽三彩窑**等；③ **北京门头沟龙泉务**——辽、金、元持续烧造，产品含白瓷、三彩、色釉。

**胎釉**：白瓷、黑釉、黄绿釉、**辽三彩**（黄、绿、白釉陶，多施于胎上，属低温铅釉陶，非高温瓷）；白瓷类定窑风格明显，部分为仿定。

**造型——契丹风格**：**鸡冠壶**（皮囊壶式，双孔或单孔，仿皮袋）、**凤首瓶**（壶口作凤首）、**穿带瓶**（两侧有系）、**盘口长颈瓶**、**海棠式长盘**等，体现游牧生活与中原器形的融合。

**装饰**：刻划、印花、堆塑；三彩器上施黄绿白釉，多划花、贴花，器形有枕、盘、罐、俑等。

**时代意义**：辽瓷为研究宋辽文化交流、契丹物质文化的直接材料；缸瓦窑、龙泉务等窑址证明北方瓷业在辽金时期持续整合。

<br>

### 金瓷

金朝定都后，中原瓷业在战争破坏后逐步恢复；定窑、磁州窑、钧窑、耀州窑、龙泉窑等均在金代继续烧造，部分窑口达到新高峰。

**定窑**：曲阳定窑金代仍产白瓷，印花、刻划继续；胎釉略粗于北宋，仍行销北方。

**磁州窑系**：**磁县观台**、**峰峰彭城**及鹤壁、禹州、修武、山西介休、山东淄博等地磁州系窑场金代产量扩大；白地黑花、铁锈花、黄绿彩等；枕、瓶、罐、盆为大宗。

**钧窑**：禹州神垕及邻近窑场金代钧瓷产量增加，釉色天蓝、月白、窑变紫红均有；器形以碗、盘、炉、盆为主，与北宋多陈设器略有不同。

**耀州窑**：陕西铜川耀州窑金代仍烧青瓷，刻花风格延续，部分产品略显粗率。

**山东、山西等地**：淄博、临汾、大同等地发现金代瓷窑，多白釉、黑釉、白地黑花。

**时代意义**：金瓷承宋启元，为元代磁州、钧窑、定窑系北迁与南北融合提供过渡；反映女真统治下中原手工业恢复与民间用瓷需求。

| 时期 | 定窑 | 磁州系 | 钧窑 | 特色 |
| :--- | :--- | :--- | :--- | :--- |
| 北宋 | 全盛，芒口覆烧 | 兴起 | 宫廷陈设 | 六大窑系形成 |
| 南宋 | 续烧 | 南移部分窑场 | — | 龙泉、景德镇崛起 |
| 辽 | 仿定白瓷 | — | — | 鸡冠壶、辽三彩 |
| 金 | 续烧 | 扩大 | 产量增 | 中原恢复、民窑为主 |

<br>

## 元代

1271—1368。对应原书第八章（p.331–356）。宋金多元窑系格局在战乱与交通变迁中重组：**景德镇**因瓷石—高岭土二元配方与**浮梁瓷局**制度跃居全国瓷业中心；**龙泉窑**仍大规模续烧并主导外销青瓷；**磁州**、**钧窑**、**定窑**系及各地民窑并行。元代工艺核心突破是**青花**、**釉里红**与**卵白釉枢府瓷**的成熟，并开启面向西亚、东南亚的**外销瓷**新高峰。

<br>

### 浮梁瓷局

元廷于景德镇设**浮梁瓷局**（《元史·百官志》正式局名），专管贡瓷烧造与税课征收，为后世**御器厂**之先声。据《元史·百官志》及《景德镇陶录》等载，设局时间在**至元十五年（1278）**——此前部分文献误作至元二十七年，应以 1278 年为定。所烧供枢密院等官府之卵白釉器习称**枢府瓷**，不宜将局名写作「枢府瓷局」。

**职能**：① 烧造供宫廷、官府用瓷（枢府卵白等）；② 管理浮梁县及邻近窑场税课；③ 协调官样与民窑生产。局址设在今景德镇珠山一带，与后世御器厂位置重叠。

**产品分工**：官样以**枢府瓷**（卵白釉、印花小件）为主；民窑则产**青白瓷**、**青花**、**釉里红**及各类色釉，并承担大宗外销。官民并行、官搭民烧的雏形于此期已现。

### 湖田窑与二元配方

**湖田窑**为景德镇元代核心窑场之一，位于今景德镇东南湖田乡；考古发现龙窑、马蹄窑、葫芦窑及大量窑具、瓷片堆积，地层可辨元、明、清连续烧造。

**胎料**：元代景德镇普遍采用**瓷石 + 高岭土**二元配方（「二元配胎」），较宋代单一瓷石胎 Al₂O₃ 含量提高，可烧更大、更厚、更稳定的器物。高岭土产地即今景德镇东乡**高岭**村，地名由此得名。

**工艺特征**：

* **胎体**：较宋瓷普遍厚重；大件罐、瓶、尊、盘常**分段拉坯或模制后接胎**，接痕处未完全修平，是元瓷断代常见线索。
* **釉**：石灰—碱釉体系，透明度提高；常见**青白釉**、**卵白釉**、**青花透明釉**。
* **窑炉**：湖田等地龙窑加长，装烧量扩大；部分精品采用匣钵单件装烧。

<br>

### 枢府瓷与卵白釉

「枢府」为元代**枢密院**简称。枢府瓷专供枢密院及宫廷使用，是元代官样瓷器代表。

**胎釉**：典型为**卵白釉**——釉色失透、白中闪青，如鸭蛋青白，不同于宋影青之透明青白。釉层较厚，温润如脂；部分精品胎质细白。

**装饰**：以**印花**、**划花**为主，纹样多云龙、缠枝花卉、凤穿花等；器形以**小件碗、盘、高足杯**、**枢府款铭盘**为主，大件较少。底足多**露胎**或浅圈足，部分器底或器内署**「枢府」**、**「太禧」**（太禧宗院）等款。

**与青花分工**：枢府瓷重制度与单色釉、印花；青花重绘画与外销。卵白釉亦见于无款民窑器，精粗有别；带「枢府」款者当为官样无疑。

| 对比项 | 枢府卵白 | 元青花 |
| :--- | :--- | :--- |
| 釉色 | 失透卵白 | 透明青白或白釉 |
| 装饰 | 印花、划花 | 青花满绘 |
| 器形 | 小件碗盘杯 | 大罐、大瓶、大盘 |
| 款识 | 「枢府」「太禧」 | 多无款或干支款 |

<br>

### 青花与青料

元青花由唐宋釉下蓝花、**巩义唐青花**、磁州白地黑花等工艺发展而来，至元中晚期趋于成熟，元末（**至正**年间）达高峰。器形高大，构图繁密，为明清青花之直接先导。青料（钴料）更替是元明清青花断代的第一依据，宜系统掌握。

#### 青料总表（元—清）

| 青料 | 别称／产地 | 成分倾向 | 呈色要点 | 主要时代 |
| :--- | :--- | :--- | :--- | :--- |
| **苏麻离青** | 苏泥勃青、苏勃泥青；波斯／西亚进口 | 高铁低锰 | 浓艳宝石蓝；**晕散**；积釉处**铁锈斑**下凹入胎 | 元中晚—明永宣（库存用尽后罕用） |
| **石子青** | **石青**、无名子、画烧青；江西瑞州（高安、上高、宜丰）、婺源等 | 锰较高 | 单独用则**灰暗偏黑**；多与进口料或回青混配 | 明洪武以降；明清**民窑**常用 |
| **平等青** | **陂塘青**；江西乐平 | 铁少、淘炼较精 | **淡雅蓝水色**，匀净少晕散 | 明成化—正德早 |
| **回青** | 西域大青、佛头青；西域／云南传入说 | 钴料，难单用 | 纯用则「色散不收」；配石子青则**蓝中泛紫** | 明正德晚—万历前中期 |
| **浙料** | 浙青；浙江绍兴、金华、衢州 | 国产上乘 | 重则浓、轻则淡翠；有**元子（顶元子）**、紫料、天青等品 | 明万历中后—清前期官窑 |
| **珠明料** | 云南等地 | 锰偏高、色稳 | 明丽层次强；与浙料等配合可成**翠毛蓝** | 清康熙高峰 |

> [!NOTE]+ 「回青」勿与元苏料混称
>
> 元明早期进口高铁料习称苏麻离青；嘉靖前后「回青」另指西域／云南传入、需配石子青之料。文献偶混用，笔记宜按呈色与时代分列。

<br>

#### 元青花与苏麻离青

* **苏麻离青**：含铁高、锰低，呈色**浓艳宝石蓝**，有自然**晕散**及**铁锈斑**（结晶斑），入胎较深。
* **国产料**：呈色灰蓝、蓝灰，少晕散，铁锈斑不明显；民窑及中晚期常见。

#### 至正型青花

「至正型」指元末**至正**年间（1341—1368）一类青花精品风格，以**英国大维德基金会藏**那对「至正十一年」铭**象耳瓶**（「萧何月下追韩信」故事）为标尺：器形硕大、纹饰分层满绘、苏麻离青发色浓艳、带**干支纪年款**。

**典型器形**：**大罐**（含四爱图、鬼谷下山等人物故事罐）、**玉壶春瓶**、**梅瓶**、**大盘**、**高足杯**、**执壶**、**僧帽壶**、**八棱瓶**等。

**纹饰布局**：口沿卷草或回纹 → 肩腹主题（缠枝莲、牡丹、松竹梅、人物故事）→ 近足莲瓣；多层横带式装饰为典型。

**人物故事**：元青花人物故事图盛行，如「萧何月下追韩信」「鬼谷子下山」「昭君出塞」「三顾茅庐」「蒙恬造笔」等；构图繁密，人物衣纹、背景山石树木层次丰富。

> [!EXAMPLE]+ 元青花断代观察
>
> - **苏麻离青**：蓝中泛黑、晕散、铁锈斑——元末至明初官窑精品常见
> - **构图**：横带分层、满绘繁密——元风；明初仍部分延续
> - **接胎**：大罐、大瓶肩腹接痕——元及明初大件常见
> - **款识**：至正干支款极稀；多数无款

<br>

### 釉里红

**釉里红**以铜为着色剂，在瓷胎上绘画后罩透明釉，于高温还原焰中一次烧成。铜离子对窑内气氛极敏感，烧成难度大，**成功率远低于青花**，故元釉里红精品稀少。

**呈色**：理想为鲜红色；实际多**暗红、灰红、局部发黑**或**红斑不匀**，与铜在还原—氧化气氛波动中析晶有关。

**器形**：玉壶春瓶、罐、碗、高足杯、匜等；纯釉里红器少于**青花釉里红**（以青花主纹、釉里红点缀花卉、游鱼、火焰等）。

**时代意义**：釉里红与青花并列为元代釉下彩两大突破；明代洪武、宣德仍烧，成化后一度衰落，清康熙以铜红釉及釉里红技术复兴。

<br>

| :--- | :--- | :--- |

| **蓝釉 / 红釉** | 高温色釉；蓝釉器、红釉器 | 景德镇、钧窑系 |

<br>

### 龙泉窑与外销

元代**龙泉窑**仍为全国最大青瓷产区之一；**大窑**、**金村**、**溪口**、**茶碗窑**等窑场延续南宋厚釉传统，产品供内销与外贸。

**胎釉**：胎灰白或灰褐；釉色**梅子青**、**粉青**续烧，部分为追求外销数量而略趋灰黄；刻花、划花、贴花、印花（莲瓣、云纹、龙纹）增多。

**外销器特征**：器形常加大（大盘、大罐、双耳瓶）；部分刻划**莲瓣纹**、**花卉纹**适应海外市场；与景德镇青花并行输出，在**韩国新安沉船**（1323）、**土耳其托普卡帕宫**、**伊朗阿德比尔寺**、**日本**、**东南亚**等地均有大量发现。

**「天下龙泉」**：元及明初，龙泉青瓷外销量极大，文献有「天下龙泉」之誉；福建、广东窑场亦仿烧龙泉风格青瓷，称「仿龙泉」或「外销青瓷」。

<br>

### 造型与接胎

元代瓷器造型雄浑硕大，与蒙古尚大之风及外销需求相关。

| 类型 | 常见器形 | 工艺特点 |
| :--- | :--- | :--- |
| 日用 | 碗、盘、高足杯、执壶 | 印花、划花；卵白釉小件 |
| 陈设 | 玉壶春瓶、梅瓶、罐、尊 | 青花满绘；分段接胎 |
| 宗教 / 外销 | 僧帽壶、八棱瓶、大盘、多穆壶 | 适应伊斯兰、东南亚习惯 |

**接胎（接坯）**：大件器（如高 40 cm 以上大罐、大瓶）因拉坯高度有限，常分**上、下两段或数段**拉坯，再于**肩、腹**处相接；接合处或留**接痕**、**胎接台阶**，修坯不完全时可在器身内外观察到。此为元及明初大件断代重要依据，非必为粗制。

**装饰手法**：刻、划、印、贴、绘并用；青花以**分层横带式**布局为典型。

<br>

### 外销与交流

元代**海上贸易**（泉州、广州、上海、扬州、宁波等港口）推动瓷器大规模输出。

| 路线 | 主要品种 | 发现地 |
| :--- | :--- | :--- |
| 海路东向 | 龙泉青瓷、青花、卵白 | 日本、朝鲜、东南亚诸岛 |
| 海路西向 | 青花大盘、罐、龙泉青瓷 | 印度、波斯、阿拉伯、东非 |
| 陆路 | 青花、磁州器 | 中亚 |

**市场适应**：外销器形、纹饰常迎合**伊斯兰**市场——如无猪纹、大盘、执壶、八棱器；部分青花纹样吸收**波斯**几何、缠枝风格。土耳其托普卡帕宫、伊朗阿德比尔寺藏元青花大罐、盘，为外销与贡赐之证。

<br>

### 时代意义

元代上承宋瓷多元格局，下启明清官窑体系；**浮梁瓷局（1278）**与**二元配胎**奠定景德镇此后六百年瓷都地位。**青花**与**釉里红**成熟，使中国瓷器装饰由刻划印为主转向**釉下彩绘**为主；**至正型青花**树立人物故事、满绘构图范式。外销规模扩大，中国瓷器深度嵌入亚欧贸易网络，为明代御器厂与清代外销瓷高峰预作铺垫。

<br>

## 明代

1368—1644。对应原书第九章（p.357–414）。明初恢复窑业，**洪武**起在景德镇珠山设**御器厂**（官窑），与民窑分轨并行。青花贯穿始终，**永宣**、**成化**、**嘉万**各呈高峰；**斗彩**、**五彩**、**颜色釉**并起。景德镇以外**德化白瓷**、**宜兴紫砂**、**龙泉**、**石湾**、**漳州**、**磁州**等各具特色。外销延续并扩大，至晚明与欧洲贸易直接对接。

<br>

### 御器厂与制度

#### 设立与沿革

* **洪武**：于景德镇**珠山**设**御器厂**，烧造宫廷用瓷；官窑制度规范化，承元浮梁瓷局之统。
* **永乐、宣德**：御器厂烧造最盛；多次遣**督陶官**（如宣德前后）驻厂；器形、款识、青料皆成范式。
* **正统—天顺**：官窑纪年器少，史称**「空白期」**；民窑仍产青花等，地层与传世品研究仍在补充。
* **成化—正德**：御器厂精烧斗彩、颜色釉；成化款识规范为后世标尺。
* **嘉靖—万历**：回青入料，五彩、大器盛行；晚明外销激增。
* **天启、崇祯**：御器厂烧造时断时续；民窑青花、五彩、外销瓷活跃。

#### 官搭民烧

明代官窑采取**官搭民烧**（亦称「官寄民烧」）为主：官方出**胎土、青料、样制**，委托民窑代烧，或指定民窑搭烧官窑器；合格者进贡，不合格者打碎（「有瑕弃毁」）。此制减轻御器厂窑炉压力，又利用民窑熟练工匠，但民窑承担烧造风险与成本。

**督陶官**：永乐、宣德、嘉靖等朝多次派遣内官或地方官驻景德镇督窑；**唐英**之前，督窑多侧重催办与验收，工艺总结以清唐英《陶成纪事》为最系统。

> [!NOTE]+ 御器厂与民窑关系
>
> - **官窑**：专供宫廷、祭祀、赏赐；款识规范；器形、纹样多严格遵循样制
> - **民窑**：商品瓷、外销瓷、民间用瓷；款识或无款、吉语款、花押
> - **官搭民烧**：官样、官料、民窑灶火；合格进贡，瑕疵打碎

<br>

### 青花与青料分期

明代青花贯穿全朝；**青料更替**直接决定呈色与风格，为断代第一依据。各料细节已见元代节「青料总表」，下按朝补充用法与辨识。

#### 青料分述

##### 苏麻离青

进口钴料（波斯／西亚），高铁低锰。呈色浓重青翠如宝石蓝，积釉处易出**铁锈斑**（黑褐斑下凹），并有**晕散**。郑和下西洋期间库存充足，**永乐、宣德**官窑多用；宣德晚已见与国产料混绘。成化初库存将尽，仅极少数器仍带苏料特征，此后官窑主用国产平等青。

##### 石子青（石青）

国产料，亦称无名子、画烧青。产江西瑞州诸处（今高安、上高、宜丰一带）及婺源等。《正字通》谓黑赭石「磨水画瓷坯，初无色，烧之成天蓝」。单独使用发色**灰暗偏黑**；洪武以降官窑少单用，多参入苏料或与回青配比。正德部分器呈浓中带灰，即石子青特征。明清**民窑青花**普遍用此料。

##### 平等青（陂塘青）

产江西**乐平**。成化、弘治、正德早期官窑主用。含杂质少，呈色**淡雅柔和**、稳定少晕散，有「云遮雾障」之感，与苏麻离青浓艳铁锈斑形成鲜明对照，是成化青花、斗彩得以精细勾线的物质基础。

##### 回青

《天工开物》称「回青乃西域大青，美者亦名**佛头青**」。正德晚期至嘉靖、隆庆、万历前期官窑多用。纯回青「色散不收」，故须配**石子青**。《江西大志·陶书》：「回青淳，则色散而不收；石青多，则色沉而不亮。」回青比例高则**蓝中泛紫**绚丽，石青多则偏灰蓝。配制有「敲青」之法（敲碎选朱砂斑者为上）。

##### 浙料与珠明料

**浙料**（浙青）：绍兴、金华一带；国产上乘，重则浓、轻则淡翠；品级有**元子（顶元子）**、紫料、天青等，元子为上。万历中期以后至清前期景德镇**官窑**多用。唐英《陶冶图说》亦记浙料出处。

**珠明料**：云南等地；康熙朝与浙料配合，发色明丽、层次分明，成就「**翠毛蓝**」与「墨分五色」分水皴染。

<br>

#### 分期总表

| 时期 | 约年 | 青料 | 呈色与风格 | 代表器 |
| :--- | :--- | :--- | :--- | :--- |

### 永宣青花

**永乐**、**宣德**两朝青花被视为明代官窑青花**典范**，合称**永宣青花**。

**青料**：**苏麻离青**与**国产料**并用；精品苏料呈**宝石蓝**，有自然**晕散**与**铁锈斑**，入胎深；国产料填绘细节或混用，色阶丰富。典型如青花海水龙纹盘：国产料画海水、进口料画龙纹。

**器形**：创新极多——**压手杯**（口沿下内凹，盈握适手）、**僧帽壶**、**扁壶**（抱月瓶）、**花浇**、**大盘**、**天球瓶**、**梅瓶**、**执壶**等；部分仿伊斯兰金属器造型。

**纹饰**：缠枝莲、折枝花果、海水江崖、瑞兽、宝相花；布局较元青花疏朗，仍留部分空白。宣德始**款识**规范。

**款识**：永乐少款，偶见「永乐年制」篆书；宣德「**大明宣德年制**」六字楷款，横竖款皆有，笔力遒劲，为后世仿款重点。

<br>

### 成弘青花与斗彩

**成化**朝青料改用**平等青**（江西乐平「陂塘青」），含铁低，呈色**淡雅蓝水色**，无苏麻离青晕散，适合**细线勾边**与**斗彩**填绘。

**斗彩**：先在胎上以青花勾勒轮廓，施釉高温烧成，再在釉上填**红、黄、绿、紫**等彩，低温烤花；「釉下青花 + 釉上彩」相逗而成，故名斗彩。成化斗彩为**最高峰**——代表如**鸡缸杯**、**天字罐**、**葡萄纹杯**、**婴戏杯**等；胎薄釉润，彩绘精细。

**弘治**：青花承成化风格而略浅淡；**娇黄釉**（鸡油黄一类铁黄）、**绿釉**名世；款识「大明弘治年制」，字体柔和。

**正德**：青料渐用**石子青**，呈色略灰；器形多样；部分器物饰**阿拉伯文**、**波斯文**，反映中西交流。晚期回青开始进入官窑配方。

<br>

### 嘉万青花与五彩

**嘉靖**、**万历**朝青料以**回青**与**石子青**混合为特征——呈色**蓝中泛紫**，浓艳明丽，与永宣苏料之「蓝中泛黑铁锈斑」、成化平等青之「淡雅」皆可一眼区分。

**五彩**：嘉靖、万历盛行；在已烧成之白釉器上，以**红、绿、黄、紫、黑**等彩描绘，再低温烤花。与青花结合称**青花五彩**——青花作蓝彩，与釉上彩并用。题材多**道教**（八仙、八卦、云鹤）、**婴戏**、**花鸟**；布局繁满，具晚明风尚。

**大器**：嘉靖、万历多烧**大罐**、**大盘**、**大瓶**；部分与**外销**订单相关。

**款识**：「大明嘉靖年制」「大明万历年制」六字款；晚明款识繁密，字体渐趋多样。万历中后期浙料逐渐取代回青配比，呈色向清初翠蓝过渡。

<br>

### 颜色釉

明代颜色釉在宣德、成化、弘治、嘉靖等朝均有名品种，为清代色釉之直接先导。

| 品种 | 盛行期 | 呈色与特征 |
| :--- | :--- | :--- |
| **霁红**（祭红、鲜红、宝石红） | 永乐、宣德 | 铜红高温釉；深红匀净；口沿或见白边；烧成极难；嘉靖后一度改矾红 |
| **霁蓝**（祭蓝） | 宣德 | 钴蓝高温釉；深沉稳定 |
| **娇黄**（鸡油黄） | 成化、弘治 | 铁黄；柔和如鸡油；弘治最著 |
| **绿釉** | 成化、弘治 | 孔雀绿、瓜皮绿等 |
| **酱釉** | 洪武—宣德 | 铁呈色，紫红或酱褐色 |
| **甜白** | 永乐、宣德 | 釉色温润如脂；暗花常见 |

洪武、永乐、宣德**铜红釉**技术为后世清康熙**郎窑红**、**霁红**、**豇豆红**奠基；霁蓝、甜白、娇黄亦为清三代仿烧对象。

<br>

### 景德镇民窑

民窑与官窑并行，产品供国内外市场；**民窑青花**、**五彩**、**色釉**数量远大于官窑。

* **镇窑**：湖田、湘湖、落马桥等民窑密集；官搭民烧之搭烧窑场亦在其中。
* **风格**：民窑青花多无款或吉语款；纹饰较官窑自由，题材民间化；胎釉精粗不一，外销器与内销器有别。
* **外销**：晚明民窑承担克拉克瓷、东南亚、日本、欧洲订单之大宗。

<br>

### 德化窑与何朝宗

**德化窑**位于今福建德化，宋元起烧，**明中晚期**白瓷与塑像达高峰，外销欧洲，称「**中国白**」（Blanc de Chine）、「**象牙白**」。

**胎釉**：胎质细白，透光；釉色白中微闪黄或闪青，温润如脂；部分精白器釉层厚而柔和。

**塑像**：**何朝宗**（约 1522—1600）为最著名瓷塑名家，款「何朝宗印」「丁云观印」等；观音、达摩、罗汉、文昌等神佛塑像，衣纹流畅，神态庄严；德化瓷塑与景德镇青花、龙泉青瓷并列为明晚期外销名产。

**日用器**：杯、碗、炉、花瓶、文房等；部分出口欧洲作陈设。

<br>

### 宜兴紫砂

**宜兴窑**位于今江苏宜兴**丁蜀镇**，所产**紫砂**器属**炻器**（介于陶与瓷之间），非严格意义瓷器，但与明清水陆茶具文化紧密相关。

**起源**：明正德、嘉靖间**供春**（或作龚春）制**树瘿壶**，开紫砂名壶之端；晚明**时大彬**、**李仲芳**、**徐友泉**等成大器。

**泥料**：紫泥、红泥、团泥等；一般不施釉（少数挂釉器除外），以**泥色**、**造型**、**款识**取胜。

**工艺**：拍打或手制成型；与景德镇瓷器、德化白瓷形成「瓷都—陶都—白瓷」三角，共同构成晚明士人饮茶风尚之物质基础。

<br>

### 龙泉、石湾与漳州

| 窑口 | 位置 | 明代表 | 特征 |
| :--- | :--- | :--- | :--- |
| **龙泉窑** | 浙江龙泉 | 青瓷续烧 | 明初仍贡；后为民窑外销；梅子青、粉青、刻花、印花 |
| **石湾窑** | 广东佛山 | 广窑 | 明中后期兴起；仿钧釉、各色釉、陶塑、建筑花脊 |
| **漳州窑** | 福建漳州 | 外销瓷 | 蓝釉、白釉、米黄釉；开光青花（Swatow 系，近克拉克风格）；明末至清 |
| **磁州窑系** | 华北 | 民间用瓷 | 白地黑花、剔花；枕、罐、瓶 |
| **彭城窑** | 河北邯郸 | 民间用瓷 | 白釉、黑釉、白地黑花；磁州窑系 |

**龙泉**：明初龙泉仍烧贡瓷；后产量转向外销，釉色略趋灰黄，刻花、莲瓣纹、龙纹常见。

**石湾**：以**仿钧**窑变釉、**翠毛釉**、陶塑著称；与景德镇瓷器、德化白瓷形成广东—福建—江西沿海瓷业带。

**漳州窑**：明末兴起，产品多供**外销**；**米黄釉**、**蓝釉**、**白釉**碗盘，与景德镇青花、德化白瓷并行输出日本、东南亚。

<br>

### 克拉克瓷

**克拉克瓷**（Kraak porcelain）指**万历前后**景德镇民窑烧造、专供**欧洲**（经葡萄牙、荷兰商船）之外销**青花盘、碗**一类；漳州窑等亦产开光青花外销器，多归 **Swatow（汕头／漳州）型**，与 Kraak 风格相关而产地、胎釉有别，不宜径称克拉克瓷。

**命名**：「Kraak」一般认为源自葡萄牙大型商船 **carrack**（荷兰语借写 Kraak，指**船型**而非某条船名）。1602、1604 年荷兰截获葡萄牙 carrack（如 **São Tiago**、**Santa Catarina**）并在阿姆斯特丹拍卖船上中国瓷，推动欧洲对这类开光青花的认知与定名；1600 年菲律宾 **San Diego** 沉船亦出水中国瓷，但**并非** Kraak 名称来源。

**特征**：盘、碗多**折沿**；腹壁**分格开光**，内绘花卉、瑞兽、人物、山水；纹饰繁满；胎较薄；多**万历年制**款或无款。

**意义**：克拉克瓷为欧洲收藏中国瓷之早期标准器；推动荷兰**代尔夫特**（Delftware）等仿中国青花；亦反映晚明海禁背景下月港、澳门等口岸之对外贸易。

<br>

### 造型、装饰与款识

**造型**：碗、盘、杯（压手杯）、瓶（梅瓶、玉壶春、天球、扁瓶）、罐、炉、壶、文房（水盂、笔架）等。永乐、宣德多**扁壶**、**僧帽壶**、**花浇**等中外交流器形。

**装饰**：云龙、海水江崖、缠枝莲、折枝花果、婴戏、高士、八仙、瑞兽；晚明道教、吉祥语增多。官窑纹饰多严格对称、层次清晰。

**款识演变**：

| 朝代 | 款识特点 |
| :--- | :--- |
| 永乐 | 少款；偶见「永乐年制」篆书 |
| 宣德 | 「大明宣德年制」六字楷；横竖款皆有；工艺精 |
| 成化 | 「大明成化年制」六字双行；款字柔和；斗彩器必款 |
| 弘治 | 「大明弘治年制」；字体略瘦 |
| 正德 | 「大明正德年制」；阿拉伯文器亦款 |
| 嘉靖 | 款识增多；「大明嘉靖年制」 |
| 万历 | 六字两行或三行；晚明款识繁密 |
| 天启、崇祯 | 民窑吉语款、花押、无款；官窑款少 |
| 民窑 | 「福」「寿」吉语款、花押、无款 |

<br>

### 外销与技术交流

* **亚洲**：东南亚、日本、朝鲜持续输入；龙泉、景德镇青花、德化白瓷、漳州窑蓝釉等。
* **欧洲**：16 世纪葡萄牙、西班牙、荷兰商船经澳门、月港等输入；克拉克瓷、德化塑像、青花大盘为大宗。
* **技术交流**：景德镇制瓷技术影响周边；欧洲仿制中国瓷（如 **Medici porcelain**、**Delftware**）；中国输入**回青**、**苏麻离青**等钴料。

<br>

### 时代意义

明代确立**御器厂—民窑**双轨体制，**青花**成为最具国际辨识度的中国瓷器品种；**斗彩**、**五彩**、**颜色釉**并立，工艺分类臻于细密。德化白瓷、宜兴紫砂拓展「瓷」之外的名窑传统；**克拉克瓷**将瓷器推为全球化早期商品，晚明与欧洲直接贸易，为清代「中国风」与广彩、粉彩外销预作通道。

<br>

## 清代

1644—1911。对应原书第十章（p.415–454）。清初恢复景德镇御窑，**康熙、雍正、乾隆**三朝为古代制瓷**技术综合高峰**：**珐琅彩**、**粉彩**、**颜色釉**（郎窑红、豇豆红、祭蓝、茶叶末等）并臻极境。中晚期官窑烧造波动，民窑、外销瓷仍盛；**广彩**、**粉彩**外销与欧洲「**中国风**」（Chinoiserie）互构。景德镇以外**德化**、**石湾**、**宜兴**、**龙泉**等延续。

<br>

### 御窑厂沿革

* **顺治**：官窑恢复，器少；「大清顺治年制」款偶见。
* **康熙**：设**景德镇御窑厂**；恢复并超越明代色釉与青花；**郎窑**（**郎廷极**督窑）以**郎窑红**著称；青花「翠毛蓝」名世。
* **雍正**：**年希尧**、**唐英**（1728 起）督窑；工艺精审、款识规范、仿古与创新并重；粉彩、豇豆红、斗彩达峰。
* **乾隆**：唐英长期督窑至 1756 年；器形繁缛、装饰堆叠；**珐琅彩**、**粉彩**、**转心瓶**、**百宝嵌**式装饰；后官窑烧造渐趋程式化。
* **嘉庆—道光**：国势下行，御窑质量参差；款识略草。
* **同治**：官窑部分恢复；「同治年制」款；质量有限。
* **光绪**：「大清光绪年制」；**大雅斋**、**体和殿制**、「天地一家春」等慈禧用瓷堂名款。

<br>

### 唐英与《陶成纪事》

**唐英**（1682—1756），满洲正白旗，雍正、乾隆两朝**内务府员外郎**、**关内税务监督**、**景德镇督陶官**。自**雍正六年（1728）** 至**乾隆二十一年（1756）** 长期督理景德镇御窑厂，为清代制瓷史上最重要督陶官。

**贡献**：① 亲赴窑场，总结制瓷工艺，编**《陶成纪事》**（原书已佚，今有辑本），详载 **57 种仿古釉** 及各色釉、彩之配方与烧成要点；② 组织仿**宋汝、官、哥、钧、定**及**明永宣**等仿古瓷；③ 推动**粉彩**精进、**珐琅彩**宫廷化生产，并改进**窑变**、**转心瓶**等；④ 规范款识、样制，提高官窑成品率。

### 康熙朝

**青花**：主用**浙料**，中后期配合**云南珠明料**；发色明丽，层次分明，称**翠毛蓝**。绘法用**分水皴**，可分「头浓、正浓、二浓、正淡、影淡」**五色阶**，近水墨渲染，为清代青花高峰。

**款识**：「大清康熙年制」六字楷；**双圈**；**图记款**（团花、龙、兔、鼎等）；早期官民款识界限不如雍乾严格。

<br>

### 雍正朝

**粉彩**：雍正为**粉彩**最高峰。釉上加**玻璃白**打底，彩料油／胶调和后渲染，低温烤花；立体感强，色阶柔和；花鸟、人物、山水皆精。

**斗彩**：继承成化并更精细；纹饰疏朗，填彩准确。

**款识**：「大清雍正年制」六字三行或双行；字体**清秀工整**；宋体、篆书并见。

<br>

### 乾隆朝

**珐琅彩**：白釉器上用**进口洋彩**（含金红「洋红」、洋黄等）描绘，再低温烤花；部分**景德镇烧白胎，北京内务府造办处画彩**。康熙创始，雍乾极盛；多小件碗、盘、瓶；常题**诗**、钤**印**；存世极少。

**粉彩**：繁缛华丽；**万花不露地**、**过枝**、**九桃**、**皮球花**等；与金彩、墨彩结合。

**转心瓶**、**交泰瓶**：内瓶可转，外瓶镂空，炫技之作。

**十二色菊瓣盘**：同一菊瓣盘器形施十余种不同颜色釉，展示色釉系统；为唐英督窑下色釉成就之集中呈现。

**仿古**：大规模仿宋汝官哥钧定及明永宣青花、成化斗彩；底署本朝款，属公开慕古。

**款识**：「大清乾隆年制」；篆、楷并用。

<br>

### 颜色釉专节

清康熙以降高温铜红釉复兴，并与钴蓝、铁黄、金红、结晶釉等并臻极境。唐英《陶成纪事》载仿古与色釉达数十种；龚钺《景德镇陶歌》有「官古窑成重霁红，最难全美弗良工」之叹。下按呈色系统分述，**豇豆红、霁红、霁蓝、鸡油黄**等尤须辨清。

#### 红釉系统

高温铜红（还原焰，约 1250–1320℃）与低温铁红、金红分途：

| 品种 | 呈色剂／温度 | 外观与鉴定点 | 盛期 |
| :--- | :--- | :--- | :--- |
| **郎窑红** | 铜；高温 | 鲜红如初凝牛血；玻璃光强；口沿**灯草口**（一圈浅白／米黄）；足端垂釉「郎不流」；常见开片 | 康熙（郎廷极督窑） |
| **霁红**（祭红、鲜红、宝石红） | 铜；高温 | 深红沉稳，釉面匀净，密布细**桔皮棕眼**；少流釉、少开片；较郎窑「静」 | 康晚创／仿明；雍正大量烧 |
| **豇豆红** | 铜；高温 | 浅红如豇豆衣；常夹**绿苔点**；少大件 | 康晚—雍；雍正后渐稀 |
| **鲜红／宝石红** | 铜；高温 | 明永宣传统之延续与仿烧 | 明永宣；清仿 |
| **珊瑚红** | 铁；低温 | 橙红如珊瑚；釉面匀 | 雍乾 |
| **矾红** | 铁；低温 | 正红或朱红；可描画 | 明清常用 |
| **胭脂红**（胭脂水） | **金**；低温约 800℃ | 吹釉极薄，明丽如胭脂；胎薄体轻 | 康晚创；雍正最美 |

**郎窑红 vs 霁红 vs 豇豆红**（康熙三大铜红）：

* **郎窑红**：最鲜、最亮、流釉明显，灯草口＋垂足。
* **霁红**：最深沉、最匀，桔皮棕眼，宜祭祀礼器气质。
* **豇豆红**：最浅淡、最「俏」，绿苔点；器形几乎皆文房小件——**太白尊、柳叶瓶、菊瓣瓶、莱菔尊、印盒、洗**等，无大件。

**豇豆红品级俗称**（同一工艺不同窑变效果）：正红匀净称「大红袍」；典型豇豆红粉红；更娇艳者称「娃娃脸」「美人醉」「桃花片」等。洪亮吉诗「绿如春水初生日，红似朝霞欲上时」即状苔点与红釉并存。配方文献：《景德镇陶录》《南窑笔记》记霁红用红铜条、紫英石、宝石／玛瑙等配合，宜秋冬风霜窑。

**胭脂红**：金为呈色剂，与铜红、铁红皆不同；由浅至深可有淡粉、胭脂水、胭脂红、胭脂紫等层次。

### 嘉庆至光绪

**嘉庆、道光**：御窑烧造减少，质量下降；款识略草；「大清嘉庆年制」「大清道光年制」。

**咸丰**：战乱影响，御窑几近停烧；传世官窑器极少。

**同治**：官窑部分恢复；「同治年制」款；质量参差。

**光绪**：御窑复烧；「大清光绪年制」；**大雅斋**、**体和殿制**、「天地一家春」等慈禧用瓷堂名款（粉彩花鸟等）；质量参差，多仿雍正、乾隆粉彩。

### 广彩与外销瓷

**广彩**（广州织金彩瓷）：**景德镇**烧白胎，运至**广州**由画匠加绘**金彩**、**粉彩**、**墨彩**等，再出口。适应**欧洲**审美——喜**金边**、**浓艳**、**繁缛**；18—19 世纪为外销瓷重要品类。

**外销流程**：欧洲商馆（如广州**十三行**）下单 → 景德镇定烧白胎 → 广州加彩 → 装船出口；或全程在景德镇按样烧造。

**定制器**：家族**纹章**、**欧洲人物**、**宗教题材**、**西方场景**等可按要求绘制；体现**中国风**（Chinoiserie）与欧洲装饰需求之合流。

<br>

### 中国风与中西交流

**17—18 世纪**：欧洲王室、贵族收藏中国瓷；**荷兰东印度公司**、**英国东印度公司**等大量订货；中国瓷器纹样、色釉影响欧洲**室内**、**家具**、**壁纸**、**洛可可**装饰——称「**中国风**」（Chinoiserie）。

**双向影响**：

* **西来**：珐琅彩使用**进口洋彩**；部分纹饰吸收**西洋画**透视、**明暗法**；欧洲**纹章**、**场景**入瓷。
* **东去**：中国青花、粉彩、色釉影响**迈森**（Meissen）、**代尔夫特**等欧洲瓷厂；中国亦输入欧洲绘画技法于宫廷作坊。

**19 世纪**：机械化与贸易格局变化；传统外销瓷仍经广州、上海等口岸输出；品质与数量渐不如前。

<br>

### 造型、装饰与款识

**造型**：继承明式碗、盘、瓶、尊、罐；新增、流行**转心瓶**、**交泰瓶**、**百寿尊**、**花觚**、**牺尊**仿古器；乾隆器形常繁复堆叠。

**装饰**：花鸟、山水、人物、博古、**万花不露地**、**过枝**、**九桃**、**皮球花**；雍正倾向疏朗清秀，乾隆倾向繁缛华丽。

**款识断代**：

| 朝代 | 款识特点 |
| :--- | :--- |
| 康熙 | 「大清康熙年制」六字楷；**双圈**；**图记款**（团花、龙、兔等）；早期官民不分 |
| 雍正 | 六字三行或双行；字体清秀工整；宋体款、篆书款 |
| 乾隆 | 「大清乾隆年制」；篆、楷并用；年号款规范 |
| 嘉庆、道光 | 款识略粗；「大清道光年制」等 |
| 咸丰 | 官窑款极少 |
| 同治 | 「同治年制」等 |
| 光绪 | 「大清光绪年制」；「大雅斋」「体和殿制」「天地一家春」等 |

> [!WARNING]+ 款识辨伪提示
>
> - 清三代官窑款字有**时代风格**：康熙遒劲、雍正清秀、乾隆规整
> - **图记款**、**堂名款**需与器形、彩料、胎釉综合判断
> - 晚清及民国**寄托款**（署「大清康熙年制」等于非本朝器）常见，不可单款断代

### 时代意义

清代尤其是**康雍乾**，将宋代以来各窑口技艺**集于景德镇**，在**胎釉配方、烧成控制、彩料科学、分工管理**上达古代顶峰；**唐英**督窑与《陶成纪事》为传统制瓷技术之系统总结。**粉彩**、**珐琅彩**拓展釉上装饰维度，与**颜色釉**、**青花**形成完整品种体系；**郎窑红**、**豇豆红**、**十二色菊瓣盘**等为色釉史之里程碑。同时，**广彩**外销与欧洲**中国风**互构，中国瓷器成为近代全球化审美的重要媒介。中晚清官窑随国势起伏，但民窑、外销、宜兴紫砂、石湾广窑等仍延续多元格局，至近代工业瓷兴起而渐转轨。
